### Acceptance Criteria

#### US-01: Automatic Type Hint Addition

- **Given** a Python file with untyped functions
- **When** the refactorer processes the file
- **Then** the system:
  - Adds return type annotations to all functions
  - Adds parameter type annotations to all function arguments
  - Uses standard library types (str, int, float, bool, List, Dict, Optional, etc.)
  - Handles complex types (Union, Callable, TypeVar) when appropriate

#### US-02: Format Preservation

- **Given** a Python file with comments and specific formatting
- **When** the refactorer processes the file
- **Then** the system:
  - Preserves all inline comments
  - Preserves all docstrings
  - Maintains original indentation style
  - Keeps blank lines in their original positions
  - Produces minimal git diff (only type annotations added)

#### US-03: Directory Processing

- **Given** a directory path with multiple Python files
- **When** the refactorer runs in batch mode
- **Then** the system:
  - Recursively finds all `.py` files
  - Processes each file independently
  - Reports progress (X of Y files processed)
  - Generates summary report of all changes

#### US-04: Change Preview

- **Given** a file to refactor
- **When** the user requests preview mode
- **Then** the system:
  - Shows the refactoring plan as JSON
  - Displays before/after diff for each function
  - Does not modify any files
  - Allows user to approve or reject

#### US-05: Type Inference

- **Given** a function with untyped parameters
- **When** the LLM analyzes the function
- **Then** the system infers types based on:
  - Variable naming conventions (e.g., `user_id` → int, `name` → str)
  - Return statements and their values
  - Operations performed on parameters
  - Docstring type hints (if present)
  - Default parameter values

#### US-06: Test Suite Compatibility

- **Given** a codebase with existing tests
- **When** refactoring is complete
- **Then** the system:
  - Runs the test suite automatically (if configured)
  - Reports any test failures
  - Provides rollback instructions if tests fail

[LibCST](https://libcst.readthedocs.io/) (from Instagram/Meta) is a Concrete Syntax Tree parser for Python that preserves all formatting details—comments, whitespace, and parentheses. Unlike Python's built-in `ast` module, LibCST allows you to modify code while keeping it human-readable.

1.  **Parse**: Convert code to a Concrete Syntax Tree (LibCST).
2.  **Plan**: Ask LLM: "Which functions need what return types? Return JSON."
3.  **Patch**: Deterministically apply the JSON plan to the Tree.

| Approach        | Best For                                  | Trade-offs                          |
| :-------------- | :---------------------------------------- | :---------------------------------- |
| **LibCST**      | Python-only, format-preserving transforms | Python-specific, larger dependency  |
| **tree-sitter** | Multi-language support, fast parsing      | No format preservation, query-based |
| **RedBaron**    | Simple Python transforms                  | Less maintained, slower than LibCST |
| **Regex**       | Simple, pattern-based changes             | Fragile, can't handle edge cases    |
| **LLM-only**    | Exploratory refactoring, small files      | Hallucination risk, format loss     |

<Callout type="warning">
  **When to use LLM-only refactoring**: Only for exploratory changes on small
  files where you'll manually review every line. For production codebases,
  always use AST-based approaches.
</Callout>

### Alternative: RedBaron

[RedBaron](https://redbaron.readthedocs.io/) is another format-preserving Python parser. While less actively maintained than LibCST, it offers a simpler API for basic transformations:

```python
import redbaron

source = "def add(a, b): return a + b"
red = redbaron.RedBaron(source)

# Find and modify function
func = red.find("def", name="add")
func.arguments[0].annotation = ": int"
print(red.dumps())
```

**Recommendation**: Use LibCST for new projects—it's more actively maintained and has better Python 3.12+ support.

## 17.2.1 AI-Powered Code Transformation Tools (2024-2025)

Before building a custom refactoring agent, consider whether existing AI-powered tools meet your needs. The landscape has evolved significantly:

### Aider: AI Pair Programming

[Aider](https://aider.chat/) is an open-source AI pair programming tool with deep git integration:

```bash
# Install and run
pip install aider-chat
aider --model gpt-4o

# In aider session:
/add legacy_module.py
> Add type hints to all functions in this file
```

**Key Features**:

- Automatic git commits with meaningful messages
- Multi-file editing with dependency awareness
- Supports GPT-4, Claude, and local models
- Architect mode for planning complex changes

**When to use**: Interactive refactoring sessions where you want human-in-the-loop review.

### Cursor IDE

[Cursor](https://cursor.sh/) provides AI-native code editing with context-aware refactoring:

- **Cmd+K**: Inline code generation and transformation
- **Composer**: Multi-file refactoring with codebase awareness
- **@ mentions**: Reference specific files, docs, or symbols

import libcst as cst
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field
from typing import List, Dict
from dotenv import load_dotenv

load_dotenv()

# 1. Define the Schema
class FunctionTypePlan(BaseModel):
    function_name: str
    arg_types: Dict[str, str] = Field(description="Map of argument name to type (e.g. {'a': 'int'})")
    return_type: str = Field(description="Return type annotation (e.g. 'int')")

class RefactorPlan(BaseModel):
    functions: List[FunctionTypePlan]

# 2. The CST Transformer (The Surgeon)
class TypeHintTransformer(cst.CSTTransformer):
    def __init__(self, plans: List[FunctionTypePlan]):
        # Convert list to dict for lookup
        self.plans = {p.function_name: p for p in plans}

    def leave_FunctionDef(self, original, updated):
        fname = original.name.value
        if fname in self.plans:
            plan = self.plans[fname]

            # 1. Add Return Type
            return_annotation = cst.Annotation(annotation=cst.Name(plan.return_type))

            # 2. Add Argument Types
            new_params = []
            for param in updated.params.params:
                pname = param.name.value
                if pname in plan.arg_types:
                    ptype = plan.arg_types[pname]
                    new_param = param.with_changes(
                        annotation=cst.Annotation(annotation=cst.Name(ptype))
                    )
                    new_params.append(new_param)
                else:
                    new_params.append(param)

            return updated.with_changes(
                returns=return_annotation,
                params=updated.params.with_changes(params=new_params)
            )
        return updated

# 3. Main Logic
def main():
    # A. Read Source
    with open("legacy.py", "r") as f:
        source_code = f.read()

    # B. Plan (The LLM)
    print("🧠 Analyzing code...")
    llm = ChatOpenAI(model="gpt-4o").with_structured_output(RefactorPlan)
    prompt = f"Analyze the following Python code and infer types for all functions:\n\n{source_code}"

    plan = llm.invoke(prompt)
    print(f"📋 Plan: {plan}")

    # C. Patch (The Surgeon)
    print("🔧 Applying patches...")
    tree = cst.parse_module(source_code)
    transformer = TypeHintTransformer(plan.functions)
    modified_tree = tree.visit(transformer)

    # D. Write Result
    with open("legacy_refactored.py", "w") as f:
        f.write(modified_tree.code)

    print("✅ Done! Check legacy_refactored.py")

if __name__ == "__main__":
    main()

### Rollback Strategies

When tests fail, you need reliable rollback:

```python
import shutil
from pathlib import Path
from typing import Dict

class RefactoringTransaction:
    """Manage refactoring with automatic rollback on failure."""

    def __init__(self):
        self.backups: Dict[Path, Path] = {}

    def backup(self, file_path: Path) -> None:
        """Create backup before modification."""
        backup_path = file_path.with_suffix(file_path.suffix + ".bak")
        shutil.copy2(file_path, backup_path)
        self.backups[file_path] = backup_path

    def rollback(self) -> None:
        """Restore all files from backups."""
        for original, backup in self.backups.items():
            shutil.move(backup, original)
        self.backups.clear()

    def commit(self) -> None:
        """Remove backups after successful refactoring."""
        for backup in self.backups.values():
            backup.unlink()
        self.backups.clear()

# Usage
transaction = RefactoringTransaction()
try:
    for file in files_to_refactor:
        transaction.backup(file)
        refactor_file(file)

    # Validate
    test_result = run_tests()
    if not test_result.passed:
        print("❌ Tests failed, rolling back...")
        transaction.rollback()
    else:
        print("✅ All tests passed, committing changes")
        transaction.commit()
except Exception as e:
    transaction.rollback()
    raise
```

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any
from pathlib import Path

class LanguageHandler(ABC):
    """Abstract base for language-specific handlers."""

    @abstractmethod
    def parse(self, source: str) -> Any:
        """Parse source code to AST."""
        pass

    @abstractmethod
    def extract_functions(self, ast: Any) -> List[Dict]:
        """Extract function signatures from AST."""
        pass

    @abstractmethod
    def apply_type_hints(self, ast: Any, plan: Dict) -> str:
        """Apply type hints and return modified source."""
        pass

class PythonHandler(LanguageHandler):
    def parse(self, source: str):
        import libcst as cst
        return cst.parse_module(source)

    # ... implementation

class TypeScriptHandler(LanguageHandler):
    def parse(self, source: str):
        # Use ts-morph via subprocess or Node.js bridge
        pass

    # ... implementation

class MultiLanguageRefactorer:
    """Refactoring agent supporting multiple languages."""

    HANDLERS = {
        ".py": PythonHandler,
        ".ts": TypeScriptHandler,
        ".tsx": TypeScriptHandler,
        ".java": JavaHandler,
    }

    def refactor_file(self, file_path: Path) -> str:
        suffix = file_path.suffix
        if suffix not in self.HANDLERS:

def chunk_files(
    directory: Path,
    chunk_size: int = 50,
    max_file_size: int = 100_000  # 100KB
) -> Iterator[List[Path]]:
    """Yield chunks of files for batch processing."""

    python_files = []

    typed_functions: int = 0
    type_coverage: float = 0.0

    def to_json(self) -> str:
        return json.dumps({
            "timestamp": self.timestamp.isoformat(),
            "total_files": self.total_files,
            "typed_files": self.typed_files,
            "total_functions": self.total_functions,
            "typed_functions": self.typed_functions,
            "type_coverage": self.type_coverage
        })

def calculate_type_coverage(directory: Path) -> RefactoringMetrics:
    """Calculate current type hint coverage."""
    metrics = RefactoringMetrics()

    for file in directory.rglob("*.py"):
        metrics.total_files += 1

        # Parse and analyze
        tree = cst.parse_module(file.read_text())
        functions = extract_functions(tree)

        file_typed = True
        for func in functions:
            metrics.total_functions += 1
            if func["has_return_type"] and func["has_param_types"]:
                metrics.typed_functions += 1
            else:
                file_typed = False

        if file_typed:
            metrics.typed_files += 1

    if metrics.total_functions > 0:
        metrics.type_coverage = metrics.typed_functions / metrics.total_functions

    return metrics
```
