## Beyond Prompt Engineering

Prompt engineering is about crafting the right words. **Context engineering** is about building reliable systems that deliver the right information to those prompts.

<ConceptIntro
  title="Context Engineering"
  analogy="Prompt engineering is like writing a good exam question. Context engineering is like building the entire educational system that prepares students to answer it—textbooks, lectures, study materials, all delivered reliably and on time."
  technicalDef="Context engineering is a structured, systematic methodology for gathering, processing, and delivering reliable context to AI systems. It transforms messy, long-running data workflows into predictable, reproducible reasoning pipelines."
  whyItMatters="The difference between 'vibe coding' and production systems. Vibe coding hopes the agent figures it out. Context engineering guarantees the agent has what it needs."

<Callout type="tip">

  quality depends heavily on curating the entire context stack—not just clever
  prompt text. Context engineering encompasses four key strategies: **writing**
  (external memory), **selecting** (relevant retrieval), **compressing**
  (summarization), and **isolating** (compartmentalized workflows).
</Callout>

Modern LLMs offer massive context windows—Claude 3.5 supports 200K tokens, Gemini 1.5 Pro handles up to 2M tokens. But bigger isn't always better. Effective context window management is critical for both cost and quality.

<Callout type="warning">
  **The "Lost in the Middle" Problem**: Research from Stanford (2024) confirms
  that LLMs struggle to use information placed in the middle of long contexts.
  Key facts at positions 25-75% of the context are recalled significantly less
  accurately than those at the beginning or end.
</Callout>

### Context Window Strategies

```python
from dataclasses import dataclass
from typing import Literal

@dataclass
class ContextWindowConfig:
    """Configuration for context window management."""
    max_tokens: int = 128000
    reserved_for_output: int = 4096
    reserved_for_system: int = 2000
    placement_strategy: Literal["primacy", "recency", "sandwich"] = "sandwich"

class ContextWindowManager:
    """Manage context placement to maximize LLM attention."""

    def __init__(self, config: ContextWindowConfig):
        self.config = config
        self.available_tokens = (
            config.max_tokens -
            config.reserved_for_output -
            config.reserved_for_system
        )

    def arrange_context(
        self,
        sections: list[dict],
        query: str
    ) -> list[dict]:
        """Arrange context sections to optimize attention.

        Sandwich strategy: Most important at start and end,
        less critical in the middle.
        """
        # Sort by relevance score
        sorted_sections = sorted(
            sections,
            key=lambda x: x.get("relevance", 0),
            reverse=True
        )

        if self.config.placement_strategy == "sandwich":
            # Split into high/medium/low priority
            n = len(sorted_sections)
            high_priority = sorted_sections[:n//3]
            medium_priority = sorted_sections[n//3:2*n//3]
            low_priority = sorted_sections[2*n//3:]

            # Sandwich: high -> low -> medium -> high
            return (
                high_priority[:len(high_priority)//2] +  # Start
                low_priority +                            # Middle
                medium_priority +                         # Middle
                high_priority[len(high_priority)//2:]    # End
            )

        elif self.config.placement_strategy == "primacy":
            # Most important first
            return sorted_sections

        else:  # recency
            # Most important last (for chat-style interactions)
            return sorted_sections[::-1]

    def chunk_document(
        self,
        text: str,
        chunk_size: int = 1000,
        overlap: int = 200
    ) -> list[str]:
        """Chunk long documents with semantic boundaries."""
        # Prefer splitting at paragraph boundaries
        paragraphs = text.split('\n\n')

        chunks = []
        current_chunk = []
        current_size = 0

        for para in paragraphs:
            para_tokens = len(para.split()) * 1.3  # Rough token estimate

            if current_size + para_tokens > chunk_size:
                if current_chunk:
                    chunks.append('\n\n'.join(current_chunk))
                # Start new chunk with overlap
                overlap_text = current_chunk[-1] if current_chunk else ""
                current_chunk = [overlap_text, para] if overlap_text else [para]
                current_size = para_tokens + (len(overlap_text.split()) * 1.3)
            else:
                current_chunk.append(para)
                current_size += para_tokens

        if current_chunk:
            chunks.append('\n\n'.join(current_chunk))

        return chunks
```

### Hybrid Search: Vector + Keyword

<HybridSearchVisualizer />

```python
from typing import Optional
import numpy as np

class HybridRetriever:
    """Combine dense (vector) and sparse (BM25) retrieval."""

    def __init__(
        self,
        vector_store,
        bm25_index,
        alpha: float = 0.7  # Weight for vector vs keyword
    ):
        self.vector_store = vector_store
        self.bm25_index = bm25_index
        self.alpha = alpha

    def retrieve(
        self,
        query: str,
        k: int = 10,
        filter_metadata: Optional[dict] = None
    ) -> list[dict]:
        """Hybrid retrieval with reciprocal rank fusion."""

        # Dense retrieval (semantic similarity)
        vector_results = self.vector_store.similarity_search(
            query, k=k*2, filter=filter_metadata
        )

        # Sparse retrieval (keyword matching)
        bm25_results = self.bm25_index.search(query, k=k*2)

        # Reciprocal Rank Fusion (RRF)
        scores = {}
        k_rrf = 60  # RRF constant

        for rank, doc in enumerate(vector_results):
            doc_id = doc["id"]
            scores[doc_id] = scores.get(doc_id, 0) + self.alpha / (k_rrf + rank)

        for rank, doc in enumerate(bm25_results):
            doc_id = doc["id"]
            scores[doc_id] = scores.get(doc_id, 0) + (1 - self.alpha) / (k_rrf + rank)

        # Sort by combined score
        ranked_ids = sorted(scores.keys(), key=lambda x: scores[x], reverse=True)

        return self._fetch_documents(ranked_ids[:k])
```

### Reranking for Precision

```python
from cohere import Client as CohereClient

class RerankedRetriever:
    """Two-stage retrieval: fast recall + precise reranking."""

    def __init__(self, base_retriever, cohere_api_key: str):
        self.base_retriever = base_retriever
        self.cohere = CohereClient(api_key=cohere_api_key)

    def retrieve(self, query: str, k: int = 5, initial_k: int = 20) -> list[dict]:
        """Retrieve with reranking for higher precision."""

        # Stage 1: Fast retrieval (high recall)
        candidates = self.base_retriever.retrieve(query, k=initial_k)

        # Stage 2: Neural reranking (high precision)
        if not candidates:
            return []

        rerank_response = self.cohere.rerank(
            model="rerank-english-v3.0",
            query=query,
            documents=[doc["content"] for doc in candidates],
            top_n=k
        )

        # Return reranked results
        return [
            {**candidates[r.index], "rerank_score": r.relevance_score}
            for r in rerank_response.results
        ]
```

<Callout type="info">
  **HyDE (Hypothetical Document Embeddings)**: Generate a hypothetical answer to
  the query, then use that answer's embedding for retrieval. This bridges the
  gap between question-style queries and document-style content.
</Callout>

```python
class HyDERetriever:
    """Hypothetical Document Embeddings for better retrieval."""

    def __init__(self, llm, vector_store, embedder):
        self.llm = llm
        self.vector_store = vector_store
        self.embedder = embedder

    async def retrieve(self, query: str, k: int = 5) -> list[dict]:
        """Generate hypothetical answer, then retrieve similar docs."""

        # Generate hypothetical document
        hyde_prompt = f"""Write a detailed paragraph that would answer this question:

Question: {query}

Write as if you're an expert explaining this topic. Be specific and technical."""

        hypothetical_doc = await self.llm.ainvoke(hyde_prompt)

        # Embed the hypothetical document
        hyde_embedding = self.embedder.embed(hypothetical_doc.content)

        # Retrieve using hypothetical doc embedding
        results = self.vector_store.similarity_search_by_vector(
            hyde_embedding, k=k
        )

        return results

class MultiQueryRetriever:
    """Generate multiple query variations for broader recall."""

    def __init__(self, llm, base_retriever):
        self.llm = llm
        self.base_retriever = base_retriever

    async def retrieve(self, query: str, k: int = 5) -> list[dict]:
        """Generate query variations and merge results."""

        # Generate alternative queries
        expansion_prompt = f"""Generate 3 alternative versions of this search query.
Each should capture a different aspect or phrasing.

Original query: {query}

Return only the 3 queries, one per line."""

        response = await self.llm.ainvoke(expansion_prompt)
        queries = [query] + response.content.strip().split('\n')[:3]

        # Retrieve for each query
        all_results = {}
        for q in queries:
            results = self.base_retriever.retrieve(q, k=k)
            for doc in results:
                if doc["id"] not in all_results:
                    all_results[doc["id"]] = doc
                    all_results[doc["id"]]["query_matches"] = 1
                else:
                    all_results[doc["id"]]["query_matches"] += 1

        # Rank by number of query matches
        ranked = sorted(
            all_results.values(),
            key=lambda x: x["query_matches"],
            reverse=True
        )

        return ranked[:k]
```

Context fetching is expensive—both in latency and API costs. Strategic caching dramatically improves both.

### Semantic Caching

```python
import hashlib
import json
from datetime import datetime, timedelta
from typing import Optional
import numpy as np

class SemanticCache:
    """Cache based on semantic similarity, not exact match."""

    def __init__(
        self,
        embedder,
        similarity_threshold: float = 0.95,
        ttl_hours: int = 24
    ):
        self.embedder = embedder
        self.threshold = similarity_threshold
        self.ttl = timedelta(hours=ttl_hours)
        self.cache = {}  # {embedding_key: (embedding, result, timestamp)}

    def _cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float:
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

    def get(self, query: str) -> Optional[dict]:
        """Find semantically similar cached result."""
        query_embedding = self.embedder.embed(query)

        best_match = None
        best_similarity = 0

        for key, (embedding, result, timestamp) in self.cache.items():
            # Check TTL
            if datetime.now() - timestamp > self.ttl:
                continue

            similarity = self._cosine_similarity(query_embedding, embedding)
            if similarity > self.threshold and similarity > best_similarity:
                best_similarity = similarity
                best_match = result

        return best_match

    def set(self, query: str, result: dict):
        """Cache result with query embedding."""
        embedding = self.embedder.embed(query)
        key = hashlib.md5(query.encode()).hexdigest()
        self.cache[key] = (embedding, result, datetime.now())

    def invalidate_by_topic(self, topic_embedding: np.ndarray, threshold: float = 0.8):
        """Invalidate cache entries related to a topic."""
        keys_to_remove = []
        for key, (embedding, _, _) in self.cache.items():
            if self._cosine_similarity(embedding, topic_embedding) > threshold:
                keys_to_remove.append(key)

        for key in keys_to_remove:
            del self.cache[key]
```

### Response Caching Patterns

```python
from functools import lru_cache
import hashlib
import json

class TieredCache:
    """Multi-tier caching: memory -> Redis -> recompute."""

    def __init__(self, redis_client, memory_size: int = 1000):
        self.redis = redis_client
        self.memory_cache = {}
        self.memory_size = memory_size
        self.access_order = []

    def _cache_key(self, query: str, params: dict) -> str:
        """Generate deterministic cache key."""
        key_data = json.dumps({"query": query, **params}, sort_keys=True)
        return hashlib.sha256(key_data.encode()).hexdigest()

    async def get_or_compute(
        self,
        query: str,
        params: dict,
        compute_fn,
        ttl_seconds: int = 3600
    ):
        """Check caches, compute if miss."""
        key = self._cache_key(query, params)

        # Tier 1: Memory cache
        if key in self.memory_cache:
            return self.memory_cache[key]

        # Tier 2: Redis cache
        cached = await self.redis.get(key)
        if cached:
            result = json.loads(cached)
            self._add_to_memory(key, result)
            return result

        # Tier 3: Compute
        result = await compute_fn(query, **params)

        # Store in both tiers
        await self.redis.setex(key, ttl_seconds, json.dumps(result))
        self._add_to_memory(key, result)

        return result

    def _add_to_memory(self, key: str, value):
        """LRU eviction for memory cache."""
        if len(self.memory_cache) >= self.memory_size:
            oldest = self.access_order.pop(0)
            del self.memory_cache[oldest]

        self.memory_cache[key] = value
        self.access_order.append(key)
```

### Advanced Async Patterns

```python
import asyncio
from typing import Optional
from dataclasses import dataclass, field
from contextlib import asynccontextmanager
import aiohttp
from asyncio import Semaphore

@dataclass
class ContextSource:
    name: str
    fetcher: callable
    timeout: float = 5.0
    required: bool = False
    rate_limit: int = 10  # requests per second
    priority: int = 1  # Higher = more important

@dataclass
class FetcherConfig:
    """Configuration for production-grade fetching."""
    max_concurrent: int = 20
    connection_pool_size: int = 100
    rate_limit_window: float = 1.0
    backpressure_threshold: int = 50
    retry_budget: int = 3

class ProductionContextFetcher:
    """Production-grade parallel fetcher with connection pooling and backpressure."""

    def __init__(self, sources: list[ContextSource], config: FetcherConfig = None):
        self.sources = sources
        self.config = config or FetcherConfig()
        self.cache = {}
        self._session: Optional[aiohttp.ClientSession] = None
        self._semaphore = Semaphore(self.config.max_concurrent)
        self._rate_limiters: dict[str, Semaphore] = {}
        self._pending_count = 0

    @asynccontextmanager
    async def _get_session(self):
        """Connection pooling with proper lifecycle management."""
        if self._session is None or self._session.closed:
            connector = aiohttp.TCPConnector(
                limit=self.config.connection_pool_size,
                limit_per_host=20,
                ttl_dns_cache=300,
                enable_cleanup_closed=True
            )
            self._session = aiohttp.ClientSession(connector=connector)

        try:
            yield self._session
        finally:
            pass  # Session reused across requests

    async def _rate_limited_fetch(
        self,
        source: ContextSource,
        query: str
    ) -> Optional[dict]:
        """Fetch with per-source rate limiting."""
        # Initialize rate limiter for source
        if source.name not in self._rate_limiters:
            self._rate_limiters[source.name] = Semaphore(source.rate_limit)

        rate_limiter = self._rate_limiters[source.name]

        async with rate_limiter:
            async with self._semaphore:  # Global concurrency limit
                return await self._fetch_with_backpressure(source, query)

    async def _fetch_with_backpressure(
        self,
        source: ContextSource,
        query: str
    ) -> Optional[dict]:
        """Apply backpressure when system is overloaded."""
        self._pending_count += 1

        try:
            # Backpressure: slow down if too many pending requests
            if self._pending_count > self.config.backpressure_threshold:
                delay = (self._pending_count - self.config.backpressure_threshold) * 0.1
                await asyncio.sleep(min(delay, 2.0))

            return await self._do_fetch(source, query)
        finally:
            self._pending_count -= 1

    async def _do_fetch(self, source: ContextSource, query: str) -> Optional[dict]:
        """Execute fetch with timeout and error handling."""
        cache_key = f"{source.name}:{query}"

        if cache_key in self.cache:
            return self.cache[cache_key]

        try:
            result = await asyncio.wait_for(
                source.fetcher(query),
                timeout=source.timeout
            )
            self.cache[cache_key] = result
            return result
        except asyncio.TimeoutError:
            print(f"⏱️ Timeout fetching from {source.name}")
            return None
        except Exception as e:
            print(f"❌ Error fetching from {source.name}: {e}")
            if source.required:
                raise
            return None

    async def fetch_all(self, query: str) -> dict:
        """Fetch from all sources with priority ordering."""
        # Sort by priority (higher first)
        sorted_sources = sorted(
            self.sources,
            key=lambda s: s.priority,
            reverse=True
        )

        tasks = [
            self._rate_limited_fetch(source, query)
            for source in sorted_sources
        ]

        results = await asyncio.gather(*tasks, return_exceptions=True)

        context = {}
        for source, result in zip(sorted_sources, results):
            if result and not isinstance(result, Exception):
                context[source.name] = result

        return context

    async def close(self):
        """Clean up resources."""
        if self._session and not self._session.closed:
            await self._session.close()
```

```python
import asyncio
from datetime import datetime, timedelta
from collections import deque

class AdaptiveRateLimiter:
    """Rate limiter that adapts to API responses."""

    def __init__(self, initial_rate: int = 10, window: float = 1.0):
        self.rate = initial_rate
        self.window = window
        self.requests: deque = deque()
        self.backoff_until: Optional[datetime] = None

    async def acquire(self):
        """Wait until rate limit allows another request."""
        now = datetime.now()

        # Check if in backoff period
        if self.backoff_until and now < self.backoff_until:
            wait_time = (self.backoff_until - now).total_seconds()
            await asyncio.sleep(wait_time)

        # Clean old requests outside window
        cutoff = now - timedelta(seconds=self.window)
        while self.requests and self.requests[0] < cutoff:
            self.requests.popleft()

        # Wait if at rate limit
        if len(self.requests) >= self.rate:
            oldest = self.requests[0]
            wait_time = (oldest + timedelta(seconds=self.window) - now).total_seconds()
            if wait_time > 0:
                await asyncio.sleep(wait_time)

        self.requests.append(datetime.now())

    def handle_rate_limit_response(self, retry_after: Optional[int] = None):
        """Adapt to rate limit responses from API."""
        if retry_after:
            self.backoff_until = datetime.now() + timedelta(seconds=retry_after)
        else:
            # Exponential backoff
            self.backoff_until = datetime.now() + timedelta(seconds=min(60, self.rate * 2))

        # Reduce rate for future requests
        self.rate = max(1, self.rate // 2)

    def handle_success(self):
        """Gradually increase rate after successes."""
        self.rate = min(100, self.rate + 1)
```

```python
import asyncio
from functools import wraps
from typing import TypeVar, Callable

T = TypeVar('T')

def with_retry(
    max_attempts: int = 3,
    backoff_factor: float = 2.0,
    exceptions: tuple = (Exception,)
):
    """Decorator for exponential backoff retry."""
    def decorator(func: Callable[..., T]) -> Callable[..., T]:
        @wraps(func)
        async def wrapper(*args, **kwargs) -> T:
            last_exception = None

            for attempt in range(max_attempts):
                try:
                    return await func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    if attempt < max_attempts - 1:
                        wait_time = backoff_factor ** attempt
                        print(f"Retry {attempt + 1}/{max_attempts} in {wait_time}s")
                        await asyncio.sleep(wait_time)

            raise last_exception
        return wrapper
    return decorator

class CircuitBreaker:
    """Prevent repeated calls to failing services."""

    def __init__(self, failure_threshold: int = 5, reset_timeout: float = 60.0):
        self.failure_threshold = failure_threshold
        self.reset_timeout = reset_timeout
        self.failures = 0
        self.last_failure_time = 0
        self.state = "closed"  # closed, open, half-open

    async def call(self, func: Callable, *args, **kwargs):
        if self.state == "open":
            if time.time() - self.last_failure_time > self.reset_timeout:
                self.state = "half-open"
            else:
                raise CircuitBreakerOpen("Circuit breaker is open")

        try:
            result = await func(*args, **kwargs)
            if self.state == "half-open":
                self.state = "closed"
                self.failures = 0
            return result
        except Exception as e:
            self.failures += 1
            self.last_failure_time = time.time()
            if self.failures >= self.failure_threshold:
                self.state = "open"
            raise

# Resilient fetcher with retry and circuit breaker
class ResilientFetcher:
    def __init__(self):
        self.circuit_breakers = {}

    @with_retry(max_attempts=3, backoff_factor=2.0)
    async def fetch_with_retry(self, source: str, url: str) -> dict:
        """Fetch with automatic retry on failure."""
        if source not in self.circuit_breakers:
            self.circuit_breakers[source] = CircuitBreaker()

        return await self.circuit_breakers[source].call(
            self._do_fetch, url
        )
```

### LLMLingua-Style Compression

```python
from typing import Literal
import tiktoken

class ContextCompressor:
    """Compress context while preserving key information."""

    def __init__(
        self,
        llm,
        target_ratio: float = 0.5,
        strategy: Literal["extractive", "abstractive", "hybrid"] = "hybrid"
    ):
        self.llm = llm
        self.target_ratio = target_ratio
        self.strategy = strategy
        self.encoder = tiktoken.get_encoding("cl100k_base")

    def count_tokens(self, text: str) -> int:
        return len(self.encoder.encode(text))

    async def compress(
        self,
        context: str,
        query: str,
        max_tokens: int
    ) -> str:
        """Compress context to fit within token budget."""
        current_tokens = self.count_tokens(context)

        if current_tokens <= max_tokens:
            return context

        if self.strategy == "extractive":
            return await self._extractive_compress(context, query, max_tokens)
        elif self.strategy == "abstractive":
            return await self._abstractive_compress(context, query, max_tokens)
        else:
            return await self._hybrid_compress(context, query, max_tokens)

    async def _extractive_compress(
        self,
        context: str,
        query: str,
        max_tokens: int
    ) -> str:
        """Extract most relevant sentences."""
        sentences = self._split_sentences(context)

        # Score sentences by relevance to query
        scored = await self._score_sentences(sentences, query)

        # Select top sentences until budget exhausted
        selected = []
        current_tokens = 0

        for sentence, score in sorted(scored, key=lambda x: x[1], reverse=True):
            sentence_tokens = self.count_tokens(sentence)
            if current_tokens + sentence_tokens <= max_tokens:
                selected.append((sentence, score))
                current_tokens += sentence_tokens

        # Restore original order
        original_order = {s: i for i, s in enumerate(sentences)}
        selected.sort(key=lambda x: original_order.get(x[0], 0))

        return " ".join(s for s, _ in selected)

    async def _abstractive_compress(
        self,
        context: str,
        query: str,
        max_tokens: int
    ) -> str:
        """Generate compressed summary."""
        prompt = f"""Compress the following context to approximately {max_tokens} tokens.
Preserve all information relevant to this query: {query}

Focus on:
- Key facts and data points
- Relevant technical details
- Important relationships and dependencies

Context to compress:
{context}

Compressed version:"""

        response = await self.llm.ainvoke(prompt)
        return response.content

    async def _hybrid_compress(
        self,
        context: str,
        query: str,
        max_tokens: int
    ) -> str:
        """Combine extractive and abstractive approaches."""
        # First pass: extractive to reduce by 50%
        intermediate_budget = max_tokens * 2
        extracted = await self._extractive_compress(
            context, query, intermediate_budget
        )

        # Second pass: abstractive to hit target
        if self.count_tokens(extracted) > max_tokens:
            return await self._abstractive_compress(
                extracted, query, max_tokens
            )

        return extracted

    async def _score_sentences(
        self,
        sentences: list[str],
        query: str
    ) -> list[tuple[str, float]]:
        """Score sentences by relevance to query."""
        # Batch scoring for efficiency
        prompt = f"""Rate each sentence's relevance to the query on a scale of 0-10.
Query: {query}

Sentences:
{chr(10).join(f'{i+1}. {s}' for i, s in enumerate(sentences))}

Return only numbers separated by commas (e.g., "8,3,9,5"):"""

        response = await self.llm.ainvoke(prompt)

        try:
            scores = [float(s.strip()) for s in response.content.split(',')]
            return list(zip(sentences, scores))
        except:
            # Fallback: equal scores
            return [(s, 5.0) for s in sentences]

    def _split_sentences(self, text: str) -> list[str]:
        """Split text into sentences."""
        import re
        sentences = re.split(r'(?<=[.!?])\s+', text)
        return [s.strip() for s in sentences if s.strip()]
```

```python
class HierarchicalSummarizer:
    """Summarize long documents through hierarchical chunking."""

    def __init__(self, llm, chunk_size: int = 4000, overlap: int = 200):
        self.llm = llm
        self.chunk_size = chunk_size
        self.overlap = overlap

    async def summarize(
        self,
        document: str,
        target_length: int = 1000,
        focus_query: str = None
    ) -> str:
        """Hierarchically summarize a long document."""
        chunks = self._chunk_document(document)

        if len(chunks) == 1:
            return await self._summarize_chunk(
                chunks[0], target_length, focus_query
            )

        # Level 1: Summarize each chunk
        chunk_summaries = await asyncio.gather(*[
            self._summarize_chunk(chunk, self.chunk_size // 2, focus_query)
            for chunk in chunks
        ])

        # Combine summaries
        combined = "\n\n".join(chunk_summaries)

        # Level 2: Summarize the summaries (recursive if needed)
        if self.count_tokens(combined) > target_length * 2:
            return await self.summarize(combined, target_length, focus_query)

        return await self._summarize_chunk(combined, target_length, focus_query)

        self,
        chunk: str,
        target_length: int,
        focus_query: str = None
    ) -> str:
        """Summarize a single chunk."""
        focus_instruction = ""
        if focus_query:
            focus_instruction = f"\nFocus on information relevant to: {focus_query}"

        prompt = f"""Summarize the following text in approximately {target_length} tokens.
Preserve key facts, data, and technical details.{focus_instruction}

Text:
{chunk}

Summary:"""

        response = await self.llm.ainvoke(prompt)
```

### Token Budget Allocation

```python
from dataclasses import dataclass
from typing import Dict

@dataclass
class TokenBudget:
    """Manage token allocation across context sections."""
    total: int
    system_prompt: int = 1500
    output_reserve: int = 4000

    @property
    def available(self) -> int:
        return self.total - self.system_prompt - self.output_reserve

class BudgetAllocator:
    """Allocate token budget across context sources."""

    def __init__(self, budget: TokenBudget):
        self.budget = budget

    def allocate(
        self,
        sources: Dict[str, dict],
        priorities: Dict[str, float] = None
    ) -> Dict[str, int]:
        """Allocate tokens to sources based on priority."""
        if priorities is None:
            # Equal allocation
            priorities = {name: 1.0 for name in sources}

        total_priority = sum(priorities.values())
        available = self.budget.available

        allocations = {}
        for name, priority in priorities.items():
            allocations[name] = int(available * (priority / total_priority))

        return allocations

    def allocate_dynamic(
        self,
        sources: Dict[str, dict],
        query: str
    ) -> Dict[str, int]:
        """Dynamically allocate based on source relevance to query."""
        # Score each source's relevance
        relevance_scores = {}
        for name, data in sources.items():
            # Simple heuristic: keyword overlap
            query_words = set(query.lower().split())
            content = str(data).lower()
            overlap = sum(1 for w in query_words if w in content)
            relevance_scores[name] = max(0.1, overlap / len(query_words))

        return self.allocate(sources, relevance_scores)
```
