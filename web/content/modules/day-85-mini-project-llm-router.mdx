## Project Overview

**Objective**: Build a unified LLM gateway that routes requests to local (Ollama/LMStudio) or cloud (OpenAI/Anthropic) models based on task requirements, cost constraints, and availability.

**Why This Matters**: Relying on a single model provider creates vendor lock-in and single points of failure. A router optimizes for cost and performance while ensuring high availability. Think of it as a smart traffic controller for your AI infrastructure—directing each request to the most appropriate "lane" based on urgency, complexity, and budget.

### Functional Requirements (FR)

| ID    | Requirement            | Description                                                                                                     | Priority |

| FR-01 | Multi-Provider Support | The system shall support OpenAI, Anthropic, Ollama, and LM Studio as LLM providers                              | P0       |
| FR-02 | Unified Chat API       | The system shall expose a single `/llm/chat` endpoint that abstracts provider differences                       | P0       |
| FR-03 | Task-Based Routing     | The system shall route requests to optimal models based on task_type (general, code, reasoning, creative, fast) | P0       |
| FR-04 | Local-First Preference | The system shall prefer local models (Ollama/LM Studio) when `prefer_local=true` and they are healthy           | P1       |
| FR-05 | Cost-Based Filtering   | The system shall filter out models exceeding `max_cost_per_1k` when specified                                   | P1       |
| FR-06 | Automatic Fallback     | The system shall automatically retry with alternative providers when the primary fails                          | P0       |
| FR-07 | Health Monitoring      | The system shall track provider health status and exclude unhealthy providers from routing                      | P1       |
| FR-08 | Usage Statistics       | The system shall track calls, tokens, costs, and latency per model                                              | P2       |

### LLM Router

```python
# services/router.py
from typing import Optional, List, Dict, Any
from config.providers import PROVIDERS, ProviderType, ModelConfig
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from langchain_community.llms import Ollama
import httpx
import asyncio
from datetime import datetime

class LLMRouter:
    """Intelligent LLM routing with fallbacks."""

    def __init__(self):
        self.providers = PROVIDERS
        self.health_status: Dict[str, bool] = {}
        self.usage_stats: Dict[str, Dict] = {}

    async def check_health(self, provider_name: str) -> bool:
        """Check if a provider is healthy."""
        provider = self.providers.get(provider_name)
        if not provider or not provider.enabled:
            return False

        try:
            if provider.type == ProviderType.OLLAMA:
                async with httpx.AsyncClient() as client:
                    resp = await client.get(f"{provider.base_url}/api/tags", timeout=2.0)
                    return resp.status_code == 200

            elif provider.type == ProviderType.LMSTUDIO:
                async with httpx.AsyncClient() as client:
                    resp = await client.get(f"{provider.base_url}/v1/models", timeout=2.0)
                    return resp.status_code == 200

            # Cloud providers - assume healthy if API key exists
            return bool(provider.api_key or True)  # Will fail on actual call if invalid

        except Exception:
            return False

    async def refresh_health(self):
        """Refresh health status for all providers."""
        for name in self.providers:
            self.health_status[name] = await self.check_health(name)

    def select_model(
        self,
        task_type: str = "general",
        prefer_local: bool = True,
        max_cost_per_1k: float = None,
        required_context: int = 4000,
        required_capabilities: List[str] = None
    ) -> Optional[ModelConfig]:
        """Select the best model for the task."""

        candidates = []

        for provider_name, provider in self.providers.items():
            if not provider.enabled:
                continue

            # Check health
            if not self.health_status.get(provider_name, True):
                continue

            for model in provider.models:
                # Check context window
                if model.context_window < required_context:
                    continue

                # Check cost
                if max_cost_per_1k and model.cost_per_1k_input > max_cost_per_1k:
                    continue

                # Check capabilities
                if required_capabilities:
                    if not all(cap in model.capabilities for cap in required_capabilities):
                        continue

                # Calculate score
                score = self._calculate_score(
                    model, provider, task_type, prefer_local
                )

                candidates.append((model, score))

        if not candidates:
            return None

        # Sort by score (higher is better)
        candidates.sort(key=lambda x: x[1], reverse=True)
        return candidates[0][0]

    def _calculate_score(
        self,
        model: ModelConfig,
        provider,
        task_type: str,
        prefer_local: bool
    ) -> float:
        """Calculate model selection score."""
        score = 0.0

        # Local preference
        if prefer_local and provider.type in [ProviderType.OLLAMA, ProviderType.LMSTUDIO]:
            score += 10.0

        # Cost efficiency (inverse of cost)
        if model.cost_per_1k_input == 0:
            score += 5.0
        else:
            score += 1.0 / (model.cost_per_1k_input * 100 + 1)

        # Task-specific scoring
        if task_type == "code" and "code" in model.capabilities:
            score += 3.0
        if task_type == "fast" and "fast" in model.capabilities:
            score += 3.0
        if task_type == "reasoning" and "reasoning" in model.capabilities:
            score += 3.0

        # Provider priority
        score -= provider.priority * 0.5

        return score

    def get_client(self, model: ModelConfig):
        """Get LangChain client for a model."""
        provider = self.providers.get(model.provider.value)

        if model.provider == ProviderType.OPENAI:
            return ChatOpenAI(model=model.name, temperature=0.7)

        elif model.provider == ProviderType.ANTHROPIC:
            return ChatAnthropic(model=model.name, temperature=0.7)

        elif model.provider == ProviderType.OLLAMA:
            return Ollama(
                model=model.name,
                base_url=provider.base_url
            )

        elif model.provider == ProviderType.LMSTUDIO:
            return ChatOpenAI(
                model=model.name,
                base_url=f"{provider.base_url}/v1",
                api_key="not-needed"
            )

        raise ValueError(f"Unknown provider: {model.provider}")

    async def invoke(
        self,
        messages: List[Dict],
        task_type: str = "general",
        prefer_local: bool = True,
        max_cost_per_1k: float = None,
        fallback: bool = True
    ) -> Dict:
        """Invoke LLM with automatic routing and fallback."""

        # Select model
        model = self.select_model(
            task_type=task_type,
            prefer_local=prefer_local,
            max_cost_per_1k=max_cost_per_1k
        )

        if not model:
            raise ValueError("No suitable model available")

        # Try primary model
        try:
            client = self.get_client(model)
            start_time = datetime.now()

            response = await client.ainvoke(messages)

            latency = (datetime.now() - start_time).total_seconds() * 1000

            # Track usage
            self._track_usage(model, len(str(messages)), len(response.content), latency)

            return {
                "content": response.content,
                "model": model.name,
                "provider": model.provider.value,
                "latency_ms": latency
            }

        except Exception as e:
            if not fallback:
                raise

            # Mark provider as unhealthy
            self.health_status[model.provider.value] = False

            # Try fallback
            fallback_model = self.select_model(
                task_type=task_type,
                prefer_local=False  # Try cloud as fallback
            )

            if fallback_model and fallback_model.name != model.name:
                return await self.invoke(
                    messages,
                    task_type=task_type,
                    prefer_local=False,
                    fallback=False
                )

            raise

    def _track_usage(self, model: ModelConfig, input_tokens: int, output_tokens: int, latency: float):
        """Track usage statistics."""
        key = f"{model.provider.value}:{model.name}"

        if key not in self.usage_stats:
            self.usage_stats[key] = {
                "calls": 0,
                "input_tokens": 0,
                "output_tokens": 0,
                "total_cost": 0.0,
                "avg_latency": 0.0
            }

        stats = self.usage_stats[key]
        stats["calls"] += 1
        stats["input_tokens"] += input_tokens
        stats["output_tokens"] += output_tokens
        stats["total_cost"] += (
            (input_tokens / 1000) * model.cost_per_1k_input +
            (output_tokens / 1000) * model.cost_per_1k_output
        )
        stats["avg_latency"] = (
            (stats["avg_latency"] * (stats["calls"] - 1) + latency) / stats["calls"]
        )
```

from fastapi import APIRouter, HTTPException
from pydantic import BaseModel
from typing import List, Dict, Optional
from services.router import LLMRouter

router = APIRouter(prefix="/llm", tags=["llm"])
llm_router = LLMRouter()

class ChatRequest(BaseModel):
    messages: List[Dict[str, str]]
    task_type: str = "general"
    prefer_local: bool = True
    max_cost_per_1k: Optional[float] = None

class ChatResponse(BaseModel):
    content: str
    model: str
    provider: str
    latency_ms: float

@router.post("/chat", response_model=ChatResponse)
async def chat(request: ChatRequest):
    """Send a chat request with automatic routing."""
    try:
        result = await llm_router.invoke(
            messages=request.messages,
            task_type=request.task_type,
            prefer_local=request.prefer_local,
            max_cost_per_1k=request.max_cost_per_1k
        )
        return ChatResponse(**result)
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@router.get("/health")
async def health():
    """Get provider health status."""
    await llm_router.refresh_health()
    return llm_router.health_status

@router.get("/stats")
def stats():
    """Get usage statistics."""
    return llm_router.usage_stats

@router.get("/models")
def list_models():
    """List available models."""
    models = []
    for provider in llm_router.providers.values():
        for model in provider.models:
            models.append({
                "name": model.name,
                "provider": model.provider.value,
                "capabilities": model.capabilities,
                "cost_per_1k_input": model.cost_per_1k_input
            })
    return models

import httpx

class SmartAgent:
    def __init__(self, router_url: str = "http://localhost:8003"):
        self.router_url = router_url

    async def think(self, prompt: str, task_type: str = "reasoning") -> str:
        """
        Send a prompt to the LLM router with automatic model selection.

        The router will:
        1. Classify the task based on task_type
        2. Check provider health status
        3. Apply cost constraints if specified
        4. Select the optimal model using the scoring algorithm
        5. Automatically fallback if the primary model fails
        """
        async with httpx.AsyncClient() as client:
            response = await client.post(
                f"{self.router_url}/llm/chat",
                json={
                    "messages": [{"role": "user", "content": prompt}],
                    "task_type": task_type,
                    "prefer_local": True  # Try local first for cost savings
                }
            )
            result = response.json()
            print(f"Used: {result['provider']}/{result['model']} ({result['latency_ms']:.0f}ms)")
            return result["content"]

# Example usage scenarios
async def main():
    agent = SmartAgent()

    # Simple code task → likely routes to local Ollama

    analysis = await agent.think(
        "Analyze the trade-offs between microservices and monolithic architecture",
        task_type="reasoning"
    )

    # Fast query → routes to fastest available model
    quick = await agent.think("What is 2+2?", task_type="fast")

## Key Takeaways

1. **Vendor Independence**: A router decouples your system from specific provider APIs, giving you flexibility to switch providers or use multiple simultaneously without changing agent code.

2. **Cost Optimization**: Defaulting to free local models for simple tasks can save 80%+ on API bills. Over the 90-day course, this infrastructure enables cost-effective experimentation and learning.

3. **Resiliency**: Systems break. Automatic fallbacks ensure your agents keep running when OpenAI is down or rate-limited. This is critical for production systems built in Month 3.

4. **Observability**: Centralizing LLM calls gives you a single place to track usage and costs across all agents in your ecosystem—essential for the capstone projects ahead.

5. **Smart Routing**: Different tasks need different models. Code generation might work fine on a local 8B model, while complex reasoning benefits from GPT-4 or Claude. The router makes this optimization automatic.
