## The Durability Problem

<Callout type="warning">
  **Critical Production Issue:** 70% of production agent failures stem from lack
  of durable execution. Agents that work perfectly in development fail
  catastrophically when they encounter timeouts, rate limits, or infrastructure
  restarts in production.
</Callout>

<ConceptIntro
  title="Durable Execution"
  analogy="Imagine writing a novel on a computer without auto-save. You write for hours, then the power goes out—all progress lost. Now imagine a system that saves every sentence as you write it, so even after a power outage, you resume exactly where you left off. Durable execution is auto-save for your agent's work."
  technicalDef="Durable execution is a programming model where the runtime automatically persists function state at each step. When failures occur, execution resumes from the last checkpoint rather than restarting from scratch. This is achieved through event sourcing, where all state changes are recorded as a sequence of events that can be replayed."
  whyItMatters="Production agents run for minutes to hours, interact with external APIs, and handle valuable user data. Without durability, a single timeout or crash can waste compute resources, lose user context, and require manual intervention. Durable execution transforms fragile scripts into reliable systems."
/>

### The "Fire and Forget" Anti-Pattern

```python
# ❌ ANTI-PATTERN: Fire and Forget
async def research_agent(query: str) -> str:

    # Step 1: Search (what if this times out?)

    # Step 3: Generate report (what if server restarts here?)

    # If ANY step fails, we lose ALL progress
```

<Callout type="danger">

## 21.1 Checkpoint-Based Recovery

<ConceptIntro
  title="Checkpointing"
  analogy="Video games have save points. When you die, you don't restart the entire game—you resume from your last save. Checkpointing gives your agents the same superpower: save progress at key points, and resume from there after any failure."
  technicalDef="Checkpointing is the practice of periodically saving execution state to durable storage. The checkpoint contains all information needed to resume execution: completed steps, intermediate results, and current position. On recovery, the system loads the latest checkpoint and continues from that point."
  whyItMatters="Checkpointing is the simplest form of durable execution. It doesn't require external infrastructure like Temporal or Inngest—just a database. It's the foundation for understanding more sophisticated durability patterns."
/>

### Complete CheckpointManager Implementation

```python
import json
import sqlite3
import hashlib
from datetime import datetime, timedelta
from typing import Any, Dict, List, Optional, TypeVar, Generic
from dataclasses import dataclass, asdict
from enum import Enum
from pathlib import Path
import asyncio

class CheckpointStatus(Enum):
    """Status of a checkpointed task."""
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    FAILED = "failed"
    CANCELLED = "cancelled"


@dataclass
class Checkpoint:
    """A saved execution state."""
    task_id: str
    step: int
    step_name: str
    status: CheckpointStatus
    data: Dict[str, Any]
    created_at: str
    version: int
    checksum: str

    def to_dict(self) -> Dict[str, Any]:
        """Convert to dictionary for storage."""
        result = asdict(self)
        result["status"] = self.status.value
        return result

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> "Checkpoint":
        """Create from dictionary."""
        data["status"] = CheckpointStatus(data["status"])
        return cls(**data)
```

class CheckpointManager:
"""
Manages checkpoints for durable task execution.

    Features:
    - Save and restore execution state
    - Checkpoint versioning for schema migrations
    - Automatic cleanup of old checkpoints
    - Integrity verification via checksums
    """

    CURRENT_VERSION = 1

    def __init__(
        self,
        db_path: str = "./checkpoints.db",
        max_checkpoints_per_task: int = 10,
        retention_days: int = 7
    ):
        """
        Initialize the checkpoint manager.

        Args:
            db_path: Path to SQLite database
            max_checkpoints_per_task: Maximum checkpoints to keep per task
            retention_days: Days to retain completed task checkpoints
        """
        self.db_path = db_path
        self.max_checkpoints = max_checkpoints_per_task
        self.retention_days = retention_days
        self._init_db()

    def _init_db(self) -> None:
        """Initialize the database schema."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS checkpoints (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    task_id TEXT NOT NULL,
                    step INTEGER NOT NULL,
                    step_name TEXT NOT NULL,
                    status TEXT NOT NULL,
                    data TEXT NOT NULL,
                    created_at TEXT NOT NULL,
                    version INTEGER NOT NULL,
                    checksum TEXT NOT NULL,
                    UNIQUE(task_id, step)
                )
            """)
            conn.execute("""
                CREATE INDEX IF NOT EXISTS idx_task_id
                ON checkpoints(task_id)
            """)
            conn.execute("""
                CREATE INDEX IF NOT EXISTS idx_created_at
                ON checkpoints(created_at)
            """)
            conn.commit()

    def _compute_checksum(self, data: Dict[str, Any]) -> str:
        """Compute checksum for data integrity verification."""
        json_str = json.dumps(data, sort_keys=True)
        return hashlib.sha256(json_str.encode()).hexdigest()[:16]

    def save(
        self,
        task_id: str,
        step: int,
        step_name: str,
        data: Dict[str, Any],
        status: CheckpointStatus = CheckpointStatus.IN_PROGRESS
    ) -> Checkpoint:
        """
        Save a checkpoint.

        Args:
            task_id: Unique identifier for the task
            step: Step number (0-indexed)
            step_name: Human-readable step name
            data: State data to persist
            status: Current task status

        Returns:
            The saved checkpoint
        """
        checksum = self._compute_checksum(data)
        checkpoint = Checkpoint(
            task_id=task_id,
            step=step,
            step_name=step_name,
            status=status,
            data=data,
            created_at=datetime.utcnow().isoformat(),
            version=self.CURRENT_VERSION,
            checksum=checksum
        )

        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                INSERT OR REPLACE INTO checkpoints
                (task_id, step, step_name, status, data, created_at, version, checksum)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                checkpoint.task_id,
                checkpoint.step,
                checkpoint.step_name,
                checkpoint.status.value,
                json.dumps(checkpoint.data),
                checkpoint.created_at,
                checkpoint.version,
                checkpoint.checksum
            ))
            conn.commit()

        # Cleanup old checkpoints for this task
        self._cleanup_task_checkpoints(task_id)

        return checkpoint


    def load_latest(self, task_id: str) -> Optional[Checkpoint]:
        """
        Load the latest checkpoint for a task.

        Args:
            task_id: The task identifier

        Returns:
            The latest checkpoint, or None if no checkpoints exist
        """
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute("""
                SELECT * FROM checkpoints
                WHERE task_id = ?
                ORDER BY step DESC
                LIMIT 1
            """, (task_id,))
            row = cursor.fetchone()

            if row is None:
                return None

            checkpoint = Checkpoint(
                task_id=row["task_id"],
                step=row["step"],
                step_name=row["step_name"],
                status=CheckpointStatus(row["status"]),
                data=json.loads(row["data"]),
                created_at=row["created_at"],
                version=row["version"],
                checksum=row["checksum"]
            )

            # Verify integrity
            if not self._verify_checksum(checkpoint):
                raise ValueError(f"Checkpoint integrity check failed for {task_id}")

            return checkpoint

    def _verify_checksum(self, checkpoint: Checkpoint) -> bool:
        """Verify checkpoint data integrity."""
        computed = self._compute_checksum(checkpoint.data)
        return computed == checkpoint.checksum

    def load_all(self, task_id: str) -> List[Checkpoint]:
        """Load all checkpoints for a task, ordered by step."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute("""
                SELECT * FROM checkpoints
                WHERE task_id = ?
                ORDER BY step ASC
            """, (task_id,))

            checkpoints = []
            for row in cursor.fetchall():
                checkpoints.append(Checkpoint(
                    task_id=row["task_id"],
                    step=row["step"],
                    step_name=row["step_name"],
                    status=CheckpointStatus(row["status"]),
                    data=json.loads(row["data"]),
                    created_at=row["created_at"],
                    version=row["version"],
                    checksum=row["checksum"]
                ))

            return checkpoints

    def mark_completed(self, task_id: str, final_result: Any = None) -> None:
        """Mark a task as completed."""
        checkpoint = self.load_latest(task_id)
        if checkpoint:
            data = checkpoint.data.copy()
            if final_result is not None:
                data["final_result"] = final_result
            self.save(
                task_id=task_id,
                step=checkpoint.step,
                step_name=checkpoint.step_name,
                data=data,
                status=CheckpointStatus.COMPLETED
            )

    def mark_failed(self, task_id: str, error: str) -> None:
        """Mark a task as failed."""
        checkpoint = self.load_latest(task_id)
        if checkpoint:
            data = checkpoint.data.copy()
            data["error"] = error
            self.save(
                task_id=task_id,
                step=checkpoint.step,
                step_name=checkpoint.step_name,
                data=data,
                status=CheckpointStatus.FAILED
            )


    def _cleanup_task_checkpoints(self, task_id: str) -> None:
        """Remove old checkpoints exceeding the limit."""
        with sqlite3.connect(self.db_path) as conn:
            # Keep only the most recent N checkpoints
            conn.execute("""
                DELETE FROM checkpoints
                WHERE task_id = ?
                AND id NOT IN (
                    SELECT id FROM checkpoints
                    WHERE task_id = ?
                    ORDER BY step DESC
                    LIMIT ?
                )
            """, (task_id, task_id, self.max_checkpoints))
            conn.commit()

    def cleanup_old_checkpoints(self) -> int:
        """
        Remove checkpoints older than retention period.

        Returns:
            Number of checkpoints deleted
        """
        cutoff = (datetime.utcnow() - timedelta(days=self.retention_days)).isoformat()

        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.execute("""
                DELETE FROM checkpoints
                WHERE created_at < ?
                AND status IN (?, ?)
            """, (cutoff, CheckpointStatus.COMPLETED.value, CheckpointStatus.FAILED.value))
            deleted = cursor.rowcount
            conn.commit()

        return deleted

    def get_pending_tasks(self) -> List[str]:
        """Get all tasks that are in progress (for recovery on startup)."""
        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.execute("""
                SELECT DISTINCT task_id FROM checkpoints
                WHERE status = ?
            """, (CheckpointStatus.IN_PROGRESS.value,))
            return [row[0] for row in cursor.fetchall()]

````

import uuid
from typing import Callable, List, Tuple

class DurableAgent:
    """An agent with checkpoint-based recovery."""

    def __init__(self, checkpoint_manager: CheckpointManager):
        self.checkpoints = checkpoint_manager
        self.steps: List[Tuple[str, Callable]] = []

    def add_step(self, name: str, func: Callable) -> "DurableAgent":
        """Add a step to the agent pipeline."""
        self.steps.append((name, func))
        return self

    async def run(self, task_id: Optional[str] = None, initial_data: Dict[str, Any] = None) -> Any:
        """
        Run the agent with checkpoint recovery.

        Args:
            task_id: Optional task ID (generated if not provided)
            initial_data: Initial data for the task

        Returns:
            Final result from the last step
        """
        task_id = task_id or str(uuid.uuid4())

        # Try to resume from checkpoint
        checkpoint = self.checkpoints.load_latest(task_id)

        if checkpoint and checkpoint.status == CheckpointStatus.COMPLETED:
            return checkpoint.data.get("final_result")

        # Determine starting point
        start_step = 0
        data = initial_data or {}

        if checkpoint:
            start_step = checkpoint.step + 1
            data = checkpoint.data.copy()
            print(f"Resuming task {task_id} from step {start_step}: {self.steps[start_step][0]}")
        else:
            print(f"Starting new task {task_id}")
            # Save initial checkpoint
            self.checkpoints.save(
                task_id=task_id,
                step=-1,
                step_name="initialized",
                data=data,
                status=CheckpointStatus.PENDING
            )
````

        # Execute remaining steps
        try:
            for i in range(start_step, len(self.steps)):
                step_name, step_func = self.steps[i]
                print(f"Executing step {i}: {step_name}")

                # Execute the step
                result = await step_func(data)
                data[f"step_{i}_result"] = result

                # Save checkpoint after each step
                self.checkpoints.save(

                    step=i,
                    step_name=step_name,

            self.checkpoints.mark_failed(task_id, str(e))

        self._progress = "generating report"

        # Step 4: Generate final report
        report = await workflow.execute_activity(
            generate_report,
            args=[request.query, analysis],
            start_to_close_timeout=timedelta(minutes=10),
            retry_policy=retry_policy,
        )

        self._progress = "completed"

        return ResearchResult(
            query=request.query,
            sources_found=len(search_results),
            report=report,
            approved=True
        )

    @workflow.signal
    async def approve(self) -> None:
        """Signal to approve the research."""
        self._approved = True

    @workflow.signal
    async def cancel(self) -> None:
        """Signal to cancel the research."""
        self._cancelled = True

    @workflow.query
    def get_progress(self) -> str:
        """Query the current progress."""
        return self._progress

```python
async def research_workflow(
    ctx: inngest.Context,
    step: inngest.Step,
) -> Dict[str, Any]:
    """
    Durable research workflow using Inngest step functions.

    Each step.run() call is automatically checkpointed.
    If the function fails, it resumes from the last successful step.
    """

    event_data = ctx.event.data
    query = event_data.get("query", "")
    user_id = event_data.get("user_id", "")

    # Step 1: Search (automatically retried on failure)
    search_results = await step.run(
        "search-web",
        lambda: search_web(query)
    )

    # Step 2: Analyze results
    analysis = await step.run(
        "analyze-results",
        lambda: analyze_with_llm(search_results)
    )

    # Step 3: Wait for approval (if required)
    if event_data.get("require_approval", False):
        # Send notification
        await step.run(
            "send-notification",
            lambda: send_approval_request(user_id, analysis)
        )

        # Wait for approval event (up to 24 hours)
        approval_event = await step.wait_for_event(
            "wait-for-approval",
            event=f"research/approved",
            match="data.workflow_id",
            timeout="24h"
        )

        if approval_event is None:
            return {"status": "timeout", "message": "Approval timeout"}

        if not approval_event.data.get("approved", False):
            return {"status": "rejected", "message": "Research rejected"}

    # Step 4: Generate final report
    report = await step.run(
        "generate-report",
        lambda: generate_report(query, analysis)
    )

    # Step 5: Send completion notification
    await step.run(
        "notify-completion",
        lambda: send_completion_notification(user_id, report)
    )

    return {
        "status": "completed",
        "query": query,
        "sources": len(search_results),
        "report": report
    }
```

class HITLManager:
"""
Manages Human-in-the-Loop approvals with durable state.

    Features:
    - Persistent approval requests
    - Multiple notification channels
    - Timeout handling
    - Webhook-based approval/rejection
    - Workflow resumption callbacks
    """

    def __init__(
        self,
        db_path: str = "./hitl.db",
        default_timeout_hours: int = 24
    ):
        self.db_path = db_path
        self.default_timeout = timedelta(hours=default_timeout_hours)
        self.notifiers: list[NotificationChannel] = []
        self.resume_callbacks: Dict[str, Callable[[ApprovalRequest], Awaitable[None]]] = {}
        self._init_db()

    def _init_db(self) -> None:
        """Initialize the database schema."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS approval_requests (
                    id TEXT PRIMARY KEY,
                    workflow_id TEXT NOT NULL,
                    user_id TEXT NOT NULL,
                    title TEXT NOT NULL,
                    description TEXT NOT NULL,
                    context TEXT NOT NULL,
                    status TEXT NOT NULL,
                    created_at TEXT NOT NULL,
                    expires_at TEXT NOT NULL,
                    decided_at TEXT,
                    decided_by TEXT,
                    decision_reason TEXT
                )
            """)
            conn.execute("""
                CREATE INDEX IF NOT EXISTS idx_workflow_id
                ON approval_requests(workflow_id)
            """)
            conn.execute("""
                CREATE INDEX IF NOT EXISTS idx_status
                ON approval_requests(status)
            """)
            conn.commit()

    def add_notifier(self, notifier: NotificationChannel) -> None:
        """Add a notification channel."""
        self.notifiers.append(notifier)

    def register_resume_callback(
        self,
        workflow_id: str,
        callback: Callable[[ApprovalRequest], Awaitable[None]]
    ) -> None:
        """Register a callback to resume workflow after approval."""
        self.resume_callbacks[workflow_id] = callback

    async def request_approval(
        self,
        workflow_id: str,
        user_id: str,
        title: str,
        description: str,
        context: Dict[str, Any],
        timeout: Optional[timedelta] = None
    ) -> ApprovalRequest:
        """
        Create an approval request and notify the user.

        Args:
            workflow_id: ID of the workflow requesting approval
            user_id: User who should approve
            title: Short title for the request
            description: Detailed description
            context: Additional context data
            timeout: How long to wait for approval

        Returns:
            The created approval request
        """
        timeout = timeout or self.default_timeout
        now = datetime.utcnow()

        request = ApprovalRequest(
            id=str(uuid.uuid4()),
            workflow_id=workflow_id,
            user_id=user_id,
            title=title,
            description=description,
            context=context,
            status=ApprovalStatus.PENDING,
            created_at=now.isoformat(),
            expires_at=(now + timeout).isoformat()
        )

        # Save to database
        self._save_request(request)

        # Send notifications
        for notifier in self.notifiers:
            try:
                await notifier.send(user_id, request)
            except Exception as e:
                print(f"Failed to send notification: {e}")

        return request


    def _save_request(self, request: ApprovalRequest) -> None:
        """Save approval request to database."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                INSERT OR REPLACE INTO approval_requests
                (id, workflow_id, user_id, title, description, context,
                 status, created_at, expires_at, decided_at, decided_by, decision_reason)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                request.id,
                request.workflow_id,
                request.user_id,
                request.title,
                request.description,
                json.dumps(request.context),
                request.status.value,
                request.created_at,
                request.expires_at,
                request.decided_at,
                request.decided_by,
                request.decision_reason
            ))
            conn.commit()

    def get_request(self, request_id: str) -> Optional[ApprovalRequest]:
        """Get an approval request by ID."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute(
                "SELECT * FROM approval_requests WHERE id = ?",
                (request_id,)
            )
            row = cursor.fetchone()

            if row is None:
                return None

            return ApprovalRequest(
                id=row["id"],
                workflow_id=row["workflow_id"],
                user_id=row["user_id"],
                title=row["title"],
                description=row["description"],
                context=json.loads(row["context"]),
                status=ApprovalStatus(row["status"]),
                created_at=row["created_at"],
                expires_at=row["expires_at"],
                decided_at=row["decided_at"],
                decided_by=row["decided_by"],
                decision_reason=row["decision_reason"]
            )

    async def process_decision(
        self,
        request_id: str,
        approved: bool,
        decided_by: str,
        reason: Optional[str] = None
    ) -> ApprovalRequest:
        """
        Process an approval decision.

        Args:
            request_id: The approval request ID
            approved: Whether the request was approved
            decided_by: Who made the decision
            reason: Optional reason for the decision

        Returns:
            The updated approval request
        """
        request = self.get_request(request_id)

        if request is None:
            raise ValueError(f"Approval request {request_id} not found")

        if request.status != ApprovalStatus.PENDING:
            raise ValueError(f"Request {request_id} already processed: {request.status}")

        # Check for timeout
        if datetime.fromisoformat(request.expires_at) < datetime.utcnow():
            request.status = ApprovalStatus.TIMEOUT
            self._save_request(request)
            raise ValueError(f"Request {request_id} has expired")

        # Update request
        request.status = ApprovalStatus.APPROVED if approved else ApprovalStatus.REJECTED
        request.decided_at = datetime.utcnow().isoformat()
        request.decided_by = decided_by
        request.decision_reason = reason

        self._save_request(request)

        # Trigger resume callback if registered
        if request.workflow_id in self.resume_callbacks:
            callback = self.resume_callbacks[request.workflow_id]
            await callback(request)

        return request

    def get_pending_requests(self, user_id: Optional[str] = None) -> list[ApprovalRequest]:
        """Get all pending approval requests."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row

            if user_id:
                cursor = conn.execute(
                    "SELECT * FROM approval_requests WHERE status = ? AND user_id = ?",
                    (ApprovalStatus.PENDING.value, user_id)
                )
            else:
                cursor = conn.execute(
                    "SELECT * FROM approval_requests WHERE status = ?",
                    (ApprovalStatus.PENDING.value,)
                )

            requests = []
            for row in cursor.fetchall():
                requests.append(ApprovalRequest(
                    id=row["id"],
                    workflow_id=row["workflow_id"],
                    user_id=row["user_id"],
                    title=row["title"],
                    description=row["description"],
                    context=json.loads(row["context"]),
                    status=ApprovalStatus(row["status"]),
                    created_at=row["created_at"],
                    expires_at=row["expires_at"],
                    decided_at=row["decided_at"],
                    decided_by=row["decided_by"],
                    decision_reason=row["decision_reason"]
                ))

            return requests

    async def check_timeouts(self) -> int:
        """Check and mark timed-out requests. Returns count of timed-out requests."""
        now = datetime.utcnow().isoformat()

        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.execute("""
                UPDATE approval_requests
                SET status = ?, decided_at = ?
                WHERE status = ? AND expires_at < ?
            """, (ApprovalStatus.TIMEOUT.value, now, ApprovalStatus.PENDING.value, now))

            count = cursor.rowcount
            conn.commit()

        return count

```python
import json

import uuid
import asyncio
from datetime import datetime
from typing import Any, Dict, Optional, Callable, Awaitable, List
from dataclasses import dataclass, asdict, field
from enum import Enum
from contextlib import asynccontextmanager


class TaskStatus(Enum):
    """Status of a long-running task."""
    QUEUED = "queued"
    RUNNING = "running"
    PAUSED = "paused"
    COMPLETED = "completed"
    FAILED = "failed"
    CANCELLED = "cancelled"


@dataclass
class TaskProgress:
    """Progress information for a task."""
    current_step: int
    total_steps: int
    step_name: str
    percentage: float
    message: str
    updated_at: str


@dataclass
class DurableTask:
    """A long-running task with durable state."""
    id: str
    name: str
    status: TaskStatus
    input_data: Dict[str, Any]
    output_data: Optional[Dict[str, Any]]
    progress: Optional[TaskProgress]
    error: Optional[str]
    created_at: str
    started_at: Optional[str]
    completed_at: Optional[str]
    retry_count: int = 0
    max_retries: int = 3
    metadata: Dict[str, Any] = field(default_factory=dict)


class DurableTaskManager:
    """
    Manages long-running tasks with progress tracking and graceful cancellation.

    Features:
    - Persistent task state
    - Progress tracking and reporting
    - Graceful pause/resume/cancel
    - Automatic retries with backoff
    - Task queuing and prioritization
    """

    def __init__(self, db_path: str = "./tasks.db"):
        self.db_path = db_path
        self._init_db()
        self._task_handlers: Dict[str, Callable] = {}
        self._running_tasks: Dict[str, asyncio.Task] = {}
        self._cancel_flags: Dict[str, asyncio.Event] = {}
        self._pause_flags: Dict[str, asyncio.Event] = {}

    def _init_db(self) -> None:

                    id TEXT PRIMARY KEY,
                    name TEXT NOT NULL,
                    status TEXT NOT NULL,
                    input_data TEXT NOT NULL,
                    output_data TEXT,
                    progress TEXT,
                    error TEXT,

    def register_handler(
        self,
```

    def _save_task(self, task: DurableTask) -> None:
        """Save task to database."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                INSERT OR REPLACE INTO tasks
                (id, name, status, input_data, output_data, progress, error,
                 created_at, started_at, completed_at, retry_count, max_retries, metadata)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                task.id,
                task.name,
                task.status.value,
                json.dumps(task.input_data),
                json.dumps(task.output_data) if task.output_data else None,
                json.dumps(asdict(task.progress)) if task.progress else None,
                task.error,
                task.created_at,
                task.started_at,
                task.completed_at,
                task.retry_count,
                task.max_retries,
                json.dumps(task.metadata)
            ))
            conn.commit()

    def get_task(self, task_id: str) -> Optional[DurableTask]:
        """Get a task by ID."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute("SELECT * FROM tasks WHERE id = ?", (task_id,))
            row = cursor.fetchone()

            if row is None:
                return None

            progress = None
            if row["progress"]:
                progress_data = json.loads(row["progress"])
                progress = TaskProgress(**progress_data)

            return DurableTask(
                id=row["id"],
                name=row["name"],
                status=TaskStatus(row["status"]),
                input_data=json.loads(row["input_data"]),
                output_data=json.loads(row["output_data"]) if row["output_data"] else None,
                progress=progress,
                error=row["error"],
                created_at=row["created_at"],
                started_at=row["started_at"],
                completed_at=row["completed_at"],
                retry_count=row["retry_count"],
                max_retries=row["max_retries"],
                metadata=json.loads(row["metadata"])
            )

    async def start(self, task_id: str) -> DurableTask:
        """Start executing a queued task."""
        task = self.get_task(task_id)

        if task is None:
            raise ValueError(f"Task {task_id} not found")

        if task.status not in (TaskStatus.QUEUED, TaskStatus.PAUSED):
            raise ValueError(f"Task {task_id} cannot be started: {task.status}")

        # Set up control flags
        self._cancel_flags[task_id] = asyncio.Event()
        self._pause_flags[task_id] = asyncio.Event()

        # Update status
        task.status = TaskStatus.RUNNING
        task.started_at = datetime.utcnow().isoformat()
        self._save_task(task)

        # Create task context
        context = TaskContext(
            task_id=task_id,
            manager=self,
            cancel_flag=self._cancel_flags[task_id],
            pause_flag=self._pause_flags[task_id]
        )

        # Start execution in background
        handler = self._task_handlers[task.name]
        self._running_tasks[task_id] = asyncio.create_task(
            self._execute_task(task, handler, context)
        )

        return task

    async def _execute_task(
        self,
        task: DurableTask,
        handler: Callable,
        context: "TaskContext"
    ) -> None:
        """Execute a task with error handling and retries."""
        try:
            result = await handler(task, context)

            task.status = TaskStatus.COMPLETED
            task.output_data = result
            task.completed_at = datetime.utcnow().isoformat()

        except asyncio.CancelledError:
            task.status = TaskStatus.CANCELLED
            task.completed_at = datetime.utcnow().isoformat()

        except Exception as e:
            task.retry_count += 1

            if task.retry_count < task.max_retries:
                # Schedule retry with exponential backoff
                delay = 2 ** task.retry_count
                task.status = TaskStatus.QUEUED
                task.error = f"Retry {task.retry_count}/{task.max_retries}: {str(e)}"
                self._save_task(task)

                await asyncio.sleep(delay)
                await self.start(task.id)
                return
            else:
                task.status = TaskStatus.FAILED
                task.error = str(e)
                task.completed_at = datetime.utcnow().isoformat()

        finally:
            self._save_task(task)
            # Cleanup
            self._running_tasks.pop(task.id, None)
            self._cancel_flags.pop(task.id, None)
            self._pause_flags.pop(task.id, None)


    async def cancel(self, task_id: str) -> DurableTask:
        """Request cancellation of a running task."""
        task = self.get_task(task_id)

        if task is None:
            raise ValueError(f"Task {task_id} not found")

        if task.status == TaskStatus.RUNNING:
            # Signal cancellation
            if task_id in self._cancel_flags:
                self._cancel_flags[task_id].set()

            # Cancel the asyncio task
            if task_id in self._running_tasks:
                self._running_tasks[task_id].cancel()

        elif task.status in (TaskStatus.QUEUED, TaskStatus.PAUSED):
            task.status = TaskStatus.CANCELLED
            task.completed_at = datetime.utcnow().isoformat()
            self._save_task(task)

        return self.get_task(task_id) or task

    async def pause(self, task_id: str) -> DurableTask:
        """Request pause of a running task."""
        task = self.get_task(task_id)

        if task is None:
            raise ValueError(f"Task {task_id} not found")

        if task.status != TaskStatus.RUNNING:
            raise ValueError(f"Task {task_id} is not running")

        if task_id in self._pause_flags:
            self._pause_flags[task_id].set()

        return task

    async def resume(self, task_id: str) -> DurableTask:
        """Resume a paused task."""
        task = self.get_task(task_id)

        if task is None:
            raise ValueError(f"Task {task_id} not found")

        if task.status != TaskStatus.PAUSED:
            raise ValueError(f"Task {task_id} is not paused")

        return await self.start(task_id)

    def get_tasks_by_status(self, status: TaskStatus) -> List[DurableTask]:
        """Get all tasks with a specific status."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute(
                "SELECT * FROM tasks WHERE status = ? ORDER BY created_at DESC",

            tasks = []
            for row in cursor.fetchall():

                    progress=progress,
                    error=row["error"],
                    created_at=row["created_at"],
                    started_at=row["started_at"],
                    completed_at=row["completed_at"],
                    retry_count=row["retry_count"],
                    max_retries=row["max_retries"],

                ))

            return tasks

class TaskContext:
"""Context provided to task handlers for progress reporting and control."""

    def __init__(
        self,
        task_id: str,
        manager: DurableTaskManager,
        cancel_flag: asyncio.Event,
        pause_flag: asyncio.Event
    ):
        self.task_id = task_id
        self._manager = manager
        self._cancel_flag = cancel_flag
        self._pause_flag = pause_flag

    async def update_progress(
        self,
        current_step: int,
        total_steps: int,
        step_name: str,
        message: str = ""
    ) -> None:
        """Update task progress."""
        task = self._manager.get_task(self.task_id)
        if task is None:
            return

        task.progress = TaskProgress(
            current_step=current_step,
            total_steps=total_steps,
            step_name=step_name,
            percentage=(current_step / total_steps) * 100 if total_steps > 0 else 0,
            message=message,
            updated_at=datetime.utcnow().isoformat()
        )
        self._manager._save_task(task)

    async def check_cancellation(self) -> bool:
        """Check if cancellation was requested."""
        return self._cancel_flag.is_set()

    async def check_pause(self) -> None:
        """Check and handle pause requests."""
        if self._pause_flag.is_set():
            task = self._manager.get_task(self.task_id)
            if task:
                task.status = TaskStatus.PAUSED
                self._manager._save_task(task)

            # Wait until resumed (flag cleared) or cancelled
            while self._pause_flag.is_set() and not self._cancel_flag.is_set():
                await asyncio.sleep(1)

            self._pause_flag.clear()

    @asynccontextmanager
    async def step(self, step_num: int, total: int, name: str):
        """Context manager for a task step with automatic progress updates."""
        await self.update_progress(step_num, total, name, f"Starting {name}")
        await self.check_pause()

        if await self.check_cancellation():
            raise asyncio.CancelledError()

        try:
            yield
        finally:
            await self.update_progress(step_num, total, name, f"Completed {name}")

```python
# idempotency.py - Idempotency key management
import json
import sqlite3
import hashlib
from datetime import datetime, timedelta
from typing import Any, Optional, Callable, TypeVar, Generic
from dataclasses import dataclass
from functools import wraps

T = TypeVar('T')


@dataclass
class IdempotencyRecord:
    """Record of an idempotent operation."""
    key: str
    result: Any
    created_at: str
    expires_at: str


class IdempotencyStore:
    """
    Store for idempotency keys and results.

    Ensures operations are executed exactly once, even with retries.
    """

    def __init__(self, db_path: str = "./idempotency.db", ttl_hours: int = 24):
        self.db_path = db_path
        self.ttl = timedelta(hours=ttl_hours)
        self._init_db()

    def _init_db(self) -> None:
        """Initialize the database schema."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS idempotency_keys (
                    key TEXT PRIMARY KEY,
                    result TEXT NOT NULL,
                    created_at TEXT NOT NULL,
                    expires_at TEXT NOT NULL
                )
            """)
            conn.execute("""
                CREATE INDEX IF NOT EXISTS idx_expires_at
                ON idempotency_keys(expires_at)
            """)
            conn.commit()

    def get(self, key: str) -> Optional[IdempotencyRecord]:
        """Get a stored result by idempotency key."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute(
                "SELECT * FROM idempotency_keys WHERE key = ?",
                (key,)
            )
            row = cursor.fetchone()

            if row is None:
                return None

            # Check expiration
            if datetime.fromisoformat(row["expires_at"]) < datetime.utcnow():
                self.delete(key)
                return None

            return IdempotencyRecord(
                key=row["key"],
                result=json.loads(row["result"]),
                created_at=row["created_at"],
                expires_at=row["expires_at"]
            )

    def set(self, key: str, result: Any) -> IdempotencyRecord:
        """Store a result with an idempotency key."""
        now = datetime.utcnow()
        record = IdempotencyRecord(
            key=key,
            result=result,
            created_at=now.isoformat(),
            expires_at=(now + self.ttl).isoformat()
        )

        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                INSERT OR REPLACE INTO idempotency_keys
                (key, result, created_at, expires_at)
                VALUES (?, ?, ?, ?)
            """, (
                record.key,
                json.dumps(record.result),
                record.created_at,
                record.expires_at
            ))
            conn.commit()

        return record

    def delete(self, key: str) -> None:
        """Delete an idempotency key."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("DELETE FROM idempotency_keys WHERE key = ?", (key,))
            conn.commit()

    def cleanup_expired(self) -> int:
        """Remove expired keys. Returns count of deleted keys."""
        now = datetime.utcnow().isoformat()
        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.execute(
                "DELETE FROM idempotency_keys WHERE expires_at < ?",
                (now,)
            )
            count = cursor.rowcount
            conn.commit()
        return count


def idempotent(store: IdempotencyStore, key_func: Callable[..., str]):
    """
    Decorator to make a function idempotent.

    Args:
        store: IdempotencyStore instance
        key_func: Function to generate idempotency key from arguments
    """
    def decorator(func: Callable[..., T]) -> Callable[..., T]:
        @wraps(func)
        async def wrapper(*args, **kwargs) -> T:
            # Generate idempotency key
            key = key_func(*args, **kwargs)

            # Check for existing result
            record = store.get(key)
            if record is not None:
                return record.result

            # Execute function
            result = await func(*args, **kwargs)

            # Store result
            store.set(key, result)

            return result

        return wrapper
    return decorator
```

### Dead Letter Queue (DLQ)

When tasks fail after all retries, they shouldn't disappear. A Dead Letter Queue captures failed tasks for manual review and recovery.

```python
# dlq.py - Dead Letter Queue implementation
import json
import sqlite3
from datetime import datetime
from typing import Any, Dict, List, Optional
from dataclasses import dataclass
from enum import Enum


class DLQStatus(Enum):
    """Status of a DLQ entry."""
    PENDING = "pending"      # Awaiting review
    RETRYING = "retrying"    # Being retried
    RESOLVED = "resolved"    # Successfully resolved
    DISCARDED = "discarded"  # Manually discarded


@dataclass
class DLQEntry:
    """An entry in the Dead Letter Queue."""
    id: str
    task_type: str
    task_id: str
    payload: Dict[str, Any]
    error: str
    retry_count: int
    status: DLQStatus
    created_at: str
    resolved_at: Optional[str] = None
    resolution_notes: Optional[str] = None


class DeadLetterQueue:
    """
    Dead Letter Queue for failed tasks.

    Captures tasks that failed after all retry attempts,
    enabling manual review and recovery.
    """

    def __init__(self, db_path: str = "./dlq.db"):
        self.db_path = db_path
        self._init_db()

    def _init_db(self) -> None:
        """Initialize the database schema."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS dlq_entries (
                    id TEXT PRIMARY KEY,
                    task_type TEXT NOT NULL,
                    task_id TEXT NOT NULL,
                    payload TEXT NOT NULL,
                    error TEXT NOT NULL,
                    retry_count INTEGER NOT NULL,
                    status TEXT NOT NULL,
                    created_at TEXT NOT NULL,
                    resolved_at TEXT,
                    resolution_notes TEXT
                )
            """)
            conn.execute("CREATE INDEX IF NOT EXISTS idx_status ON dlq_entries(status)")
            conn.execute("CREATE INDEX IF NOT EXISTS idx_task_type ON dlq_entries(task_type)")
            conn.commit()

    def add(
        self,
        task_type: str,
        task_id: str,
        payload: Dict[str, Any],
        error: str,
        retry_count: int
    ) -> DLQEntry:
        """Add a failed task to the DLQ."""
        import uuid

        entry = DLQEntry(
            id=str(uuid.uuid4()),
            task_type=task_type,
            task_id=task_id,
            payload=payload,
            error=error,
            retry_count=retry_count,
            status=DLQStatus.PENDING,
            created_at=datetime.utcnow().isoformat()
        )

        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                INSERT INTO dlq_entries
                (id, task_type, task_id, payload, error, retry_count, status, created_at)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                entry.id,
                entry.task_type,
                entry.task_id,
                json.dumps(entry.payload),
                entry.error,
                entry.retry_count,
                entry.status.value,
                entry.created_at
            ))
            conn.commit()

        return entry

    def get_pending(self, task_type: Optional[str] = None) -> List[DLQEntry]:
        """Get all pending DLQ entries."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row

            if task_type:
                cursor = conn.execute(
                    "SELECT * FROM dlq_entries WHERE status = ? AND task_type = ?",
                    (DLQStatus.PENDING.value, task_type)
                )
            else:
                cursor = conn.execute(
                    "SELECT * FROM dlq_entries WHERE status = ?",
                    (DLQStatus.PENDING.value,)
                )

            return [self._row_to_entry(row) for row in cursor.fetchall()]

    def _row_to_entry(self, row: sqlite3.Row) -> DLQEntry:
        """Convert a database row to a DLQEntry."""
        return DLQEntry(
            id=row["id"],
            task_type=row["task_type"],
            task_id=row["task_id"],
            payload=json.loads(row["payload"]),
            error=row["error"],
            retry_count=row["retry_count"],
            status=DLQStatus(row["status"]),
            created_at=row["created_at"],
            resolved_at=row["resolved_at"],
            resolution_notes=row["resolution_notes"]
        )

    def retry(self, entry_id: str) -> DLQEntry:
        """Mark an entry for retry."""
        return self._update_status(entry_id, DLQStatus.RETRYING)

    def resolve(self, entry_id: str, notes: str = "") -> DLQEntry:
        """Mark an entry as resolved."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                UPDATE dlq_entries
                SET status = ?, resolved_at = ?, resolution_notes = ?
                WHERE id = ?
            """, (
                DLQStatus.RESOLVED.value,
                datetime.utcnow().isoformat(),
                notes,
                entry_id
            ))
            conn.commit()

        return self.get(entry_id)

    def discard(self, entry_id: str, reason: str = "") -> DLQEntry:
        """Discard an entry (won't be retried)."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("""
                UPDATE dlq_entries
                SET status = ?, resolved_at = ?, resolution_notes = ?
                WHERE id = ?
            """, (
                DLQStatus.DISCARDED.value,
                datetime.utcnow().isoformat(),
                reason,
                entry_id
            ))
            conn.commit()

        return self.get(entry_id)

    def _update_status(self, entry_id: str, status: DLQStatus) -> DLQEntry:
        """Update entry status."""
        with sqlite3.connect(self.db_path) as conn:
            conn.execute(
                "UPDATE dlq_entries SET status = ? WHERE id = ?",
                (status.value, entry_id)
            )
            conn.commit()

        return self.get(entry_id)

    def get(self, entry_id: str) -> Optional[DLQEntry]:
        """Get a DLQ entry by ID."""
        with sqlite3.connect(self.db_path) as conn:
            conn.row_factory = sqlite3.Row
            cursor = conn.execute(
                "SELECT * FROM dlq_entries WHERE id = ?",
                (entry_id,)
            )
            row = cursor.fetchone()
            return self._row_to_entry(row) if row else None

    def get_stats(self) -> Dict[str, int]:
        """Get DLQ statistics."""
        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.execute("""
                SELECT status, COUNT(*) as count
                FROM dlq_entries
                GROUP BY status
            """)
            return {row[0]: row[1] for row in cursor.fetchall()}
```

```python
class TaskMetrics:
    """Metrics for task execution."""
    total_tasks: int
    running_tasks: int
    completed_tasks: int
    failed_tasks: int
    avg_duration_seconds: float
    success_rate: float
    dlq_size: int

class TaskMonitor:
    """
    Monitors task execution and generates alerts.

    Tracks:
    - Task success/failure rates
    - Execution duration
    - Queue depths
    - DLQ growth
    """

    def __init__(
        self,
        task_manager: "DurableTaskManager",
        dlq: "DeadLetterQueue",
        hitl_manager: "HITLManager"
    ):
        self.task_manager = task_manager
        self.dlq = dlq
        self.hitl_manager = hitl_manager
        self.alert_handlers: List[Callable[[Alert], None]] = []
        self._thresholds = {
            "failure_rate": 0.1,      # Alert if > 10% failure rate
            "dlq_size": 10,           # Alert if DLQ > 10 entries
            "pending_approvals": 50,  # Alert if > 50 pending approvals
            "avg_duration": 300,      # Alert if avg duration > 5 minutes
        }

    def set_threshold(self, metric: str, value: float) -> None:
        """Set an alert threshold."""
        self._thresholds[metric] = value

    def add_alert_handler(self, handler: Callable[[Alert], None]) -> None:
        """Add a handler for alerts (e.g., send to Slack, PagerDuty)."""
        self.alert_handlers.append(handler)

    def collect_metrics(self) -> TaskMetrics:
        """Collect current task metrics."""
        # Get task counts by status
        running = len(self.task_manager.get_tasks_by_status(TaskStatus.RUNNING))
        completed = len(self.task_manager.get_tasks_by_status(TaskStatus.COMPLETED))
        failed = len(self.task_manager.get_tasks_by_status(TaskStatus.FAILED))
        queued = len(self.task_manager.get_tasks_by_status(TaskStatus.QUEUED))

        total = running + completed + failed + queued
        success_rate = completed / total if total > 0 else 1.0

        # Get DLQ stats
        dlq_stats = self.dlq.get_stats()
        dlq_size = dlq_stats.get("pending", 0)

        # Get pending approvals
        pending_approvals = len(self.hitl_manager.get_pending_requests())

        # Calculate average duration (simplified)
        avg_duration = 0.0  # Would calculate from completed tasks

        return TaskMetrics(
            total_tasks=total,
            running_tasks=running,
            completed_tasks=completed,
            failed_tasks=failed,
            avg_duration_seconds=avg_duration,
            success_rate=success_rate,
            dlq_size=dlq_size,
            pending_approvals=pending_approvals
        )

    def check_alerts(self) -> List[Alert]:
        """Check metrics against thresholds and generate alerts."""
        metrics = self.collect_metrics()
        alerts = []

        # Check failure rate
        failure_rate = 1 - metrics.success_rate
        if failure_rate > self._thresholds["failure_rate"]:
            alerts.append(self._create_alert(
                severity=AlertSeverity.ERROR,
                title="High Task Failure Rate",
                message=f"Task failure rate is {failure_rate:.1%}, threshold is {self._thresholds['failure_rate']:.1%}",
                metric_name="failure_rate",
                metric_value=failure_rate,
                threshold=self._thresholds["failure_rate"]
            ))

        # Check DLQ size
        if metrics.dlq_size > self._thresholds["dlq_size"]:
            alerts.append(self._create_alert(
                severity=AlertSeverity.WARNING,
                title="Dead Letter Queue Growing",
                message=f"DLQ has {metrics.dlq_size} entries, threshold is {self._thresholds['dlq_size']}",
                metric_name="dlq_size",
                metric_value=metrics.dlq_size,
                threshold=self._thresholds["dlq_size"]
            ))

        # Check pending approvals
        if metrics.pending_approvals > self._thresholds["pending_approvals"]:
            alerts.append(self._create_alert(
                severity=AlertSeverity.WARNING,
                title="Many Pending Approvals",
                message=f"{metrics.pending_approvals} approvals pending, threshold is {self._thresholds['pending_approvals']}",
                metric_name="pending_approvals",
                metric_value=metrics.pending_approvals,
                threshold=self._thresholds["pending_approvals"]
            ))

        # Dispatch alerts
        for alert in alerts:
            for handler in self.alert_handlers:
                try:
                    handler(alert)
                except Exception as e:
                    print(f"Alert handler failed: {e}")

        return alerts

    def _create_alert(
        self,
        severity: AlertSeverity,
        title: str,
        message: str,
        metric_name: str,
        metric_value: float,
        threshold: float
    ) -> Alert:
        """Create an alert."""
        import uuid
        return Alert(
            id=str(uuid.uuid4()),
            severity=severity,
            title=title,
            message=message,
            metric_name=metric_name,
            metric_value=metric_value,
            threshold=threshold,
            created_at=datetime.utcnow().isoformat()
        )

    async def start_monitoring(self, interval_seconds: int = 60) -> None:
        """Start periodic monitoring."""
        while True:
            self.check_alerts()
            await asyncio.sleep(interval_seconds)
```

```python
    - Monitoring and alerting

    def __init__(self, config: ProductionAgentConfig):

                    slack_alert_handler(config.slack_webhook)
                )

        # Register task handler
        self.tasks.register_handler("research", self._research_handler)

    async def research(
        self,
        query: str,
        user_id: str,
        require_approval: bool = False,
        idempotency_key: Optional[str] = None
    ) -> Dict[str, Any]:
        """
        Execute a research task with full durability.

        Args:
            query: Research query
            user_id: User requesting the research
            require_approval: Whether to require human approval
            idempotency_key: Optional key for idempotent execution
        """
        # Check idempotency
        if idempotency_key:
            existing = self.idempotency.get(idempotency_key)
            if existing:
                return existing.result

        # Submit task
        task = await self.tasks.submit(
            name="research",
            input_data={
                "query": query,
                "user_id": user_id,
                "require_approval": require_approval
            },
            max_retries=self.config.max_retries,
            metadata={"idempotency_key": idempotency_key}
        )

        # Start execution
        try:
            await self.tasks.start(task.id)

            # Wait for completion
            while True:
                task = self.tasks.get_task(task.id)
                if task.status in (TaskStatus.COMPLETED, TaskStatus.FAILED, TaskStatus.CANCELLED):
                    break
                await asyncio.sleep(1)

            if task.status == TaskStatus.COMPLETED:
                result = task.output_data

                # Store in idempotency cache
                if idempotency_key:
                    self.idempotency.set(idempotency_key, result)

                return result

            elif task.status == TaskStatus.FAILED:
                # Add to DLQ
                self.dlq.add(
                    task_type="research",
                    task_id=task.id,
                    payload=task.input_data,
                    error=task.error or "Unknown error",
                    retry_count=task.retry_count
                )
                raise Exception(f"Research failed: {task.error}")

            else:
                raise Exception(f"Research cancelled")

        except Exception as e:
            # Ensure task is in DLQ for review
            if task.status != TaskStatus.FAILED:
                self.dlq.add(
                    task_type="research",
                    task_id=task.id,
                    payload=task.input_data,
                    error=str(e),
                    retry_count=task.retry_count
                )
            raise
```

## Comparison: Durability Approaches

| Approach                    | Complexity | Infrastructure       | Best For                      |
| :-------------------------- | :--------- | :------------------- | :---------------------------- |
| **Custom Checkpoints**      | Low        | SQLite/PostgreSQL    | Simple agents, learning       |
