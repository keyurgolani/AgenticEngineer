### Architecture Decision Records (ADRs)

#### ADR-001: Microservices Architecture

**Context:** AgentOS requires multiple capabilities (memory, RAG, LLM routing, etc.) that could be built as a monolith or as separate services.

**Decision:** Implement as microservices with each capability as an independent service communicating via HTTP APIs.

**Real-World Analogy:** Think of this like a restaurant kitchen. Instead of one chef doing everything (monolith), you have specialized stations—grill, sauté, pastry, salad. Each station (service) focuses on what it does best, and the expeditor (orchestrator) coordinates the orders. If the grill breaks down, the rest of the kitchen keeps running.

**Consequences:**

- ✅ Independent scaling of services based on load
- ✅ Technology flexibility (different languages/frameworks per service)
- ✅ Fault isolation (one service failure doesn't crash everything)
- ✅ Easier testing and deployment of individual components
- ⚠️ Network latency between services
- ⚠️ More complex deployment and monitoring
- ⚠️ Distributed system challenges (consistency, debugging)

#### ADR-002: Hybrid LLM Strategy (Local-First with Cloud Fallback)

**Context:** Users want privacy and cost control (local LLMs) but also need access to powerful models (cloud) for complex tasks.

**Decision:** Implement LLM Router service that prefers local Ollama models but falls back to cloud providers (OpenAI, Anthropic) based on task complexity and user preferences.

**Real-World Analogy:** This is like having a home gym with basic equipment for daily workouts (local LLMs), but maintaining a membership at a premium gym with specialized equipment for serious training sessions (cloud LLMs). You use what you have at home for most tasks, but when you need that Olympic-grade equipment, you go to the premium facility.

- ⚠️ More complex routing logic

#### ADR-003: Request Classification Before Routing

**Context:** Incoming requests could be handled by any of 5 specialist agents. Need to determine the best agent for each request.

**Decision:** Implement two-stage classification: fast keyword matching first, then LLM-based classification for ambiguous requests.

**Real-World Analogy:** This is like how email spam filters work. First, they check for obvious spam keywords (fast, cheap). If it's unclear, they use machine learning models to analyze the content more deeply (slower, more accurate). Most emails are caught by the fast filter, saving computational resources for the tricky cases.

**Consequences:**

#### ADR-004: Centralized Configuration via YAML

**Context:** Multiple services and agents need configuration (models, prompts, routing rules). Configuration could be hardcoded, environment variables, or external files.

**Decision:** Use YAML configuration files (`agents.yaml`, `providers.yaml`, `policies.yaml`) loaded at startup.

**Consequences:**

- ✅ Human-readable configuration
- ✅ Easy to modify without code changes
- ✅ Version controllable
- ✅ Supports complex nested structures
- ⚠️ No runtime configuration updates (requires restart)
- ⚠️ YAML parsing errors can be cryptic
- ⚠️ Secrets should not be in YAML (use env vars)

#### ADR-005: Docker Compose for Deployment

**Context:** AgentOS has 10+ services that need to be deployed together with proper networking and dependencies.

**Decision:** Use Docker Compose for local development and single-server deployment. Kubernetes manifests as stretch goal.

**Consequences:**

- ✅ Single command deployment (`docker-compose up`)
- ✅ Consistent environments (dev = prod)
- ✅ Built-in service discovery via container names
- ✅ Volume management for persistence
- ⚠️ Single-server limitation (no horizontal scaling)
- ⚠️ Resource constraints on one machine
- ⚠️ Not suitable for high-availability production

#### Test Scenario 6: Service Failure Resilience

```python
def test_service_failure_resilience():
    """Verify system handles service failures gracefully."""
    # Stop the research service
    os.system("docker-compose stop research")

    try:
        # Research query should fail gracefully
        response = requests.post(
            "http://localhost:8000/chat",
            json={"message": "Research quantum computing"},
            headers={"X-User-Id": "test"}
        )

        # Should not crash, should return error or fallback
        assert response.status_code in [200, 503]
        if response.status_code == 200:
            assert "unavailable" in response.json()["response"].lower() or \
                   response.json()["agent_used"] != "research"
    finally:
        os.system("docker-compose start research")
```

### Troubleshooting Guide

#### Issue: "Docker Compose fails to start all services"

**Symptoms:** Some containers exit immediately or stay in "restarting" state.

**Causes:**

1. Port conflicts with existing services
2. Insufficient memory/CPU
3. Missing environment variables
4. Service dependency issues

**Solutions:**

```bash
# Check which services are failing
docker-compose ps

# View logs for failing service
docker-compose logs <service-name>

# Check for port conflicts
lsof -i :8000  # Check each port

# Increase Docker resources (Docker Desktop settings)
# Minimum: 8GB RAM, 4 CPUs

# Verify .env file has all required variables
cat .env | grep -E "^[A-Z]"

# Start services in dependency order
docker-compose up -d postgres redis
sleep 10
docker-compose up -d
```

#### Issue: "Ollama models not loading"

**Symptoms:** Local LLM requests fail with "model not found" or timeout.

**Causes:**

1. Models not pulled
2. Insufficient GPU memory
3. Ollama container not healthy

**Solutions:**

```bash
# Pull models explicitly
docker exec agentos-ollama-1 ollama pull llama3.1:8b

# Check Ollama logs
docker-compose logs ollama

# Verify GPU access (if using)
docker exec agentos-ollama-1 nvidia-smi

# Use smaller model if memory constrained
docker exec agentos-ollama-1 ollama pull llama3.2:3b

# Test Ollama directly
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.1:8b",
  "prompt": "Hello"
}'
```

#### Issue: "Orchestrator routing to wrong agent"

**Symptoms:** Queries consistently go to wrong specialist agent.

**Causes:**

1. Keyword configuration incorrect
2. LLM classifier prompt needs tuning
3. Confidence threshold too low/high

**Solutions:**

```yaml
# config/agents.yaml - Update keywords
routing:
  keywords:
    research:
      [
        "research",
        "find",
        "search",
```

### Phase 3: The Smart Orchestrator (45 minutes)

```python
# orchestrator/main.py
from typing import Dict, List, Optional, Any
from pydantic import BaseModel
from langgraph.graph import StateGraph, END
from orchestrator.classifier import RequestClassifier
from orchestrator.router import AgentRouter
from orchestrator.state import OrchestratorState
import yaml
import asyncio

class OrchestratorRequest(BaseModel):
    user_id: str
    session_id: str
    message: str
    context: Optional[Dict] = None
    preferences: Optional[Dict] = None

class OrchestratorResponse(BaseModel):
    response: str
    agent_used: str
    confidence: float
    sources: Optional[List[Dict]] = None
    metadata: Dict = {}

class SmartOrchestrator:
    """Central orchestrator that routes requests to specialized agents."""

    def __init__(self, config_path: str = "config/agents.yaml"):
        with open(config_path) as f:
            self.config = yaml.safe_load(f)

        self.classifier = RequestClassifier(self.config["routing"])
        self.router = AgentRouter(self.config["agents"])
        self.graph = self._build_graph()

    def _build_graph(self) -> StateGraph:
        """Build the orchestration graph."""

        workflow = StateGraph(OrchestratorState)

        # Add nodes
        workflow.add_node("classify", self._classify_node)
        workflow.add_node("enrich_context", self._enrich_context_node)
        workflow.add_node("route_to_agent", self._route_node)
        workflow.add_node("execute_agent", self._execute_node)
        workflow.add_node("post_process", self._post_process_node)

        # Set entry point
        workflow.set_entry_point("classify")

        # Add edges
        workflow.add_edge("classify", "enrich_context")
        workflow.add_edge("enrich_context", "route_to_agent")
        workflow.add_edge("route_to_agent", "execute_agent")
        workflow.add_edge("execute_agent", "post_process")
        workflow.add_edge("post_process", END)

        return workflow.compile()

    async def _classify_node(self, state: OrchestratorState) -> Dict:
        """Classify the request to determine the best agent."""
        classification = await self.classifier.classify(
            message=state["message"],
            context=state.get("context")
        )

        return {
            "target_agent": classification["agent"],
            "classification_confidence": classification["confidence"],
            "detected_intent": classification["intent"],
            "detected_entities": classification["entities"]
        }

    async def _enrich_context_node(self, state: OrchestratorState) -> Dict:
        """Enrich context with memory and relevant documents."""
        enriched = {}

        # Fetch user memories
        try:
            from services.memory_client import MemoryClient
            memory_client = MemoryClient()

            # Get relevant long-term memories
            memories = await memory_client.recall(
                user_id=state["user_id"],
                query=state["message"],
                top_k=3
            )
            enriched["memories"] = memories

            # Get conversation history
            history = await memory_client.get_messages(
                user_id=state["user_id"],
                session_id=state["session_id"],
                limit=10
            )
            enriched["conversation_history"] = history

        except Exception as e:
            print(f"Memory enrichment failed: {e}")

        # Fetch relevant documents if RAG is needed
        if state["target_agent"] in ["research", "analysis", "code"]:
            try:
                from services.rag_client import RAGClient
                rag_client = RAGClient()

                docs = await rag_client.query(
                    user_id=state["user_id"],
                    query=state["message"],
                    top_k=3
                )
                enriched["relevant_documents"] = docs

            except Exception as e:
                print(f"RAG enrichment failed: {e}")

        return {"enriched_context": enriched}

    async def _route_node(self, state: OrchestratorState) -> Dict:
        """Route to the appropriate agent."""
        agent_config = self.router.get_agent_config(state["target_agent"])

        # Get prompt from library
        try:
            from services.prompt_client import PromptClient
            prompt_client = PromptClient()

            prompt = await prompt_client.get_prompt(
                name=agent_config["prompts"]["system"],
                variables={
                    "user_id": state["user_id"],
                    "context": state.get("enriched_context", {})
                }
            )

            return {"agent_prompt": prompt}

        except Exception as e:
            print(f"Prompt fetch failed: {e}")
            return {"agent_prompt": None}

    async def _execute_node(self, state: OrchestratorState) -> Dict:
        """Execute the selected agent."""
        agent = self.router.get_agent(state["target_agent"])

        result = await agent.execute(
            message=state["message"],
            context=state.get("enriched_context", {}),
            prompt=state.get("agent_prompt"),
            preferences=state.get("preferences", {})
        )

        return {
            "agent_response": result["response"],
            "agent_metadata": result.get("metadata", {}),
            "sources": result.get("sources", [])
        }

    async def _post_process_node(self, state: OrchestratorState) -> Dict:
        """Post-process the response and update memory."""

        # Store conversation in memory
        try:
            from services.memory_client import MemoryClient
            memory_client = MemoryClient()

            # Store user message
            await memory_client.add_message(
                user_id=state["user_id"],
                session_id=state["session_id"],
                role="user",
                content=state["message"]
            )

            # Store assistant response
            await memory_client.add_message(
                user_id=state["user_id"],
                session_id=state["session_id"],
                role="assistant",
                content=state["agent_response"],
                metadata={"agent": state["target_agent"]}
            )

        except Exception as e:
            print(f"Memory storage failed: {e}")

        return {"status": "completed"}

    async def process(self, request: OrchestratorRequest) -> OrchestratorResponse:
        """Process a request through the orchestration pipeline."""

        initial_state = {
            "user_id": request.user_id,
            "session_id": request.session_id,
            "message": request.message,
            "context": request.context,
            "preferences": request.preferences,
            "status": "started"
        }

        result = await self.graph.ainvoke(initial_state)

        return OrchestratorResponse(
            response=result["agent_response"],
            agent_used=result["target_agent"],
            confidence=result["classification_confidence"],
            sources=result.get("sources"),
            metadata=result.get("agent_metadata", {})
        )
```

### Phase 4: Request Classifier (30 minutes)

```python
# orchestrator/classifier.py
from langchain_openai import ChatOpenAI
from typing import Dict, List, Optional
import re

class RequestClassifier:
    """Classify incoming requests to route to the right agent."""

    def __init__(self, routing_config: Dict):
        self.config = routing_config
        self.keywords = routing_config.get("keywords", {})
        self.default_agent = routing_config.get("default", "assistant")
        self.threshold = routing_config.get("confidence_threshold", 0.7)
        self.llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

    async def classify(
        self,
        message: str,
        context: Optional[Dict] = None
    ) -> Dict:
        """Classify a request and return routing information."""

        # First, try keyword-based classification (fast)
        keyword_result = self._keyword_classify(message)

        if keyword_result["confidence"] >= self.threshold:
            return keyword_result

        # Fall back to LLM classification (more accurate)
        llm_result = await self._llm_classify(message, context)

        # Use the higher confidence result
        if llm_result["confidence"] > keyword_result["confidence"]:
            return llm_result

        return keyword_result

    def _keyword_classify(self, message: str) -> Dict:
        """Fast keyword-based classification."""
        message_lower = message.lower()

        scores = {}
        for agent, keywords in self.keywords.items():
            score = sum(1 for kw in keywords if kw in message_lower)
            scores[agent] = score

        if not scores or max(scores.values()) == 0:
            return {
                "agent": self.default_agent,
                "confidence": 0.3,
                "intent": "general",
                "entities": [],
                "method": "keyword_default"
            }

        best_agent = max(scores, key=scores.get)
        max_score = scores[best_agent]

        # Normalize confidence
        confidence = min(0.9, 0.4 + (max_score * 0.15))

        return {
            "agent": best_agent,
            "confidence": confidence,
            "intent": best_agent,
            "entities": [],
            "method": "keyword"
        }

    async def _llm_classify(
        self,
        message: str,
        context: Optional[Dict]
    ) -> Dict:
        """LLM-based classification for complex requests."""

        agents_desc = """
Available agents:
- research: Web research, fact-finding, investigation, "what is", "who is", "find out"
- code: Programming, debugging, code review, implementation, any programming language
- analysis: Data analysis, statistics, trends, charts, numerical analysis
- creative: Creative writing, stories, content, brainstorming, marketing copy
- assistant: General questions, planning, summarization, misc tasks
"""

        prompt = f"""{agents_desc}

User message: "{message}"

Classify this message. Return JSON:
{{"agent": "agent_name", "confidence": 0.0-1.0, "intent": "brief intent", "entities": ["key entities"]}}"""

        response = await self.llm.ainvoke(prompt)

        try:
            import json
            result = json.loads(response.content)
            result["method"] = "llm"
            return result
        except:
            return {
                "agent": self.default_agent,
                "confidence": 0.5,
                "intent": "unknown",
                "entities": [],
                "method": "llm_fallback"
            }
```

### Phase 5: Base Agent Class (30 minutes)

```python
# agents/base.py
from abc import ABC, abstractmethod
from typing import Dict, List, Optional, Any
from pydantic import BaseModel
import httpx

class AgentResponse(BaseModel):
    response: str
    sources: Optional[List[Dict]] = None
    metadata: Dict = {}
    tokens_used: Optional[int] = None

class BaseAgent(ABC):
    """Base class for all specialized agents."""

    def __init__(self, config: Dict):
        self.config = config
        self.name = config.get("name", "Agent")
        self.capabilities = config.get("capabilities", [])
        self.default_model = config.get("default_model", "gpt-4o-mini")
        self.fallback_model = config.get("fallback_model")
        self.temperature = config.get("temperature", 0.7)

        # Service clients
        self.llm_router_url = "http://localhost:8004"
        self.memory_url = "http://localhost:8002"
        self.rag_url = "http://localhost:8003"
        self.prompt_url = "http://localhost:8001"

    async def execute(
        self,
        message: str,
        context: Dict = None,
        prompt: Dict = None,
        preferences: Dict = None
    ) -> AgentResponse:
        """Execute the agent's task."""

        # Build the full context
        full_context = await self._build_context(message, context)

        # Get system prompt
        system_prompt = await self._get_system_prompt(prompt)

        # Execute the agent-specific logic
        result = await self._execute(message, full_context, system_prompt, preferences)

        return result

    async def _build_context(self, message: str, context: Dict) -> Dict:
        """Build context for the agent."""
        full_context = context or {}

        # Add agent-specific context building
        agent_context = await self._get_agent_context(message)
        full_context.update(agent_context)

        return full_context

    async def _get_system_prompt(self, prompt: Dict) -> str:
        """Get the system prompt for this agent."""
        if prompt and "system_prompt" in prompt:
            return prompt["system_prompt"]

        # Fallback to default prompt
        return self._get_default_prompt()

    @abstractmethod
    async def _execute(
        self,
        message: str,
        context: Dict,
        system_prompt: str,
        preferences: Dict
    ) -> AgentResponse:
        """Agent-specific execution logic."""
        pass

    @abstractmethod
    async def _get_agent_context(self, message: str) -> Dict:
        """Get agent-specific context."""
        pass

    @abstractmethod
    def _get_default_prompt(self) -> str:
        """Get default system prompt."""
        pass

    async def _call_llm(
        self,
        messages: List[Dict],
        task_type: str = "general",
        prefer_local: bool = True
    ) -> str:
        """Call LLM through the router."""
        async with httpx.AsyncClient() as client:
            response = await client.post(
                f"{self.llm_router_url}/llm/chat",
                json={
                    "messages": messages,
                    "task_type": task_type,
                    "prefer_local": prefer_local
                },
                timeout=60.0
            )
            result = response.json()
            return result["content"]

    async def _search_documents(
        self,
        query: str,
        user_id: str,
        top_k: int = 5
    ) -> List[Dict]:
        """Search RAG documents."""
        async with httpx.AsyncClient() as client:
            response = await client.post(
                f"{self.rag_url}/rag/{user_id}/query",
                params={"query": query, "top_k": top_k}
            )
            return response.json()

    async def _recall_memories(
        self,
        query: str,
        user_id: str,
        top_k: int = 3
    ) -> List[Dict]:
        """Recall relevant memories."""
        async with httpx.AsyncClient() as client:
            response = await client.post(
                f"{self.memory_url}/memory/{user_id}/long-term/recall",
                json={"query": query, "top_k": top_k}
            )
            return response.json()
```

1. **Separation of Concerns**: Each service has a single responsibility
   - _Like a well-organized toolbox where each tool has its designated spot and purpose_

2. **Loose Coupling**: Services communicate via APIs
   - _Like electrical outlets—you can plug in any compatible device without rewiring the house_

3. **Local-First**: Prefer local LLMs when possible
   - _Like cooking at home before ordering takeout—cheaper, more control, and private_

4. **Graceful Degradation**: Fallbacks at every level
   - _Like a car with multiple safety systems—if one fails, others keep you safe_

5. **Observability**: Logging, metrics, and tracing
   - _Like a car dashboard showing speed, fuel, temperature—you always know what's happening_

6. **Security**: Authentication, rate limiting, input validation
   - _Like a building with security guards, badge access, and surveillance—multiple layers of protection_
