## 90.5 Design Patterns Reference

### Core Pattern Catalog

| Pattern               | When to Use              | Key Implementation                  |
| :-------------------- | :----------------------- | :---------------------------------- |
| **ReAct**             | Dynamic tool use         | Thought → Action → Observation loop |
| **Plan-and-Execute**  | Complex multi-step tasks | Separate planner and executor       |
| **Supervisor**        | Coordinating specialists | Central router with worker nodes    |
| **Reflection**        | Quality improvement      | Generator → Critic → Refine loop    |
| **Context Isolation** | Multi-agent systems      | Scoped contexts per worker          |
| **Human-in-the-Loop** | High-stakes actions      | `interrupt_before` checkpoints      |
| **Neuro-Symbolic**    | Code manipulation        | LLM reasoning + AST transforms      |

### 2024-2025 Emerging Patterns

| Pattern                        | When to Use              | Key Implementation                            |
| :----------------------------- | :----------------------- | :-------------------------------------------- |
| **Tree-of-Thought**            | Complex reasoning        | Branching exploration with backtracking       |
| **Multi-Agent Debate (MAD)**   | Consensus building       | Agents argue positions, synthesize agreement  |
| **HACN**                       | Large-scale coordination | Hierarchical Adaptive Consensus Network       |
| **Model Routing** (Day 19)     | Cost optimization        | ComplexityAssessor, ModelRouter, CostTracker  |
| **Semantic Caching** (Day 19)  | Latency reduction        | Cache similar queries, not just exact matches |
| **Durable Execution** (Day 21) | Long-running workflows   | CheckpointManager, Temporal.io, Inngest       |
| **A2A Communication** (Day 38) | Agent collaboration      | AgentCard, AgentRegistry, A2AMessenger        |
| **Neuro-Symbolic** (Day 67)    | Guaranteed correctness   | HybridCodeTransformer, VerifiedTransformer    |
| **Speculative Execution**      | Performance              | Pre-compute likely next steps                 |

<Callout type="tip">
  **Pattern Selection**: Start with ReAct for simple agents, graduate to
  Plan-and-Execute for complex tasks, and use Supervisor patterns when you need
  specialized workers. Add Tree-of-Thought when reasoning quality matters more
  than speed.
</Callout>

### The Four Pillars, Revisited

<Mermaid
  chart={`

  caption="The Four Pillars: Creating a solid foundation."
/>

1. **Reliability** - Your agents will fail. Design for recovery with checkpointing, durable execution, and human-in-the-loop patterns. Temporal.io and Inngest (Day 21) have emerged as key infrastructure for long-running agent workflows.

<Callout type="info">
  **Real-world analogy**: Think of reliability like building a bridge. You don't
  just design for perfect conditions—you design for earthquakes, floods, and
  heavy loads. Similarly, production agents must handle API failures, rate
  limits, and unexpected inputs gracefully.
</Callout>

2. **Interoperability** - MCP has become the standard for tool integration, adopted across all major IDEs and frameworks. The A2A protocol (Day 38) is emerging for agent-to-agent communication with AgentCard, AgentRegistry, and A2AMessenger. Bet on standards—they compound.

<Callout type="info">
  **Real-world analogy**: Standards are like electrical outlets. Imagine if
  every appliance needed a different plug! MCP and A2A are creating universal
  "plugs" for agents, enabling them to work together seamlessly regardless of
  who built them.
</Callout>

3. **Efficiency** - Context engineering is the new prompt engineering. It's not just what you say, but what information your agent has access to. Semantic caching, model routing (Day 19), and context isolation are essential techniques. ComplexityAssessor and CostTracker help optimize costs while maintaining quality.

<Callout type="info">
  **Real-world analogy**: Context engineering is like being a great executive
  assistant. It's not about giving your boss all the information—it's about
  giving them exactly the right information at the right time. Too much context
  overwhelms; too little leaves gaps.
</Callout>

4. **Correctness** - Neuro-symbolic approaches (Day 67) are gaining traction. Ground probabilistic systems in deterministic structures using HybridCodeTransformer, VerifiedTransformer, and logic programming with pyDatalog. Red teaming and adversarial testing are now standard practice for production agents.

<Callout type="info">
  **Real-world analogy**: Neuro-symbolic AI is like having a creative artist
  (neural) work with a meticulous accountant (symbolic). The artist generates
  ideas, the accountant verifies they follow the rules. Together, they produce
  both innovative and correct results.
</Callout>
