## 5.2 Chunking Strategies

Chunking is the most underrated part of RAG. Bad chunking = bad retrieval.

### Fixed-Size Chunking

```python
def fixed_chunk(text: str, chunk_size: int = 500, overlap: int = 50) -> list[str]:
    """Simple fixed-size chunking with overlap."""
    chunks = []
    start = 0

    while start < len(text):
        end = start + chunk_size
        chunk = text[start:end]
        chunks.append(chunk)
        start = end - overlap  # Overlap for context continuity

    return chunks
```

Better: Split on natural boundaries (paragraphs, sections, functions):

```python
import re

def semantic_chunk(text: str, max_size: int = 1000) -> list[str]:
    """Split on semantic boundaries."""
    # Split on double newlines (paragraphs)
    paragraphs = re.split(r'\n\n+', text)

    chunks = []
    current_chunk = ""

    for para in paragraphs:
        if len(current_chunk) + len(para) < max_size:
            current_chunk += para + "\n\n"
        else:
            if current_chunk:
                chunks.append(current_chunk.strip())
            current_chunk = para + "\n\n"

    if current_chunk:
        chunks.append(current_chunk.strip())

    return chunks
```

### Code-Aware Chunking

For code, respect function/class boundaries:

```python
import ast

def chunk_python_code(code: str) -> list[dict]:
    """Chunk Python code by function/class."""
    tree = ast.parse(code)
    chunks = []

    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.ClassDef)):
            chunk = {
                "type": type(node).__name__,
                "name": node.name,
                "code": ast.get_source_segment(code, node),
                "line_start": node.lineno,
                "line_end": node.end_lineno
            }
            chunks.append(chunk)

    return chunks
```

### Late Chunking (Advanced)

Traditional chunking loses context because each chunk is embedded independently. **Late chunking** solves this by processing the entire document through the embedding model first, then chunking the token embeddings:

<Mermaid
  chart={`
graph LR
    subgraph Traditional Chunking
        A1[Document] --> B1[Split into Chunks]
        B1 --> C1[Embed Each Chunk]
        C1 --> D1[Store Vectors]
    end
    
    subgraph Late Chunking
        A2[Document] --> B2[Embed Full Document]
        B2 --> C2[Split Token Embeddings]
        C2 --> D2[Pool into Chunk Vectors]
        D2 --> E2[Store Vectors]
    end
    
    style D1 fill:#f96,stroke:#333
    style E2 fill:#9f9,stroke:#333
`}
/>

```python
from transformers import AutoModel, AutoTokenizer
import torch

def late_chunking(
    text: str,
    chunk_size: int = 512,
    model_name: str = "jinaai/jina-embeddings-v3"
) -> list[list[float]]:
    """
    Late chunking: embed full document, then chunk token embeddings.
    Requires a long-context embedding model like Jina v3.
    """
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModel.from_pretrained(model_name, trust_remote_code=True)

    # Tokenize full document
    inputs = tokenizer(text, return_tensors="pt", truncation=False)

    # Get token embeddings for full document
    with torch.no_grad():
        outputs = model(**inputs)
        token_embeddings = outputs.last_hidden_state[0]  # [seq_len, hidden_dim]

    # Split token embeddings into chunks
    chunk_embeddings = []
    for i in range(0, len(token_embeddings), chunk_size):
        chunk_tokens = token_embeddings[i:i + chunk_size]
        # Mean pooling over chunk tokens
        chunk_vector = chunk_tokens.mean(dim=0).tolist()
        chunk_embeddings.append(chunk_vector)

    return chunk_embeddings
```

<Callout type="tip">
  **When to Use Late Chunking**: Late chunking preserves context across chunk
  boundaries, making it ideal for documents where information spans multiple
  sections. It requires long-context embedding models (Jina v3, Voyage 3) and
  more compute, but significantly improves retrieval for complex documents.
</Callout>

Modern embedding models like Voyage 3.5 and OpenAI's text-embedding-3 support **Matryoshka representations**—you can truncate embeddings to smaller dimensions while preserving most of the semantic information:

```python
from openai import OpenAI

client = OpenAI()

def get_embedding_with_dimensions(text: str, dimensions: int = 256) -> list[float]:
    """Get embedding with reduced dimensions for faster search."""
    response = client.embeddings.create(
        input=text,
        model="text-embedding-3-small",
        dimensions=dimensions  # 256, 512, 1024, or 1536
    )
    return response.data[0].embedding

# Use smaller dimensions for faster search, larger for higher accuracy
fast_embedding = get_embedding_with_dimensions("Hello world", dimensions=256)
accurate_embedding = get_embedding_with_dimensions("Hello world", dimensions=1536)
```

<Callout type="info">
  **Matryoshka Trade-offs**: 256 dimensions = 6x faster search, ~5% quality
  loss. 512 dimensions = 3x faster, ~2% quality loss. Use smaller dimensions for
  initial retrieval, then rerank with full embeddings.
</Callout>

### Using Cohere Embed v4 (Multimodal)

Cohere's Embed v4 supports text, images, and mixed documents with 128K context:

```python
import cohere
import base64

co = cohere.Client()

def get_cohere_embedding(text: str) -> list[float]:
    """Get text embedding using Cohere Embed v4."""
    response = co.embed(
        texts=[text],
        model="embed-v4",
        input_type="search_document",  # or "search_query" for queries
        embedding_types=["float"]
    )
    return response.embeddings.float[0]

def get_multimodal_embedding(text: str, image_path: str) -> list[float]:
    """Get embedding for text + image using Cohere Embed v4."""
    with open(image_path, "rb") as f:
        image_base64 = base64.standard_b64encode(f.read()).decode("utf-8")

    response = co.embed(
        model="embed-v4",
        input_type="search_document",
        embedding_types=["float"],
        images=[f"data:image/jpeg;base64,{image_base64}"],
        texts=[text]
    )
    return response.embeddings.float[0]
```

<Callout type="info">
  **Multimodal RAG**: Cohere Embed v4 can embed documents containing both text
  and images into a single vector. This enables searching across PDFs, slides,
  and documents with diagrams without separate image processing pipelines.
</Callout>

## 5.5 Building a Complete RAG Pipeline

<Mermaid
  chart={`

        Query[User Query] --> QEmbed[Query Embedder]
        QEmbed --> Match{Similarity Match}

        Match -->|Top-K Chunks| Context[Context Window]
        Context --> LLM[Generation]

    end

```python
import os
from pathlib import Path
import chromadb
from openai import OpenAI

class RAGPipeline:
    def __init__(self, collection_name: str = "knowledge_base"):
        self.client = OpenAI()
        self.chroma = chromadb.Client()
        self.collection = self.chroma.get_or_create_collection(
            name=collection_name,
            metadata={"hnsw:space": "cosine"}
        )

    def ingest_directory(self, path: str, extensions: list[str] = [".md", ".txt", ".py"]):
        """Ingest all matching files from a directory."""
        documents = []
        metadatas = []
        ids = []

        for file_path in Path(path).rglob("*"):
            if file_path.suffix in extensions:
                content = file_path.read_text()
                chunks = self._chunk_document(content, str(file_path))

                for i, chunk in enumerate(chunks):
                    documents.append(chunk["text"])
                    metadatas.append({
                        "source": str(file_path),
                        "chunk_index": i
                    })
                    ids.append(f"{file_path.stem}_{i}")

        # Batch add to collection
        if documents:
            self.collection.add(
                documents=documents,
                metadatas=metadatas,
                ids=ids
            )
            print(f"Ingested {len(documents)} chunks from {path}")

    def _chunk_document(self, content: str, source: str) -> list[dict]:
        """Chunk a document with metadata."""
        chunks = []
        # Simple paragraph-based chunking
        paragraphs = content.split("\n\n")

        current_chunk = ""
        for para in paragraphs:
            if len(current_chunk) + len(para) < 1000:
                current_chunk += para + "\n\n"
            else:
                if current_chunk.strip():
                    chunks.append({"text": current_chunk.strip(), "source": source})
                current_chunk = para + "\n\n"

        if current_chunk.strip():
            chunks.append({"text": current_chunk.strip(), "source": source})

        return chunks

    def query(self, question: str, n_results: int = 5) -> str:
        """Query the knowledge base and generate an answer."""
        # Retrieve relevant chunks
        results = self.collection.query(
            query_texts=[question],
            n_results=n_results
        )

        # Build context from results
        context_parts = []
        for doc, metadata in zip(results["documents"][0], results["metadatas"][0]):
            context_parts.append(f"[Source: {metadata['source']}]\n{doc}")

        context = "\n\n---\n\n".join(context_parts)

        # Generate answer
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {
                    "role": "system",
                    "content": """You are a helpful assistant. Answer questions based on the provided context.
                    If the context doesn't contain relevant information, say so.
                    Always cite your sources."""
                },
                {
                    "role": "user",
                    "content": f"Context:\n{context}\n\nQuestion: {question}"
                }
            ],
            temperature=0.1
        )

        return response.choices[0].message.content

# Usage
rag = RAGPipeline()
rag.ingest_directory("./docs")
answer = rag.query("How do I configure the database connection?")
print(answer)
```

### HyDE (Hypothetical Document Embeddings)

```python
    """
    HyDE: Generate hypothetical answer, then search with it.
    Improves retrieval when queries don't match document style.
    """
    # Step 1: Generate hypothetical document
    hypothetical = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {
                "role": "system",
                "content": """You are a technical documentation writer.
                Given a question, write a detailed paragraph that would answer it.
                Write as if this paragraph exists in official documentation."""
            },
            {"role": "user", "content": question}
        ],

    ).choices[0].message.content

    # Step 2: Search using the hypothetical document
    results = collection.query(
        query_texts=[hypothetical],
        n_results=n_results
    )

    return results, hypothetical
```

### RAPTOR (Recursive Abstractive Processing for Tree-Organized Retrieval)

RAPTOR builds a hierarchical tree of summaries, enabling retrieval at different levels of abstraction:

<Mermaid

    subgraph "RAPTOR Tree Structure"
        Root[Root Summary<br/>Entire corpus]
        Root --> C1[Cluster 1 Summary]
        Root --> C2[Cluster 2 Summary]
        Root --> C3[Cluster 3 Summary]
        C1 --> D1[Chunk 1]
        C1 --> D2[Chunk 2]
        C2 --> D3[Chunk 3]
        C2 --> D4[Chunk 4]
        C3 --> D5[Chunk 5]
        C3 --> D6[Chunk 6]
    end
    
    style Root fill:#f9f,stroke:#333
    style C1 fill:#bbf,stroke:#333
    style C2 fill:#bbf,stroke:#333
    style C3 fill:#bbf,stroke:#333
`}
/>

```python
from sklearn.cluster import KMeans
import numpy as np

class RAPTORIndex:
    """
    RAPTOR: Build hierarchical summaries for multi-level retrieval.
    Great for answering questions that span multiple documents.
    """

    def __init__(self, client: OpenAI, n_clusters: int = 5):
        self.client = client
        self.n_clusters = n_clusters
        self.tree = {}  # level -> [(summary, embedding, children)]

    def build_tree(self, chunks: list[str], embeddings: list[list[float]], level: int = 0):
        """Recursively cluster and summarize chunks."""
        if len(chunks) <= self.n_clusters:
            # Base case: store leaf nodes
            self.tree[level] = [(chunk, emb, None) for chunk, emb in zip(chunks, embeddings)]
            return

        # Cluster chunks
        kmeans = KMeans(n_clusters=self.n_clusters, random_state=42)
        labels = kmeans.fit_predict(np.array(embeddings))

        # Group chunks by cluster
        clusters = {}
        for i, label in enumerate(labels):
            if label not in clusters:
                clusters[label] = []
            clusters[label].append((chunks[i], embeddings[i]))

        # Summarize each cluster
        summaries = []
        summary_embeddings = []

        for label, cluster_chunks in clusters.items():
            texts = [c[0] for c in cluster_chunks]
            combined = "\n\n".join(texts[:5])  # Limit for context window

            summary = self.client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[
                    {"role": "system", "content": "Summarize these related text chunks concisely."},
                    {"role": "user", "content": combined}
                ]
            ).choices[0].message.content

            summary_emb = self._get_embedding(summary)
            summaries.append(summary)
            summary_embeddings.append(summary_emb)

            # Store this level
            if level not in self.tree:
                self.tree[level] = []
            self.tree[level].append((summary, summary_emb, cluster_chunks))

        # Recurse up the tree
        self.build_tree(summaries, summary_embeddings, level + 1)

    def query(self, question: str, top_k: int = 5) -> list[str]:
        """Query across all levels of the tree."""
        query_emb = self._get_embedding(question)
        all_results = []

        # Search each level
        for level, nodes in self.tree.items():
            for summary, emb, children in nodes:
                similarity = self._cosine_similarity(query_emb, emb)
                all_results.append((similarity, summary, level))

        # Return top results across all levels
        all_results.sort(reverse=True)
        return [r[1] for r in all_results[:top_k]]

    def _get_embedding(self, text: str) -> list[float]:
        response = self.client.embeddings.create(
            input=text, model="text-embedding-3-small"
        )
        return response.data[0].embedding

    def _cosine_similarity(self, a: list[float], b: list[float]) -> float:
        a, b = np.array(a), np.array(b)
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

<Callout type="info">
  **RAPTOR Use Cases**: RAPTOR excels at multi-hop questions that require
  synthesizing information across documents. Questions like "What are the main
  themes across all quarterly reports?" benefit from higher-level summaries,
  while specific questions retrieve from leaf chunks.
</Callout>

### Reranking

<Mermaid
  chart={`
graph TD
    Docs[1000s of Documents] -->|Retrieve top-k| Initial[20 Candidates]
    Initial -->|Cross-Encoder| Rerank[Reranking]
    Rerank -->|Sort by Score| Final[Top 5 Relevant]

`}

Initial retrieval casts a wide net; reranking refines results using a cross-encoder model:

```python
from sentence_transformers import CrossEncoder

class RerankedRAG(RAGPipeline):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        # Cross-encoder for reranking
        self.reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

    def query_with_rerank(
        self,
        question: str,
        initial_k: int = 20,
        final_k: int = 5
    ) -> str:
        """Retrieve more candidates, then rerank to get the best."""
        # Step 1: Initial retrieval (cast wide net)
        results = self.collection.query(
            query_texts=[question],
            n_results=initial_k
        )

        documents = results["documents"][0]
        metadatas = results["metadatas"][0]

        # Step 2: Rerank with cross-encoder
        pairs = [[question, doc] for doc in documents]
        scores = self.reranker.predict(pairs)

        # Step 3: Sort by reranker score and take top-k
        ranked = sorted(
            zip(documents, metadatas, scores),
            key=lambda x: x[2],
            reverse=True
        )[:final_k]

        # Build context from reranked results
        context_parts = [
            f"[Source: {meta['source']}]\n{doc}"
            for doc, meta, _ in ranked
        ]
        context = "\n\n---\n\n".join(context_parts)

        return self._generate_answer(question, context)
```

<Callout type="tip">
  **Reranking Best Practice**: Retrieve 3-4x more documents than you need, then
  rerank down. For example, retrieve 20 candidates and rerank to top 5. This
  dramatically improves precision without sacrificing recall.
</Callout>

```python
def expand_query(question: str, client: OpenAI) -> list[str]:
    """Generate query variations to improve retrieval recall."""
    response = client.chat.completions.create(

        queries = expand_query(question, self.client)

            for doc, meta in list(all_docs.items())[:n_results]
```

```python
from rank_bm25 import BM25Okapi

class HybridRAG(RAGPipeline):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.bm25 = None
        self.documents = []

    def _build_bm25_index(self):
        """Build BM25 index for keyword search."""
        # Get all documents from collection
        all_docs = self.collection.get()
        self.documents = all_docs["documents"]

        # Tokenize for BM25
        tokenized = [doc.lower().split() for doc in self.documents]
        self.bm25 = BM25Okapi(tokenized)

    def hybrid_query(self, question: str, n_results: int = 5, alpha: float = 0.5):
        """Combine BM25 and vector search results."""
        # Vector search
        vector_results = self.collection.query(
            query_texts=[question],
            n_results=n_results * 2
        )

        # BM25 search
        if self.bm25 is None:
            self._build_bm25_index()

        tokenized_query = question.lower().split()
        bm25_scores = self.bm25.get_scores(tokenized_query)

        # Combine scores (simplified)
        # In production, use reciprocal rank fusion
        combined = {}
        for i, doc in enumerate(vector_results["documents"][0]):
            combined[doc] = alpha * (1 / (i + 1))  # Vector rank score

        top_bm25_indices = sorted(range(len(bm25_scores)),
                                   key=lambda i: bm25_scores[i],
                                   reverse=True)[:n_results * 2]

        for rank, idx in enumerate(top_bm25_indices):
            doc = self.documents[idx]
            if doc in combined:
                combined[doc] += (1 - alpha) * (1 / (rank + 1))
            else:
                combined[doc] = (1 - alpha) * (1 / (rank + 1))

        # Return top results
        sorted_docs = sorted(combined.items(), key=lambda x: x[1], reverse=True)
        return [doc for doc, score in sorted_docs[:n_results]]
```

Let the agent decide when, what, and how to retrieve. This is the most flexible pattern—the agent can reformulate queries, choose different retrieval strategies, and decide when it has enough information:

```python
from typing import Literal
from pydantic import BaseModel, Field

class RetrievalDecision(BaseModel):
    """Agent's decision about retrieval."""
    action: Literal["search", "search_code", "search_graph", "answer"]
    query: str | None = Field(description="Search query if action is search")
    reasoning: str = Field(description="Why this action was chosen")

class AgenticRAG:
    """
    Agentic RAG: Let the agent control the retrieval process.
    The agent decides when to search, what to search for, and when to stop.
    """

    def __init__(self, client: OpenAI, collections: dict):
        self.client = client
        self.collections = collections  # {"docs": ..., "code": ..., "graph": ...}

    def run(self, question: str, max_iterations: int = 3) -> str:
        """Run agentic RAG loop."""
        context_parts = []
        iteration = 0

        while iteration < max_iterations:
            # Ask agent what to do
            decision = self._decide_action(question, context_parts)

            if decision.action == "answer":
                break

            # Execute retrieval
            if decision.action == "search":
                results = self.collections["docs"].query(
                    query_texts=[decision.query],
                    n_results=3
                )
                context_parts.extend(results["documents"][0])

            elif decision.action == "search_code":
                results = self.collections["code"].query(
                    query_texts=[decision.query],
                    n_results=3
                )
                context_parts.extend(results["documents"][0])

            elif decision.action == "search_graph":
                # Query knowledge graph
                results = self._query_graph(decision.query)
                context_parts.append(results)

            iteration += 1

        # Generate final answer
        return self._generate_answer(question, context_parts)

    def _decide_action(
        self,
        question: str,
        context: list[str]
    ) -> RetrievalDecision:
        """Let the agent decide what to do next."""
        context_summary = "\n---\n".join(context[-5:]) if context else "No context yet."

        response = self.client.beta.chat.completions.parse(
            model="gpt-4o-mini",
            messages=[
                {
                    "role": "system",
                    "content": """You are a retrieval agent. Given a question and current context,
                    decide whether to:
                    - "search": Search documentation for more information
                    - "search_code": Search code examples
                    - "search_graph": Query the knowledge graph for relationships
                    - "answer": You have enough context to answer

                    If searching, provide a specific, targeted query."""
                },
                {
                    "role": "user",
                    "content": f"Question: {question}\n\nCurrent context:\n{context_summary}"
                }
            ],
            response_format=RetrievalDecision
        )

        return response.choices[0].message.parsed

# Usage
agentic_rag = AgenticRAG(client, {
    "docs": docs_collection,
    "code": code_collection,
    "graph": graph_index
})

answer = agentic_rag.run("How do I implement rate limiting with Redis?")
```

<Callout type="tip">
  **Agentic RAG Best Practices**: (1) Give the agent clear retrieval tool
  descriptions. (2) Include retrieved context in each decision prompt so it
  knows what it already has. (3) Set a max iteration limit to prevent infinite
  loops. (4) Log the agent's reasoning for debugging retrieval issues.

### Self-RAG (Self-Reflective RAG)

Self-RAG adds reflection and self-critique to the RAG pipeline. The model evaluates its own retrieval and generation quality, deciding when to retrieve more, when the answer is sufficient, and when to regenerate:

<Mermaid
  chart={`
flowchart TB
    Q[User Question] --> DECIDE{Need Retrieval?}
    
    DECIDE -->|No| GEN1[Generate without retrieval]
    DECIDE -->|Yes| RET[Retrieve Documents]
    
    RET --> EVAL{Evaluate Relevance}
    EVAL -->|Irrelevant| RET
    EVAL -->|Relevant| GEN2[Generate with Context]
    
    GEN1 --> CRITIQUE{Self-Critique}
    GEN2 --> CRITIQUE
    
    CRITIQUE -->|Supported & Useful| RESPOND[Final Response]
    CRITIQUE -->|Not Supported| REGEN[Regenerate]
    CRITIQUE -->|Not Useful| REFINE[Refine Query]
    
    REGEN --> CRITIQUE
    REFINE --> RET
    
    style DECIDE fill:#e1bee7,stroke:#333
    style EVAL fill:#bbf,stroke:#333
    style CRITIQUE fill:#c8e6c9,stroke:#333
`}
/>

```python
from typing import Literal
from pydantic import BaseModel, Field
import json

class RetrievalNeed(BaseModel):
    """Assess whether retrieval is needed."""
    needs_retrieval: bool
    reasoning: str

class RelevanceScore(BaseModel):
    """Evaluate document relevance."""
    is_relevant: bool
    relevance_score: float = Field(ge=0, le=1)
    reasoning: str

class SupportScore(BaseModel):
    """Evaluate if answer is supported by context."""
    is_supported: bool
    support_score: float = Field(ge=0, le=1)
    unsupported_claims: list[str] = Field(default_factory=list)

class UsefulnessScore(BaseModel):
    """Evaluate if answer is useful."""
    is_useful: bool
    usefulness_score: float = Field(ge=0, le=1)
    improvement_suggestions: list[str] = Field(default_factory=list)

class SelfRAG:
    """
    Self-RAG: Retrieval with self-reflection and critique.
    The model decides when to retrieve, evaluates relevance,
    and critiques its own answers for support and usefulness.
    """

    def __init__(self, client: OpenAI, collection):
        self.client = client
        self.collection = collection

    def query(self, question: str, max_iterations: int = 3) -> dict:
        """Run Self-RAG with reflection loop."""
        iteration = 0
        context = []

        while iteration < max_iterations:
            # Step 1: Decide if retrieval is needed
            if not context:
                need = self._assess_retrieval_need(question)
                if need.needs_retrieval:
                    docs = self._retrieve(question)
                    context = self._filter_relevant(question, docs)

            # Step 2: Generate answer
            answer = self._generate(question, context)

            # Step 3: Self-critique
            support = self._check_support(answer, context)
            usefulness = self._check_usefulness(question, answer)

            # Step 4: Decide next action
            if support.is_supported and usefulness.is_useful:
                return {
                    "answer": answer,
                    "support_score": support.support_score,
                    "usefulness_score": usefulness.usefulness_score,
                    "iterations": iteration + 1,
                    "context_used": len(context)
                }

            # Need to improve - either retrieve more or regenerate
            if not support.is_supported:
                # Retrieve more context for unsupported claims
                for claim in support.unsupported_claims[:2]:
                    new_docs = self._retrieve(claim)
                    context.extend(self._filter_relevant(claim, new_docs))

            iteration += 1

        # Return best effort
        return {
            "answer": answer,
            "support_score": support.support_score,
            "usefulness_score": usefulness.usefulness_score,
            "iterations": iteration,
            "context_used": len(context),
            "warning": "Max iterations reached"
        }

    def _assess_retrieval_need(self, question: str) -> RetrievalNeed:
        """Decide if retrieval is needed for this question."""
        response = self.client.beta.chat.completions.parse(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """Assess if external retrieval is needed to answer this question.
Retrieval IS needed for: specific facts, recent information, domain-specific knowledge.
Retrieval is NOT needed for: general knowledge, simple reasoning, opinions."""
            }, {
                "role": "user",
                "content": question
            }],
            response_format=RetrievalNeed
        )
        return response.choices[0].message.parsed

    def _retrieve(self, query: str, n: int = 5) -> list[str]:

    def _filter_relevant(self, question: str, docs: list[str]) -> list[str]:
```

### Corrective RAG (CRAG)

CRAG adds error detection and correction to the RAG pipeline. When retrieval quality is poor, it falls back to alternative strategies like web search:

<Mermaid
  chart={`
flowchart TB
    Q[User Question] --> RET[Retrieve from Knowledge Base]
    RET --> EVAL{Evaluate Retrieval Quality}
    
    EVAL -->|Correct| USE[Use Retrieved Docs]
    EVAL -->|Ambiguous| REFINE[Refine + Augment]
    EVAL -->|Incorrect| FALLBACK[Web Search Fallback]
    
    REFINE --> DECOMP[Decompose Query]
    DECOMP --> RET2[Re-retrieve]
    RET2 --> USE
    
    FALLBACK --> WEB[Search Web]
    WEB --> FILTER[Filter & Verify]
    FILTER --> USE
    
    USE --> GEN[Generate Answer]
    GEN --> VERIFY{Verify Grounding}
    VERIFY -->|Grounded| RESPOND[Final Response]
    VERIFY -->|Not Grounded| FALLBACK
    
    style EVAL fill:#e1bee7,stroke:#333
    style FALLBACK fill:#ffcdd2,stroke:#333
    style VERIFY fill:#c8e6c9,stroke:#333
`}
/>

```python
from typing import Literal
from pydantic import BaseModel, Field
import requests

class RetrievalQuality(BaseModel):
    """Assess retrieval quality."""
    quality: Literal["correct", "ambiguous", "incorrect"]
    confidence: float = Field(ge=0, le=1)
    reasoning: str

class CRAGPipeline:
    """
    Corrective RAG: Detect retrieval errors and apply corrections.
    Falls back to web search when knowledge base retrieval fails.
    """

    def __init__(self, client: OpenAI, collection, web_search_api_key: str = None):
        self.client = client
        self.collection = collection
        self.web_api_key = web_search_api_key

    def query(self, question: str) -> dict:
        """Run CRAG pipeline with error correction."""

        # Step 1: Initial retrieval
        docs = self._retrieve(question)

        # Step 2: Evaluate retrieval quality
        quality = self._evaluate_retrieval(question, docs)

        # Step 3: Apply corrective action based on quality
        if quality.quality == "correct":
            # Good retrieval - use directly
            context = docs
            source = "knowledge_base"

        elif quality.quality == "ambiguous":
            # Partial match - refine and augment
            refined_docs = self._refine_retrieval(question, docs)
            context = docs + refined_docs
            source = "knowledge_base_refined"

        else:  # incorrect
            # Poor retrieval - fall back to web search
            if self.web_api_key:
                web_results = self._web_search(question)
                context = self._filter_web_results(question, web_results)
                source = "web_search"
            else:
                # No web search available - try query decomposition
                context = self._decompose_and_retrieve(question)
                source = "decomposed_retrieval"

        # Step 4: Generate answer
        answer = self._generate(question, context)

        # Step 5: Verify grounding
        is_grounded = self._verify_grounding(answer, context)

        return {
            "answer": answer,
            "source": source,
            "retrieval_quality": quality.quality,
            "confidence": quality.confidence,
            "grounded": is_grounded,
            "context_count": len(context)
        }

    def _retrieve(self, query: str, n: int = 5) -> list[str]:
        """Retrieve from knowledge base."""
        results = self.collection.query(query_texts=[query], n_results=n)
        return results["documents"][0] if results["documents"] else []

    def _evaluate_retrieval(self, question: str, docs: list[str]) -> RetrievalQuality:
        """Evaluate if retrieved documents can answer the question."""
        docs_text = "\n\n---\n\n".join(docs) if docs else "No documents retrieved."

        response = self.client.beta.chat.completions.parse(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """Evaluate retrieval quality:
- "correct": Documents contain information to fully answer the question
- "ambiguous": Documents are partially relevant but may need augmentation
- "incorrect": Documents are irrelevant or misleading for this question"""
            }, {
                "role": "user",
                "content": f"Question: {question}\n\nRetrieved Documents:\n{docs_text}"
            }],
            response_format=RetrievalQuality
        )
        return response.choices[0].message.parsed

    def _refine_retrieval(self, question: str, initial_docs: list[str]) -> list[str]:
        """Refine retrieval with query reformulation."""
        # Generate alternative queries
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": "Generate 2 alternative search queries that might find missing information."
            }, {
                "role": "user",
                "content": f"Original question: {question}\nPartially relevant docs found. Generate alternative queries."
            }]
        )

        alt_queries = response.choices[0].message.content.strip().split("\n")
        additional_docs = []
        for q in alt_queries[:2]:
            docs = self._retrieve(q.strip(), n=3)
            additional_docs.extend(docs)

        return additional_docs

    def _web_search(self, query: str) -> list[dict]:
        """Search the web for information (using Tavily, Serper, or similar)."""
        # Example using a generic web search API
        # Replace with your preferred search API
        try:
            response = requests.post(
                "https://api.tavily.com/search",
                json={"query": query, "max_results": 5},
                headers={"Authorization": f"Bearer {self.web_api_key}"}
            )
            return response.json().get("results", [])
        except Exception:
            return []

    def _filter_web_results(self, question: str, results: list[dict]) -> list[str]:
        """Filter and extract relevant content from web results."""
        filtered = []
        for result in results:
            content = result.get("content", result.get("snippet", ""))
            if content:
                # Verify relevance
                response = self.client.chat.completions.create(
                    model="gpt-4o-mini",
                    messages=[{
                        "role": "system",
                        "content": "Is this web result relevant to the question? Reply YES or NO."
                    }, {
                        "role": "user",
                        "content": f"Question: {question}\n\nWeb result: {content[:500]}"
                    }]
                )
                if "YES" in response.choices[0].message.content.upper():
                    filtered.append(content)
        return filtered

    def _decompose_and_retrieve(self, question: str) -> list[str]:
        """Decompose question and retrieve for each part."""
        # Generate sub-questions
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": "Break this question into 2-3 simpler sub-questions."
            }, {
                "role": "user",
                "content": question
            }]
        )

        sub_questions = response.choices[0].message.content.strip().split("\n")
        all_docs = []
        for sq in sub_questions[:3]:
            docs = self._retrieve(sq.strip(), n=3)
            all_docs.extend(docs)

        return list(set(all_docs))  # Deduplicate

    def _generate(self, question: str, context: list[str]) -> str:
        """Generate answer from context."""
        ctx = "\n\n".join(context) if context else "No context available."
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": "Answer based on the provided context. Cite sources when possible."
            }, {
                "role": "user",
                "content": f"Context:\n{ctx}\n\nQuestion: {question}"
            }]
        )
        return response.choices[0].message.content

    def _verify_grounding(self, answer: str, context: list[str]) -> bool:
        """Verify answer is grounded in context."""
        ctx = "\n\n".join(context)
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": "Is this answer fully supported by the context? Reply YES or NO."
            }, {
                "role": "user",
                "content": f"Context:\n{ctx}\n\nAnswer:\n{answer}"
            }]
        )
        return "YES" in response.choices[0].message.content.upper()
```

<Callout type="warning">
  **CRAG Web Search**: Web search fallback requires an API key (Tavily, Serper,
  or similar). Without it, CRAG falls back to query decomposition. Always verify
  web results for accuracy before including them in context.
</Callout>

### Multi-hop Reasoning

Multi-hop RAG handles complex questions that require chaining multiple retrievals and reasoning across documents:

<Mermaid
  chart={`
flowchart LR
    Q["Who founded the company<br/>that made the iPhone?"]
    
    Q --> HOP1[Hop 1: What company made iPhone?]
    HOP1 --> R1[Retrieved: Apple Inc.]
    
    R1 --> HOP2[Hop 2: Who founded Apple?]
    HOP2 --> R2[Retrieved: Steve Jobs,<br/>Steve Wozniak, Ronald Wayne]
    
    R2 --> SYNTH[Synthesize]
    SYNTH --> A["Steve Jobs, Steve Wozniak,<br/>and Ronald Wayne"]
    
    style HOP1 fill:#e1bee7
    style HOP2 fill:#bbdefb
    style SYNTH fill:#c8e6c9
`}
/>

```python
from typing import List, Optional
from pydantic import BaseModel, Field

class ReasoningStep(BaseModel):
    """A single reasoning step in multi-hop retrieval."""
    question: str
    retrieved_info: str
    extracted_entities: list[str]
    next_question: Optional[str] = None

class MultiHopRAG:
    """
    Multi-hop RAG: Chain retrievals for complex questions.
    Extracts entities and follows relationships across documents.
    """

    def __init__(self, client: OpenAI, collection):
        self.client = client
        self.collection = collection

    def query(self, question: str, max_hops: int = 3) -> dict:
        """Execute multi-hop reasoning."""
        reasoning_chain: List[ReasoningStep] = []
        current_question = question
        accumulated_context = []

        for hop in range(max_hops):
            # Retrieve for current question
            docs = self._retrieve(current_question)
            accumulated_context.extend(docs)

            # Extract relevant information and entities
            step = self._reason_step(
                original_question=question,
                current_question=current_question,
                retrieved_docs=docs,
                previous_steps=reasoning_chain
            )
            reasoning_chain.append(step)

            # Check if we can answer or need another hop
            if step.next_question is None:
                break

            current_question = step.next_question

        # Synthesize final answer from all hops
        answer = self._synthesize(question, reasoning_chain)

        return {
            "answer": answer,
            "hops": len(reasoning_chain),
            "reasoning_chain": [
                {"question": s.question, "info": s.retrieved_info[:200]}
                for s in reasoning_chain
            ]
        }

    def _retrieve(self, query: str, n: int = 3) -> list[str]:
        """Retrieve documents for a query."""
        results = self.collection.query(query_texts=[query], n_results=n)
        return results["documents"][0] if results["documents"] else []

    def _reason_step(
        self,
        original_question: str,
        current_question: str,
        retrieved_docs: list[str],
        previous_steps: list[ReasoningStep]
    ) -> ReasoningStep:
        """Perform one reasoning step."""
        docs_text = "\n\n".join(retrieved_docs)
        prev_context = "\n".join([
            f"- {s.question}: {s.retrieved_info}"
            for s in previous_steps
        ]) if previous_steps else "None"

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """You are performing multi-hop reasoning.
Given the original question, current sub-question, and retrieved documents:
1. Extract the key information that answers the current question
2. Identify important entities (people, places, concepts)
3. Determine if another retrieval is needed to answer the original question
4. If yes, formulate the next question to search for

Return JSON:
{
    "retrieved_info": "key information extracted",
    "extracted_entities": ["entity1", "entity2"],
    "can_answer_original": true/false,
    "next_question": "follow-up question or null if can answer"
}"""
            }, {
                "role": "user",
                "content": f"""Original question: {original_question}
Current question: {current_question}
Previous findings: {prev_context}

Retrieved documents:
{docs_text}"""
            }],
            response_format={"type": "json_object"}
        )

        data = json.loads(response.choices[0].message.content)

        return ReasoningStep(
            question=current_question,
            retrieved_info=data["retrieved_info"],
            extracted_entities=data["extracted_entities"],
            next_question=data.get("next_question")
        )

    def _synthesize(self, question: str, chain: list[ReasoningStep]) -> str:
        """Synthesize final answer from reasoning chain."""
        chain_summary = "\n\n".join([
            f"Step {i+1} - {step.question}:\n{step.retrieved_info}"
            for i, step in enumerate(chain)
        ])

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": "Synthesize a complete answer from the multi-hop reasoning chain."
            }, {
                "role": "user",
                "content": f"Question: {question}\n\nReasoning chain:\n{chain_summary}"
            }]
        )
        return response.choices[0].message.content
```

<Callout type="tip">
  **Multi-hop Use Cases**: Multi-hop RAG excels at questions requiring entity
  linking ("Who is the CEO of the company that acquired Twitter?") or temporal
  reasoning ("What happened after the merger was announced?"). It's overkill for
  simple factual lookups.
</Callout>

### Query Decomposition

Break complex queries into simpler sub-queries, retrieve in parallel, and synthesize results:

<Mermaid

    Q --> DECOMP{Decompose}
    
    DECOMP --> SQ1["Python web frameworks<br/>and performance"]
    DECOMP --> SQ2["Rust web frameworks<br/>and performance"]
    DECOMP --> SQ3["Python vs Rust<br/>developer experience"]
    
    SQ1 --> R1[Retrieve]
    SQ2 --> R2[Retrieve]
    SQ3 --> R3[Retrieve]
    
    R1 --> SYNTH[Synthesize Comparison]

```python
from typing import List
from pydantic import BaseModel, Field
from concurrent.futures import ThreadPoolExecutor, as_completed

class SubQuery(BaseModel):
    """A decomposed sub-query."""
    query: str
    purpose: str = Field(description="What this sub-query aims to find")

class DecomposedQueries(BaseModel):
    """Result of query decomposition."""
    sub_queries: List[SubQuery]
    synthesis_strategy: str = Field(description="How to combine results")

class QueryDecompositionRAG:
    """
    Query Decomposition RAG: Break complex queries into sub-queries,
    retrieve in parallel, and synthesize results.
    """

    def __init__(self, client: OpenAI, collection):
        self.client = client
        self.collection = collection

    def query(self, question: str) -> dict:
        """Execute query decomposition RAG."""

        # Step 1: Decompose the query
        decomposition = self._decompose(question)

        # Step 2: Retrieve for each sub-query in parallel
        sub_results = self._parallel_retrieve(decomposition.sub_queries)

        # Step 3: Synthesize results
        answer = self._synthesize(
            question,
            sub_results,
            decomposition.synthesis_strategy
        )

        return {
            "answer": answer,
            "sub_queries": [sq.query for sq in decomposition.sub_queries],
            "synthesis_strategy": decomposition.synthesis_strategy,
            "total_docs_retrieved": sum(len(r["docs"]) for r in sub_results)
        }

    def _decompose(self, question: str) -> DecomposedQueries:
        """Decompose a complex question into sub-queries."""
        response = self.client.beta.chat.completions.parse(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """Decompose this complex question into 2-4 simpler sub-queries.
Each sub-query should:
- Be self-contained and searchable
- Address a specific aspect of the original question
- Together, cover all aspects needed to answer the original

Also specify how to synthesize the results (e.g., "compare", "combine", "sequence")."""
            }, {
                "role": "user",
                "content": question
            }],
            response_format=DecomposedQueries
        )
        return response.choices[0].message.parsed

    def _parallel_retrieve(self, sub_queries: List[SubQuery]) -> List[dict]:
        """Retrieve for all sub-queries in parallel."""
        results = []

        with ThreadPoolExecutor(max_workers=4) as executor:
            futures = {
                executor.submit(self._retrieve_for_subquery, sq): sq
                for sq in sub_queries
            }

            for future in as_completed(futures):
                sq = futures[future]
                docs = future.result()
                results.append({
                    "query": sq.query,
                    "purpose": sq.purpose,
                    "docs": docs
                })

        return results

    def _retrieve_for_subquery(self, sq: SubQuery) -> list[str]:
        """Retrieve documents for a single sub-query."""
        results = self.collection.query(query_texts=[sq.query], n_results=3)
        return results["documents"][0] if results["documents"] else []

    def _synthesize(
        self,
        original_question: str,
        sub_results: List[dict],
        strategy: str
    ) -> str:
        """Synthesize final answer from sub-query results."""
        # Format sub-results
        formatted_results = []
        for r in sub_results:
            docs_text = "\n".join(r["docs"][:2])  # Limit docs per sub-query
            formatted_results.append(
                f"### {r['purpose']}\nQuery: {r['query']}\nFindings:\n{docs_text}"
            )

        all_results = "\n\n".join(formatted_results)

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": f"""Synthesize a comprehensive answer using the '{strategy}' approach.
Combine information from all sub-query results to fully answer the original question.
Ensure the answer is coherent and addresses all aspects of the question."""
            }, {
                "role": "user",
                "content": f"Original question: {original_question}\n\nSub-query results:\n{all_results}"
            }]
        )
        return response.choices[0].message.content


# Example usage
decomp_rag = QueryDecompositionRAG(client, collection)

# Complex comparison question
result = decomp_rag.query(
    "Compare the authentication approaches in Django, FastAPI, and Express.js"
)
print(f"Sub-queries used: {result['sub_queries']}")
print(f"Answer: {result['answer']}")
```

<Callout type="info">
  **Parallel Retrieval**: Query decomposition enables parallel retrieval,
  reducing latency for complex questions. A question decomposed into 3
  sub-queries can be answered in roughly the same time as a single query, while
  gathering 3x more relevant context.
</Callout>

### Choosing the Right RAG Pattern

| Pattern                 | Best For                           | Trade-offs                                |
| :---------------------- | :--------------------------------- | :---------------------------------------- |
| **Basic RAG**           | Simple Q&A, documentation          | Fast, simple, but limited context         |
| **Hybrid Search**       | Mixed queries (exact + semantic)   | Slightly more complex, better recall      |
| **Reranking**           | High-precision needs               | Adds latency, improves top-k quality      |
| **HyDE**                | Short queries, technical docs      | Extra LLM call, better query matching     |
| **RAPTOR**              | Multi-hop questions, long docs     | High indexing cost, great for synthesis   |
| **GraphRAG**            | Relationship questions, themes     | Expensive to build, corpus-level insights |
| **Agentic RAG**         | Complex, multi-step research       | Most flexible, requires good prompting    |
| **Self-RAG**            | High-accuracy, critical answers    | 3-4x LLM calls, catches hallucinations    |
| **CRAG**                | Unreliable retrieval, web fallback | Adds complexity, robust error handling    |
| **Multi-hop**           | Entity linking, chained facts      | Multiple retrievals, reasoning overhead   |
| **Query Decomposition** | Complex comparisons, analysis      | Parallel retrieval, synthesis required    |

<Callout type="info">
  **Start Simple**: Begin with basic RAG + reranking. Add hybrid search if you
  have exact-match needs. Consider HyDE for technical documentation. Use RAPTOR
  or GraphRAG only when you need corpus-level understanding or multi-hop
  reasoning. For production systems requiring high accuracy, consider Self-RAG
  or CRAG for self-correction capabilities.
</Callout>

## Connection to Structured Output

RAG and structured output work together in production systems. While RAG retrieves relevant context, structured output ensures the generated response follows a predictable format:

```python
from pydantic import BaseModel, Field
from langchain_openai import ChatOpenAI

class RAGAnswer(BaseModel):
    """Structured response from RAG system."""
    answer: str = Field(description="Direct answer to the question")
    confidence: float = Field(ge=0, le=1, description="Confidence score")
    sources: list[str] = Field(description="Source documents cited")

def structured_rag_query(question: str, context: str) -> RAGAnswer:
    """RAG query with structured output."""
    llm = ChatOpenAI(model="gpt-4o-mini")
    structured_llm = llm.with_structured_output(RAGAnswer)

    prompt = f"""Answer based on the context. Cite your sources.

Context:
{context}

Question: {question}"""

    return structured_llm.invoke(prompt)
```
