## 65.1 Voice Agent Architecture

The classic voice agent follows a three-stage pipeline: **Speech-to-Text (STT) → LLM → Text-to-Speech (TTS)**. Understanding this pipeline is essential for optimizing latency and quality.

### Latency Breakdown

For natural conversation, total round-trip latency should be **under 500ms**. Here's how the budget typically breaks down:

| Stage       | Target Latency | What Affects It                     |
| :---------- | :------------- | :---------------------------------- |
| **VAD**     | 20-50ms        | Sensitivity settings, buffer size   |
| **STT**     | 100-300ms      | Model size, streaming vs batch      |
| **LLM**     | 200-400ms      | Model size, prompt length, provider |
| **TTS**     | 50-150ms       | Voice quality, streaming support    |
| **Network** | 20-100ms       | Edge deployment, connection quality |

<Callout type="warning">
  **The 500ms Rule:** Human conversation has natural pauses of 200-500ms between
  turns. Exceed 500ms response time and users perceive the agent as "slow" or
  "thinking." Exceed 1 second and they start repeating themselves.
</Callout>

### Cascaded vs End-to-End Approaches

Two architectural patterns dominate voice agent design:

**Cascaded (STT → LLM → TTS):**

- Modular, each component independently optimizable
- Can use best-in-class for each stage
- Higher total latency due to sequential processing
- Text intermediate enables logging, moderation, tool calling

**End-to-End (Speech-to-Speech):**

- Single model handles audio in and out
- Lower latency, more natural prosody
- Harder to debug, less control over intermediate steps
- Examples: OpenAI Realtime API, Gemini Live

```python
# Cascaded approach - explicit pipeline
async def cascaded_voice_agent(audio_input: bytes) -> bytes:
    # Stage 1: Speech to Text
    transcript = await stt_model.transcribe(audio_input)

    # Stage 2: LLM Processing (can add tools, RAG, etc.)
    response_text = await llm.generate(transcript)

    # Stage 3: Text to Speech
    audio_output = await tts_model.synthesize(response_text)

    return audio_output

# End-to-end approach - single model
async def e2e_voice_agent(audio_input: bytes) -> bytes:
    # Single model handles everything
    audio_output = await realtime_model.process(audio_input)
    return audio_output
```

## 65.2 Speech-to-Text Options

Choosing the right STT provider depends on your latency requirements, accuracy needs, language support, and deployment constraints.

### OpenAI Whisper

Whisper is the gold standard for accuracy and the most versatile option. Available both as an API and for local deployment.

```python
from openai import OpenAI

client = OpenAI()

# API usage - simple but adds network latency
def transcribe_with_whisper_api(audio_file: str) -> str:
    with open(audio_file, "rb") as f:
        transcript = client.audio.transcriptions.create(
            model="whisper-1",
            file=f,
            response_format="text"
        )
    return transcript

# Local usage with faster-whisper (optimized implementation)
from faster_whisper import WhisperModel

model = WhisperModel("large-v3", device="cuda", compute_type="float16")

def transcribe_local(audio_path: str) -> str:
    segments, info = model.transcribe(audio_path, beam_size=5)
    return " ".join([segment.text for segment in segments])
```

### Qwen3-ASR for Local/Private Deployments

For on-premise or privacy-sensitive deployments, Qwen3-ASR provides excellent accuracy without cloud dependencies.

```python
from transformers import AutoModelForSpeechSeq2Seq, AutoProcessor
import torch

model_id = "Qwen/Qwen2-Audio-7B"
device = "cuda" if torch.cuda.is_available() else "cpu"

processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForSpeechSeq2Seq.from_pretrained(
    model_id,
    torch_dtype=torch.float16,
    device_map="auto"
)

def transcribe_local_qwen(audio_array, sampling_rate=16000):
    inputs = processor(
        audio_array,
        sampling_rate=sampling_rate,
        return_tensors="pt"
    ).to(device)

    generated_ids = model.generate(**inputs, max_new_tokens=256)
    transcription = processor.batch_decode(
        generated_ids,
        skip_special_tokens=True
    )[0]

    return transcription
```

## 65.3 Text-to-Speech Synthesis

TTS is the final mile of voice agents—where quality directly impacts user perception. Modern TTS has achieved near-human naturalness, but latency and cost vary significantly.

### ElevenLabs (Quality Leader)

ElevenLabs produces the most natural-sounding voices with excellent emotional range and prosody control.

```python
from elevenlabs import ElevenLabs, Voice, VoiceSettings

client = ElevenLabs(api_key="your-api-key")

def synthesize_speech(text: str, voice_id: str = "Rachel") -> bytes:
    audio = client.generate(
        text=text,
        voice=Voice(
            voice_id=voice_id,
            settings=VoiceSettings(
                stability=0.5,
                similarity_boost=0.75,
                style=0.5,
                use_speaker_boost=True
            )
        ),
        model="eleven_turbo_v2_5"  # Optimized for low latency
    )
    return b"".join(audio)

# Streaming for lower time-to-first-byte
async def stream_speech(text: str):
    async for chunk in client.generate_stream(
        text=text,
        voice="Rachel",
        model="eleven_turbo_v2_5",
        stream=True
    ):
        yield chunk
```

## 65.4 Real-Time Streaming Frameworks

Building voice agents from scratch is complex. These frameworks handle the hard parts: audio streaming, VAD, turn-taking, and pipeline orchestration.

### Pipecat (Open-Source, Python)

Pipecat is the leading open-source framework for building voice agents. It provides a pipeline abstraction that makes it easy to compose STT, LLM, and TTS components.

```python
import asyncio
from pipecat.frames.frames import TextFrame, AudioRawFrame
from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.runner import PipelineRunner
from pipecat.pipeline.task import PipelineTask
from pipecat.services.openai import OpenAILLMService
from pipecat.services.deepgram import DeepgramSTTService, DeepgramTTSService
from pipecat.transports.services.daily import DailyTransport

async def main():
    # Configure transport (Daily.co for WebRTC)
    transport = DailyTransport(
        room_url="https://your-domain.daily.co/room",
        token="your-token",
        bot_name="Voice Assistant"
    )

    # Configure services
    stt = DeepgramSTTService(api_key="your-deepgram-key")

    llm = OpenAILLMService(
        api_key="your-openai-key",
        model="gpt-4o-mini",
        system_prompt="""You are a helpful voice assistant.
        Keep responses concise and conversational.
        Respond in 1-2 sentences when possible."""
    )

    tts = DeepgramTTSService(
        api_key="your-deepgram-key",
        voice="aura-asteria-en"
    )

    # Build the pipeline
    pipeline = Pipeline([
        transport.input(),   # Audio from user
        stt,                 # Speech to text
        llm,                 # Generate response
        tts,                 # Text to speech
        transport.output()   # Audio to user
    ])

    # Run the pipeline
    task = PipelineTask(pipeline)
    runner = PipelineRunner()
    await runner.run(task)

if __name__ == "__main__":
    asyncio.run(main())
```

### OpenAI Realtime API (Native Speech-to-Speech)

The OpenAI Realtime API bypasses the traditional pipeline entirely, providing native speech-to-speech with the lowest possible latency.

```python
import asyncio
import websockets
import json
import base64

async def realtime_voice_agent():
    url = "wss://api.openai.com/v1/realtime?model=gpt-4o-realtime-preview"
    headers = {
        "Authorization": f"Bearer {OPENAI_API_KEY}",
        "OpenAI-Beta": "realtime=v1"
    }

    async with websockets.connect(url, extra_headers=headers) as ws:
        # Configure the session
        await ws.send(json.dumps({
            "type": "session.update",
            "session": {
                "modalities": ["text", "audio"],
                "instructions": "You are a helpful voice assistant.",
                "voice": "alloy",
                "input_audio_format": "pcm16",
                "output_audio_format": "pcm16",
                "turn_detection": {
                    "type": "server_vad",
                    "threshold": 0.5,
                    "prefix_padding_ms": 300,
                    "silence_duration_ms": 500
                }
            }
        }))

        # Handle messages
        async for message in ws:
            event = json.loads(message)

            if event["type"] == "response.audio.delta":
                # Stream audio to speaker
                audio_chunk = base64.b64decode(event["delta"])
                play_audio(audio_chunk)

            elif event["type"] == "response.audio_transcript.delta":
                # Optional: display transcript
                print(event["delta"], end="", flush=True)

            elif event["type"] == "input_audio_buffer.speech_started":
                # User started speaking - handle interruption
                await ws.send(json.dumps({"type": "response.cancel"}))

asyncio.run(realtime_voice_agent())
```

### Streaming Everything

Never wait for complete responses. Stream at every stage:

```python
import asyncio
from typing import AsyncIterator

async def streaming_voice_pipeline(
    audio_input: AsyncIterator[bytes]
) -> AsyncIterator[bytes]:
    """Fully streaming voice pipeline with minimal latency."""

    # Stream STT - get partial transcripts
    transcript_buffer = ""
    async for audio_chunk in audio_input:
        partial_transcript = await stt.transcribe_chunk(audio_chunk)
        transcript_buffer += partial_transcript

        # Check for sentence boundary
        if is_sentence_complete(transcript_buffer):
            # Stream to LLM immediately
            async for llm_chunk in llm.stream(transcript_buffer):
                # Stream to TTS immediately
                async for audio_chunk in tts.stream(llm_chunk):
                    yield audio_chunk

            transcript_buffer = ""
```

### Speculative Execution

Start generating responses before the user finishes speaking:

```python
class SpeculativeVoiceAgent:
    def __init__(self):
        self.pending_responses = {}

    async def on_partial_transcript(self, partial: str):
        """Generate speculative response on partial input."""
        # Only speculate on substantial input
        if len(partial.split()) < 3:
            return

        # Generate response speculatively
        task = asyncio.create_task(self.llm.generate(partial))
        self.pending_responses[partial] = task

    async def on_final_transcript(self, final: str):
        """Use speculative response if available, else generate fresh."""
        # Check if we have a matching speculative response
        for partial, task in self.pending_responses.items():
            if final.startswith(partial) and task.done():
                # Use speculative response
                return task.result()

        # No match - generate fresh
        return await self.llm.generate(final)
```

### Latency Budget Monitoring

Track latency at each stage to identify bottlenecks:

```python
import time
from dataclasses import dataclass
from typing import Optional

@dataclass
class LatencyMetrics:
    vad_ms: float = 0
    stt_ms: float = 0
    llm_ttfb_ms: float = 0  # Time to first byte
    llm_total_ms: float = 0
    tts_ttfb_ms: float = 0
    tts_total_ms: float = 0

    @property
    def total_ttfb(self) -> float:
        """Time from user stop speaking to first audio byte."""
        return self.vad_ms + self.stt_ms + self.llm_ttfb_ms + self.tts_ttfb_ms

    def is_acceptable(self, threshold_ms: float = 500) -> bool:
        return self.total_ttfb < threshold_ms

class LatencyTracker:
    def __init__(self):
        self.metrics = LatencyMetrics()
        self._stage_start: Optional[float] = None

    def start_stage(self):
        self._stage_start = time.perf_counter()

    def end_stage(self, stage: str):
        if self._stage_start:
            elapsed = (time.perf_counter() - self._stage_start) * 1000
            setattr(self.metrics, f"{stage}_ms", elapsed)
            self._stage_start = None
```

## 65.6 Interruption Handling

Natural conversation includes interruptions. Users expect to be able to cut off the agent mid-sentence. Handling this gracefully is critical for user experience.

<Mermaid

```python
import asyncio
from enum import Enum

class AgentState(Enum):
    LISTENING = "listening"
    THINKING = "thinking"
    SPEAKING = "speaking"

class InterruptibleVoiceAgent:
    def __init__(self):
        self.state = AgentState.LISTENING
        self.current_response_task: asyncio.Task | None = None
        self.tts_cancel_event = asyncio.Event()

    async def on_vad_speech_start(self):
        """Called when VAD detects user started speaking."""
        if self.state == AgentState.SPEAKING:
            # User is interrupting - cancel current response
            await self.handle_interruption()

    async def handle_interruption(self):
        """Gracefully handle user interruption."""
        print("🛑 Interruption detected - stopping response")

        # Signal TTS to stop
        self.tts_cancel_event.set()

        # Cancel any pending LLM generation
        if self.current_response_task:
            self.current_response_task.cancel()
            try:
                await self.current_response_task
            except asyncio.CancelledError:
                pass

        # Transition to listening
        self.state = AgentState.LISTENING
        self.tts_cancel_event.clear()

    async def speak_response(self, text: str):
        """Speak response with interruption support."""
        self.state = AgentState.SPEAKING

        async for audio_chunk in self.tts.stream(text):
            # Check for interruption before each chunk
            if self.tts_cancel_event.is_set():
                print("Response cancelled due to interruption")
                return

            await self.play_audio(audio_chunk)

        self.state = AgentState.LISTENING
```

```python
        self.user_speaking = True
        self.speech_start_time = asyncio.get_event_loop().time()

        # Cancel any pending end-of-turn timer
        if self._silence_timer:
            self._silence_timer.cancel()

        # If agent is speaking, this is an interruption
        if self.agent_speaking:
            await self.on_interruption()

        """Wait for silence to confirm end of turn."""
        await asyncio.sleep(self.config.end_of_turn_silence_ms / 1000)

        # If user hasn't started speaking again, it's our turn
```

### Verbal Acknowledgment Pattern

```python
from typing import Callable, Any
import asyncio

class VoiceToolExecutor:
    # Acknowledgment phrases for different tool types
    TOOL_ACKNOWLEDGMENTS = {
        "search": ["Let me look that up...", "Searching now...", "One moment..."],
        "book": ["I'll book that for you...", "Making that reservation..."],
        "send": ["Sending that now...", "I'll send that right away..."],
        "calculate": ["Let me calculate that...", "Working on that..."],
        "default": ["One moment...", "Let me check...", "Working on it..."]
    }

    def __init__(self, tts_callback: Callable[[str], Any]):
        self.speak = tts_callback

    async def execute_with_feedback(
        self,
        tool_name: str,
        tool_func: Callable,
        *args,
        **kwargs
    ) -> Any:
        """Execute tool with verbal feedback."""

        # Determine acknowledgment type
        tool_type = self._categorize_tool(tool_name)
        ack = random.choice(self.TOOL_ACKNOWLEDGMENTS.get(
            tool_type,
            self.TOOL_ACKNOWLEDGMENTS["default"]
        ))

        # Speak acknowledgment (non-blocking)
        speak_task = asyncio.create_task(self.speak(ack))

        # Execute tool
        result = await tool_func(*args, **kwargs)

        # Wait for acknowledgment to finish if still speaking
        await speak_task

        return result

    def _categorize_tool(self, tool_name: str) -> str:
        """Categorize tool for appropriate acknowledgment."""
        name_lower = tool_name.lower()
        if any(w in name_lower for w in ["search", "find", "lookup", "get"]):
            return "search"
        if any(w in name_lower for w in ["book", "reserve", "schedule"]):
            return "book"
        if any(w in name_lower for w in ["send", "email", "message"]):
            return "send"
        if any(w in name_lower for w in ["calculate", "compute", "analyze"]):
            return "calculate"
        return "default"
```

### Progress Updates for Long Operations

```python
class ProgressiveToolExecutor:
    """Execute tools with periodic progress updates."""

    PROGRESS_PHRASES = [
        "Still working on that...",
        "Almost there...",
        "Just a moment longer...",
        "Processing...",
    ]

    async def execute_with_progress(
        self,
        tool_func: Callable,
        timeout_seconds: float = 10,
        update_interval: float = 3,
    ) -> Any:
        """Execute tool with progress updates for long operations."""

        tool_task = asyncio.create_task(tool_func())
        progress_count = 0

        while not tool_task.done():
            try:
                # Wait for tool or timeout
                result = await asyncio.wait_for(
                    asyncio.shield(tool_task),
                    timeout=update_interval
                )
                return result
            except asyncio.TimeoutError:
                # Tool still running - give progress update
                if progress_count < len(self.PROGRESS_PHRASES):
                    await self.speak(self.PROGRESS_PHRASES[progress_count])
                    progress_count += 1

                # Check total timeout
                if progress_count * update_interval > timeout_seconds:
                    tool_task.cancel()
                    await self.speak("I'm sorry, that's taking too long. Let me try another way.")
                    raise TimeoutError("Tool execution exceeded timeout")

        return tool_task.result()
```

```python
import noisereduce as nr
import numpy as np

def preprocess_audio(audio: np.ndarray, sample_rate: int) -> np.ndarray:
    """Clean up audio before STT."""

    # Reduce background noise
    reduced = nr.reduce_noise(
        y=audio,
        sr=sample_rate,
        stationary=True,
        prop_decrease=0.75
    )

    # Normalize volume
    max_val = np.max(np.abs(reduced))
    if max_val > 0:
        reduced = reduced / max_val * 0.95

    return reduced

# For real-time, use a simpler approach
def simple_noise_gate(audio: np.ndarray, threshold: float = 0.02) -> np.ndarray:
    """Simple noise gate for real-time processing."""
    mask = np.abs(audio) > threshold
    return audio * mask
```

### Cost Optimization

Voice agents can be expensive. Here's how to optimize:

```python
from dataclasses import dataclass

@dataclass
class CostMetrics:
    stt_seconds: float = 0
    llm_tokens: int = 0
    tts_characters: int = 0

    @property
    def estimated_cost(self) -> float:
        """Estimate cost in USD."""
        stt_cost = self.stt_seconds * 0.006 / 60  # Whisper: $0.006/min
        llm_cost = self.llm_tokens * 0.00001     # GPT-4o-mini estimate
        tts_cost = self.tts_characters * 0.000015  # OpenAI TTS
        return stt_cost + llm_cost + tts_cost

class CostOptimizedAgent:
    """Voice agent with cost controls."""

    def __init__(self, daily_budget: float = 10.0):
        self.daily_budget = daily_budget
        self.daily_cost = 0.0
        self.metrics = CostMetrics()

    async def process_with_budget(self, audio: bytes) -> str:
        """Process request with budget awareness."""

        # Check budget before processing
        if self.daily_cost >= self.daily_budget:
            return "I've reached my daily limit. Please try again tomorrow."

        # Use cheaper models when budget is tight
        remaining = self.daily_budget - self.daily_cost

        if remaining < 1.0:
            # Switch to cheaper options
            self.llm_model = "gpt-4o-mini"
            self.tts_model = "tts-1"  # vs tts-1-hd

        # Process and track costs
        result = await self._process(audio)
        self.daily_cost += self.metrics.estimated_cost

        return result

    def optimize_response_length(self, response: str, max_chars: int = 200) -> str:
        """Truncate responses to control TTS costs."""
        if len(response) > max_chars:
            # Find natural break point
            truncated = response[:max_chars]
            last_period = truncated.rfind('.')
            if last_period > max_chars * 0.5:
                return truncated[:last_period + 1]
        return response
```

7. **Tool calling**: Verbal acknowledgments, progress updates, natural responses
8. **Production concerns**: VAD tuning, noise handling, accessibility, cost control
