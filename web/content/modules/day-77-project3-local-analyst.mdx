## Project Overview

**Objective**: Build a data analysis agent that runs entirely within a secure perimeter, analyzing sensitive financial data without ever sending raw data to external LLM APIs.

**Why This Matters**: Regulated industries (finance, healthcare) cannot use tools like ChatGPT's Data Analyst because uploading customer data violates GDPR/HIPAA. This project shows how to build compliant AI systems.

**Skills Showcased**:

- Privacy-preserving architecture
- Secure code execution (sandboxing)
- Local LLM deployment
- Schema-based reasoning

### Acceptance Criteria

#### US-01: Natural Language Queries

- **Given** a user loads a CSV/Parquet dataset
- **When** they ask a natural language question (e.g., "What's the average revenue by region?")
- **Then** the system:
  - Extracts schema from the dataset
  - Generates appropriate pandas/matplotlib code
  - Executes the code and returns results
  - Provides a natural language summary of findings

#### US-02: Data Privacy Guarantee

- **Given** a dataset is loaded
- **When** the LLM is invoked
- **Then** the system:
  - Sends ONLY schema information (column names, types, row count)
  - NEVER sends actual data values to the LLM
  - Logs can be audited to verify no data leakage

#### US-03: Visualization Generation

- **Given** a user requests a visualization (e.g., "Plot sales over time")
- **When** the analysis completes
- **Then** the system:
  - Generates matplotlib/seaborn code
  - Saves chart to `output.png`
  - Returns the chart as base64 or file path

#### US-04: Code Validation

- **Given** the LLM generates Python code
- **When** the code is about to execute
- **Then** the system:
  - Parses code with AST
  - Blocks forbidden imports (os, sys, subprocess, requests, etc.)
  - Blocks forbidden functions (exec, eval, open, **import**, etc.)
  - Rejects code that fails validation with clear error message

#### US-05: Local LLM Support

- **Given** the user configures `USE_LOCAL_LLM=true`
- **When** analysis is requested
- **Then** the system:
  - Uses Ollama with codellama or mistral model
  - All processing happens on local machine
  - No network calls to external LLM APIs

#### US-06: Document RAG

- **Given** the user loads documents into LanceDB
- **When** they ask a question about document content
- **Then** the system:
  - Uses local embeddings (sentence-transformers)
  - Retrieves relevant chunks from LanceDB
  - Generates answer based on retrieved context

#### US-07: Schema Anonymization

- **Given** anonymization is enabled
- **When** schema is sent to LLM
- **Then** the system:
  - Replaces column names with generic labels (column_0, column_1, etc.)
  - Maintains a mapping for de-anonymization
  - De-anonymizes generated code before execution

| `LoadingData`       | Reading CSV/Parquet file         | 30s     | → DataReady, Error                   |

### Tool Specifications

#### Tool: `extract_safe_schema`

| Attribute            | Value                                                                      |
| :------------------- | :------------------------------------------------------------------------- |
| **Purpose**          | Extract schema without exposing data values                                |
| **Input**            | `df: pd.DataFrame`                                                         |
| **Output**           | `{columns: [{name, dtype, null_count, unique_count, example}], row_count}` |
| **Privacy**          | Examples are synthetic (e.g., "[text value]", "123.45")                    |
| **Error Conditions** | Empty dataframe → return minimal schema                                    |

#### Tool: `anonymize_schema`

| Attribute            | Value                                         |
| :------------------- | :-------------------------------------------- |
| **Purpose**          | Replace column names with generic labels      |
| **Input**            | `schema: dict`                                |
| **Output**           | `{anonymized_schema: dict, column_map: dict}` |
| **Mapping**          | `{"column_0": "original_name", ...}`          |
| **Error Conditions** | None expected                                 |

#### Tool: `generate_analysis_code`

| Attribute              | Value                                               |
| :--------------------- | :-------------------------------------------------- |
| **Purpose**            | Generate pandas code from schema and query          |
| **Input**              | `schema: dict, query: str`                          |
| **Output**             | `str` (Python code)                                 |
| **Model**              | gpt-4o (API) or codellama:13b (local)               |
| **Prompt Constraints** | Must use `df` variable, save charts to `output.png` |
| **Error Conditions**   | Invalid response → retry with clarification         |

#### Tool: `validate_code`

| Attribute               | Value                                                                             |
| :---------------------- | :-------------------------------------------------------------------------------- |
| **Purpose**             | Check code for security issues                                                    |
| **Input**               | `code: str`                                                                       |
| **Output**              | `{is_valid: bool, message: str}`                                                  |
| **Forbidden Imports**   | os, sys, subprocess, socket, requests, urllib, http, ftplib, smtplib, pickle      |
| **Forbidden Functions** | exec, eval, compile, open, **import**, getattr, setattr, delattr, globals, locals |
| **Error Conditions**    | Syntax error → return invalid with parse error                                    |

#### Tool: `execute_in_sandbox`

| Attribute            | Value                                                      |
| :------------------- | :--------------------------------------------------------- |
| **Purpose**          | Run validated code in isolated environment                 |
| **Input**            | `code: str, data_path: str`                                |
| **Output**           | `{output: str, error: str, chart: base64}`                 |
| **Sandbox**          | E2B Code Interpreter (production) or restricted exec (dev) |
| **Timeout**          | 60 seconds                                                 |
| **Error Conditions** | Timeout → kill process, return error                       |

#### Tool: `summarize_results`

| Attribute            | Value                                        |
| :------------------- | :------------------------------------------- |
| **Purpose**          | Convert execution output to natural language |
| **Input**            | `query: str, output: str`                    |
| **Output**           | `str` (natural language summary)             |
| **Model**            | gpt-4o or local LLM                          |
| **Error Conditions** | Empty output → return "No results found"     |

```python
import pandas as pd

def extract_safe_schema(df: pd.DataFrame) -> dict:
    """Extract schema without exposing actual data."""
    schema = {
        "columns": [],
        "row_count": len(df),
        "sample_values": {}  # Synthetic examples only
    }

    for col in df.columns:
        col_info = {
            "name": col,
            "dtype": str(df[col].dtype),
            "null_count": int(df[col].isnull().sum()),
            "unique_count": int(df[col].nunique())
        }

        # Add synthetic examples based on dtype
        if df[col].dtype == 'object':
            col_info["example"] = "[text value]"
        elif df[col].dtype in ['int64', 'float64']:
            col_info["example"] = "123.45"
            col_info["min"] = float(df[col].min())
            col_info["max"] = float(df[col].max())
        elif df[col].dtype == 'datetime64[ns]':
            col_info["example"] = "2024-01-15"

        schema["columns"].append(col_info)

    return schema

# Usage
df = pd.read_csv("sensitive_transactions.csv")
schema = extract_safe_schema(df)

# Schema contains NO actual values, just structure
print(json.dumps(schema, indent=2))
```

```python
import ast
import re
import base64
from typing import Tuple, List

class EnhancedCodeValidator:
    """Advanced code validation with exfiltration detection."""

    FORBIDDEN_IMPORTS = {
        # Network
        'os', 'sys', 'subprocess', 'socket', 'requests', 'urllib',
        'http', 'ftplib', 'smtplib', 'httpx', 'aiohttp',
        # Serialization (data exfil vectors)
        'pickle', 'shelve', 'marshal', 'dill',
        # System access
        'ctypes', 'multiprocessing', 'threading', 'signal',
        # Code execution
        'importlib', 'builtins', 'code', 'codeop',
        # File operations
        'pathlib', 'shutil', 'tempfile', 'glob',
    }

    FORBIDDEN_FUNCTIONS = {
        'exec', 'eval', 'compile', 'open', '__import__',
        'getattr', 'setattr', 'delattr', 'globals', 'locals',
        'vars', 'dir', 'breakpoint', 'input', 'help',
    }

    # Patterns that suggest data exfiltration via encoding
    EXFIL_PATTERNS = [
        r'base64\.b64encode',
        r'\.encode\([\'"]hex[\'"]\)',
        r'binascii\.',
        r'codecs\.encode',
        r'zlib\.compress',
        r'gzip\.compress',
        r'\.to_json\(\)',  # DataFrame to JSON (potential exfil)
        r'\.to_dict\(\)',  # DataFrame to dict
        r'json\.dumps.*df',  # Serializing dataframe
    ]

    # Suspicious string patterns (DNS exfil, encoded data)
    SUSPICIOUS_STRINGS = [
        r'[a-zA-Z0-9+/]{50,}={0,2}',  # Base64-like strings
        r'\\x[0-9a-fA-F]{2}',  # Hex escape sequences
        r'0x[0-9a-fA-F]+',  # Hex literals
    ]

    def validate(self, code: str) -> Tuple[bool, str, List[str]]:
        """
        Validate code with detailed warnings.
        Returns: (is_valid, message, warnings)
        """
        warnings = []

        # 1. Syntax check
        try:
            tree = ast.parse(code)
        except SyntaxError as e:
            return False, f"Syntax error: {e}", []

        # 2. AST-based checks
        for node in ast.walk(tree):
            # Import checks
            if isinstance(node, ast.Import):
                for alias in node.names:
                    module = alias.name.split('.')[0]
                    if module in self.FORBIDDEN_IMPORTS:
                        return False, f"Forbidden import: {alias.name}", warnings

            if isinstance(node, ast.ImportFrom):
                if node.module:
                    module = node.module.split('.')[0]
                    if module in self.FORBIDDEN_IMPORTS:
                        return False, f"Forbidden import: {node.module}", warnings

            # Function call checks
            if isinstance(node, ast.Call):
                func_name = self._get_func_name(node)
                if func_name in self.FORBIDDEN_FUNCTIONS:
                    return False, f"Forbidden function: {func_name}", warnings

                # Check for attribute access patterns (e.g., df.to_csv)
                if isinstance(node.func, ast.Attribute):
                    if node.func.attr in ['to_csv', 'to_excel', 'to_parquet']:
                        # Allow only output.png, block data export
                        warnings.append(f"Data export detected: {node.func.attr}")

            # String literal checks (embedded payloads)
            if isinstance(node, ast.Constant) and isinstance(node.value, str):
                for pattern in self.SUSPICIOUS_STRINGS:
                    if re.search(pattern, node.value):
                        warnings.append(f"Suspicious string pattern detected")
                        break

        # 3. Regex-based exfiltration pattern checks
        for pattern in self.EXFIL_PATTERNS:
            if re.search(pattern, code):
                return False, f"Potential data exfiltration pattern: {pattern}", warnings

        # 4. Check for dynamic attribute access
        if re.search(r'__\w+__', code):
            dunder_matches = re.findall(r'__\w+__', code)
            allowed_dunders = {'__name__', '__doc__', '__init__'}
            for match in dunder_matches:
                if match not in allowed_dunders:
                    return False, f"Forbidden dunder access: {match}", warnings

        return True, "Code validated successfully", warnings

    def _get_func_name(self, node: ast.Call) -> str:
        """Extract function name from Call node."""
        if isinstance(node.func, ast.Name):
            return node.func.id
        elif isinstance(node.func, ast.Attribute):
            return node.func.attr
        return ""

# Usage
validator = EnhancedCodeValidator()
is_valid, message, warnings = validator.validate(generated_code)

if warnings:
    print(f"Warnings: {warnings}")
if not is_valid:
    raise SecurityError(message)
```

## 15.6 Complete Agent

```python
from typing import TypedDict
from langgraph.graph import StateGraph, END

class AnalystState(TypedDict):
    query: str
    data_path: str
    schema: dict
    generated_code: str
    validation_result: str
    execution_result: dict
    final_answer: str

def schema_node(state: AnalystState) -> dict:
    df = pd.read_csv(state["data_path"])
    schema = extract_safe_schema(df)
    return {"schema": schema}

def codegen_node(state: AnalystState) -> dict:
    code = generate_analysis_code(state["schema"], state["query"])
    return {"generated_code": code}

def validate_node(state: AnalystState) -> dict:
    is_valid, message = validate_code(state["generated_code"])
    return {"validation_result": "valid" if is_valid else message}

def execute_node(state: AnalystState) -> dict:
    if state["validation_result"] != "valid":
        return {"execution_result": {"error": state["validation_result"]}}

    result = execute_in_sandbox(
        state["generated_code"],
        state["data_path"]
    )
    return {"execution_result": result}

def summarize_node(state: AnalystState) -> dict:
    """Summarize results for the user."""
    result = state["execution_result"]

    if result.get("error"):
        return {"final_answer": f"Analysis failed: {result['error']}"}

    llm = ChatOpenAI(model="gpt-4o")

    summary = llm.invoke(f"""
    The user asked: {state["query"]}

    The analysis produced this output:
    {result["output"]}

    Summarize the findings in a clear, concise way.
    """)

    return {"final_answer": summary.content}

def build_analyst():
    workflow = StateGraph(AnalystState)

    workflow.add_node("extract_schema", schema_node)
    workflow.add_node("generate_code", codegen_node)
    workflow.add_node("validate", validate_node)
    workflow.add_node("execute", execute_node)
    workflow.add_node("summarize", summarize_node)

    workflow.set_entry_point("extract_schema")
    workflow.add_edge("extract_schema", "generate_code")
    workflow.add_edge("generate_code", "validate")
    workflow.add_edge("validate", "execute")
    workflow.add_edge("execute", "summarize")
    workflow.add_edge("summarize", END)

    return workflow.compile()

# Usage
analyst = build_analyst()

result = analyst.invoke({
    "query": "What's the correlation between age and income?",
    "data_path": "./sensitive_customer_data.csv"
})

print(result["final_answer"])
```

```python
def anonymize_schema(schema: dict) -> dict:
    """Replace column names with generic labels."""
    anonymized = schema.copy()
    column_map = {}

    for i, col in enumerate(anonymized["columns"]):
        original_name = col["name"]
        anonymous_name = f"column_{i}"
        column_map[anonymous_name] = original_name
        col["name"] = anonymous_name

    return anonymized, column_map

def deanonymize_code(code: str, column_map: dict) -> str:
    """Replace anonymous names with real names before execution."""
    for anon, real in column_map.items():
        code = code.replace(f"'{anon}'", f"'{real}'")
        code = code.replace(f'"{anon}"', f'"{real}"')
    return code
```

### GDPR Article 22: Automated Decision-Making

<Callout type="warning">
  **Legal Requirement**: Under GDPR Article 22, individuals have the right not
  to be subject to decisions based solely on automated processing that
  significantly affect them. This applies to AI-driven data analysis.
</Callout>

**Requirements for GDPR Compliance**:

| Requirement           | Implementation                                     |
| :-------------------- | :------------------------------------------------- |
| **Human oversight**   | Add human-in-the-loop for consequential decisions  |
| **Explainability**    | Log reasoning chain, not just results              |
| **Right to contest**  | Provide mechanism to challenge automated decisions |
| **Data minimization** | Process only necessary data (schema-only helps!)   |

```python
class GDPRCompliantAnalyst:
    """Analyst with GDPR Article 22 compliance features."""

    def analyze(self, query: str, data_path: str) -> dict:
        result = self.agent.invoke({
            "query": query,
            "data_path": data_path
        })

        # GDPR: Log the decision-making process
        audit_log = {
            "timestamp": datetime.utcnow().isoformat(),
            "query": query,
            "schema_sent": result["schema"],  # What LLM saw
            "code_generated": result["generated_code"],
            "human_review_required": self._requires_human_review(result),
            "data_subjects_affected": self._count_affected(data_path),
        }

        self._write_audit_log(audit_log)

        # Flag for human review if consequential
        if audit_log["human_review_required"]:
            result["status"] = "pending_human_review"
            result["review_reason"] = "Automated decision affecting individuals"

        return result

    def _requires_human_review(self, result: dict) -> bool:
        """Determine if decision requires human oversight."""
        consequential_keywords = [
            "eligibility", "approval", "denial", "score",
            "risk", "fraud", "terminate", "reject"
        ]
        query_lower = result.get("query", "").lower()
        return any(kw in query_lower for kw in consequential_keywords)
```

### HIPAA Technical Safeguards

```python
class HIPAACompliantAnalyst:
    """Analyst meeting HIPAA technical safeguard requirements."""

    # HIPAA §164.312(a)(1): Access Control
    def __init__(self, user_credentials: dict):
        self._verify_authorization(user_credentials)
        self._session_id = self._create_audit_session()

    # HIPAA §164.312(b): Audit Controls
    def analyze(self, query: str, data_path: str) -> dict:
        # Log all access attempts
        self._log_access_attempt(query, data_path)

        try:
            result = self._execute_analysis(query, data_path)
            self._log_access_success(result)
            return result
        except Exception as e:
            self._log_access_failure(str(e))
            raise

    # HIPAA §164.312(c)(1): Integrity Controls
    def _execute_analysis(self, query: str, data_path: str) -> dict:
        # Verify data integrity before analysis
        data_hash = self._compute_hash(data_path)

        result = self.agent.invoke({"query": query, "data_path": data_path})

        # Verify data wasn't modified
        if self._compute_hash(data_path) != data_hash:
            raise IntegrityError("Data modified during analysis")

        return result

    # HIPAA §164.312(e)(1): Transmission Security
    # Handled by: Local execution (no transmission) or TLS for cloud APIs
```

### Data Retention and Deletion

<Callout type="info">
  **GDPR Right to Erasure**: Users can request deletion of their data. Your
  system must support this without breaking audit trails.

```python
class DataRetentionManager:
    """Manage data retention per compliance requirements."""

    RETENTION_POLICIES = {
        "query_logs": 90,      # Days - for debugging
        "audit_logs": 2555,    # 7 years - SOC2/HIPAA
        "analysis_results": 30, # Days - GDPR minimization
        "raw_data": 0,         # Never retained by analyst
    }

    def apply_retention_policy(self):
        """Delete data exceeding retention period."""
        for data_type, retention_days in self.RETENTION_POLICIES.items():
            if retention_days == 0:
                continue  # Never retained

            cutoff = datetime.utcnow() - timedelta(days=retention_days)
            self._delete_before(data_type, cutoff)

    def handle_deletion_request(self, user_id: str):
        """GDPR Article 17: Right to erasure."""
        # Delete user's analysis results
        self._delete_user_results(user_id)

        # Anonymize audit logs (keep for compliance, remove PII)
        self._anonymize_audit_logs(user_id)

        # Log the deletion request itself (required for compliance)
        self._log_deletion_request(user_id)
```
