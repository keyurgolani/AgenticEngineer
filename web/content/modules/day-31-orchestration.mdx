## From Loops to Graphs

Our hand-built agent loops work, but they lack the robustness needed for production: no state persistence, no human-in-the-loop, no parallel execution. **LangGraph** solves all of this.

<Callout type="info" title="LangGraph in 2025">
  LangGraph has evolved significantly since its initial release. Version 0.3+
  introduced the **Functional API** for simpler workflows, the **Command
  primitive** for advanced human-in-the-loop patterns, and **LangGraph
  Platform** (now LangSmith Deployment) for production deployments. This module
  covers both the classic Graph API and these new capabilities. As we enter
  Month 2 of our 90-day journey, we're shifting from foundational concepts to
  production-grade multi-agent systems.
</Callout>

#### Pattern Details

**1. Pipeline** — Tasks flow sequentially through specialized stages. Simple but inflexible.

```
Input → Extract → Transform → Load → Output
```

**2. Supervisor** — A central agent decides which specialist handles each subtask.

```
User → Supervisor → [Billing Agent | Support Agent | Sales Agent]
```

**3. Fan-out/Fan-in** — Dispatch work to multiple agents in parallel, then aggregate results.

```
Query → [Agent1, Agent2, Agent3] → Synthesizer → Response
```

**4. Router** — Single classification step routes to exactly one handler (no aggregation).

```
Query → Classifier → Agent_N → Response
```

**5. Hierarchical** — Tree structure with managers delegating to sub-managers.

```
CEO Agent → [VP Engineering → [Team Lead → Developers], VP Sales → [Reps]]
```

**6. Collaborative** — Peer agents work on shared state without central control.

```
Agent A ↔ Shared State ↔ Agent B (both read/write)
```

**7. Blackboard** — Agents post findings to a shared "blackboard"; others react to changes.

```
[Agent1, Agent2, Agent3] ↔ Blackboard (opportunistic contribution)
```

**8. Swarm** — Autonomous agents with local rules produce emergent global behavior.

```
[Agent1, Agent2, ...AgentN] → Emergent Solution (no central control)
```

**9. Council** — Multiple agents vote or reach consensus on decisions.

```
Query → [Judge1, Judge2, Judge3] → Majority Vote → Decision
```

**10. Evaluator/Critic** — Generator produces output; critic provides feedback for iteration.

```
Generator → Draft → Critic → Feedback → Generator (loop until approved)
```

**11. Debate** — Agents argue opposing positions; synthesizer extracts best arguments.

```
[Pro Agent ↔ Con Agent] → Moderator → Balanced Conclusion
```

<Callout type="tip" title="Pattern Selection Guide">
  Start with the simplest pattern that meets your needs. **Pipeline** for linear
  workflows, **Supervisor** for task routing, **Fan-out/Fan-in** for parallel
  research. Only reach for complex patterns like **Swarm** or **Blackboard**
  when simpler approaches fail.
</Callout>

## 31.2 Two APIs: Graph and Functional

LangGraph now offers two complementary approaches to building workflows:

<Mermaid
  chart={`
graph LR
    subgraph "Graph API (Explicit)"
        A[StateGraph] --> B[add_node]
        B --> C[add_edge]
        C --> D[compile]
    end

    subgraph "Functional API (Decorator)"
        E[@entrypoint] --> F[@task]
        F --> G[@task]
        G --> E
    end

    style A fill:#e3f2fd
    style E fill:#f3e5f5

`}
caption="Two APIs, One Runtime: Choose your abstraction level."
/>

### The Graph API (Classic)

The original approach using `StateGraph`, explicit nodes, and edges:

```python
from langgraph.graph import StateGraph, START, END

workflow = StateGraph(AgentState)
workflow.add_node("research", researcher_node)
workflow.add_node("write", writer_node)
workflow.add_edge(START, "research")
workflow.add_edge("research", "write")
workflow.add_edge("write", END)

app = workflow.compile()
```

### The Functional API (New in 0.3+)

A decorator-based approach using `@entrypoint` and `@task`:

```python
from langgraph.func import entrypoint, task
from langgraph.checkpoint.memory import InMemorySaver

@task
def research(topic: str) -> str:
    """Research the given topic."""
    return f"Research findings for: {topic}"

@task
def write(findings: str) -> str:
    """Write based on research findings."""
    return f"Article based on: {findings}"

@entrypoint(checkpointer=InMemorySaver())
def workflow(topic: str) -> str:
    """Main workflow combining research and writing."""
    findings = research(topic).result()
    article = write(findings).result()
    return article
```

### When to Use Each API

| Use Case                              | Recommended API  |
| :------------------------------------ | :--------------- |
| Complex branching with multiple paths | Graph API        |
| Simple linear workflows               | Functional API   |
| Existing codebase integration         | Functional API   |
| Visual debugging in LangGraph Studio  | Graph API        |
| Parallel fan-out patterns             | Graph API (Send) |
| Quick prototyping                     | Functional API   |

<Callout type="info" title="Same Runtime, Different Syntax">
  Both APIs share the same underlying Pregel runtime. You can even mix them—use
  a compiled StateGraph as a node within a Functional API workflow, or call
  `@task` functions from Graph API nodes.
</Callout>

### State

State is a TypedDict that flows through the graph:

```python
from typing import TypedDict, Annotated, List
import operator

class AgentState(TypedDict):
    # Messages accumulate (using operator.add)
    messages: Annotated[List[dict], operator.add]

    # Current step in the workflow
    current_step: str

    # Results from tools
    tool_results: Annotated[dict, operator.ior]  # Merge dicts

    # Final output
    final_answer: str
```

### Nodes

Nodes are functions that transform state:

```python
def researcher_node(state: AgentState) -> dict:
    """Research node - searches for information."""
    query = state["messages"][-1]["content"]

    # Do research...
    results = search_web(query)

    # Return state updates (partial)
    return {
        "tool_results": {"research": results},
        "current_step": "analyze"
    }
```

### Edges

Edges define control flow:

```python
from langgraph.graph import StateGraph, END

workflow = StateGraph(AgentState)

# Add nodes
workflow.add_node("research", researcher_node)
workflow.add_node("analyze", analyzer_node)
workflow.add_node("write", writer_node)

# Add edges
workflow.add_edge("research", "analyze")  # Always go research -> analyze

# Conditional edge
def should_continue(state: AgentState) -> str:
    if state.get("needs_more_research"):
        return "research"  # Loop back
    return "write"  # Move forward

workflow.add_conditional_edges(
    "analyze",
    should_continue,
    {
        "research": "research",
        "write": "write"
    }
)

workflow.add_edge("write", END)
```

## 31.4 Building a Complete Agent

Let's build a research agent with LangGraph:

```python
from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import ToolNode
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage
from typing import TypedDict, Annotated, List
import operator

# 1. Define State
class ResearchState(TypedDict):
    messages: Annotated[List, operator.add]
    research_results: str
    draft: str
    feedback: str
    iteration: int

# 2. Define Nodes
def planner_node(state: ResearchState) -> dict:
    """Plan the research approach."""
    llm = ChatOpenAI(model="gpt-4o-mini")

    response = llm.invoke([
        {"role": "system", "content": "You are a research planner. Create a research plan."},
        {"role": "user", "content": state["messages"][-1].content}
    ])

    return {
        "messages": [AIMessage(content=f"Plan: {response.content}")],
        "iteration": 0
    }

def researcher_node(state: ResearchState) -> dict:
    """Execute research based on the plan."""
    # Simulate research (in production, use Tavily/SerpAPI)
    topic = state["messages"][0].content

    results = f"Research findings for '{topic}':\n"
    results += "- Finding 1: Important fact\n"
    results += "- Finding 2: Key statistic\n"
    results += "- Finding 3: Expert opinion\n"

    return {
        "research_results": results,
        "messages": [AIMessage(content=f"Research complete: {results[:100]}...")]
    }

def writer_node(state: ResearchState) -> dict:
    """Write a draft based on research."""
    llm = ChatOpenAI(model="gpt-4o-mini")

    response = llm.invoke([
        {"role": "system", "content": "Write a concise summary based on the research."},
        {"role": "user", "content": state["research_results"]}
    ])

    return {
        "draft": response.content,
        "messages": [AIMessage(content="Draft written.")]
    }

def reviewer_node(state: ResearchState) -> dict:
    """Review the draft and provide feedback."""
    llm = ChatOpenAI(model="gpt-4o-mini")

    response = llm.invoke([
        {"role": "system", "content": "Review this draft. If it's good, say 'APPROVED'. Otherwise, provide specific feedback."},
        {"role": "user", "content": state["draft"]}
    ])

    return {
        "feedback": response.content,
        "iteration": state["iteration"] + 1,
        "messages": [AIMessage(content=f"Review: {response.content[:50]}...")]
    }

# 3. Define Routing Logic
def should_revise(state: ResearchState) -> str:
    """Decide whether to revise or finish."""
    if "APPROVED" in state["feedback"]:
        return "end"
    if state["iteration"] >= 3:
        return "end"  # Max iterations
    return "revise"

# 4. Build the Graph
workflow = StateGraph(ResearchState)

workflow.add_node("planner", planner_node)
workflow.add_node("researcher", researcher_node)
workflow.add_node("writer", writer_node)
workflow.add_node("reviewer", reviewer_node)

workflow.add_edge(START, "planner")
workflow.add_edge("planner", "researcher")
workflow.add_edge("researcher", "writer")
workflow.add_edge("writer", "reviewer")

workflow.add_conditional_edges(
    "reviewer",
    should_revise,
    {
        "revise": "writer",  # Loop back to writer
        "end": END
    }
)

# 5. Compile
app = workflow.compile()

# 6. Run
result = app.invoke({
    "messages": [HumanMessage(content="Research the impact of AI on software engineering")]
})

print(result["draft"])
```

## 31.5 Production Checkpointing

For production, you need robust state persistence. LangGraph supports multiple checkpointer backends:

### Development: In-Memory and SQLite

```python
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.checkpoint.sqlite import SqliteSaver

# In-memory (development only - state lost on restart)
checkpointer = InMemorySaver()

# SQLite (local development with persistence)
checkpointer = SqliteSaver.from_conn_string("checkpoints.db")

app = workflow.compile(checkpointer=checkpointer)
```

### Production: PostgreSQL

PostgreSQL is the recommended choice for production deployments:

  <div className="flex justify-center">
    <div className="w-full max-w-3xl bg-white dark:bg-zinc-900 rounded-lg shadow-sm p-4 overflow-x-auto">
      ```mermaid

    participant Agent
    participant Graph
    participant Postgres
    
    Agent->>Graph: Invoke(Input)
    Graph->>Graph: Execute Node
    Graph->>Graph: Update State
    Graph->>Postgres: Write Checkpoint (thread_id)
    Postgres-->>Graph: Ack
    Graph-->>Agent: Return Result
    
    opt Restart/Resume
        Agent->>Graph: Invoke(thread_id)
        Graph->>Postgres: Read Latest Checkpoint
        Postgres-->>Graph: Return State
        Graph->>Graph: Resume Execution
    end
      ```

```python
from langgraph.checkpoint.postgres import PostgresSaver
from psycopg_pool import ConnectionPool

# Create a connection pool for better performance
pool = ConnectionPool(
    conninfo="postgresql://user:password@localhost:5432/langgraph",
    min_size=5,
    max_size=20
)

# Use the pool with PostgresSaver
with PostgresSaver.from_conn_string(
    "postgresql://user:password@localhost:5432/langgraph"
) as checkpointer:
    app = workflow.compile(checkpointer=checkpointer)

    # Run with thread_id for persistence
    config = {"configurable": {"thread_id": "user-123-session-1"}}
    result = app.invoke({"messages": [HumanMessage(content="Research AI")]}, config)
```

### Production: Redis

Redis offers ultra-fast persistence with sub-millisecond latency:

```python
from langgraph_checkpoint_redis import RedisSaver, AsyncRedisSaver

# Synchronous Redis checkpointer
checkpointer = RedisSaver.from_conn_string("redis://localhost:6379")

# Async Redis checkpointer (for async workflows)
async_checkpointer = AsyncRedisSaver.from_conn_string("redis://localhost:6379")

# Shallow saver (stores only latest checkpoint - lower memory)
from langgraph_checkpoint_redis import ShallowRedisSaver
shallow_checkpointer = ShallowRedisSaver.from_conn_string("redis://localhost:6379")

app = workflow.compile(checkpointer=checkpointer)
```

<Callout type="tip" title="Redis for Cross-Thread Memory">
  Redis also supports `RedisStore` for cross-thread memory—letting agents
  remember information about users across different conversation threads. This
  is ideal for building agents that maintain long-term user profiles.
</Callout>

### Checkpointer Comparison

| Backend           | Latency   | Durability   | Best For                   |
| :---------------- | :-------- | :----------- | :------------------------- |
| **InMemorySaver** | ~0ms      | None         | Unit tests, prototyping    |
| **SqliteSaver**   | ~1-5ms    | Local file   | Local development          |
| **PostgresSaver** | ~5-20ms   | Full ACID    | Production, compliance     |
| **RedisSaver**    | under 1ms | Configurable | High-throughput, real-time |

### Basic Approval Pattern

```python
def retry_on_specific_errors(error: Exception) -> bool:

    # Retry on rate limits and transient errors

    if isinstance(error, APIError) and error.status_code >= 500:
```

## 31.11 Advanced Architecture: The Filesystem & Bash Agent

While LangGraph manages _flow_, how you structure _context_ is equally critical. A powerful emerging pattern is the **Filesystem Agent**.

### The Concept

Instead of creating custom tools for every API or database method, you map your domain entities to a **virtual filesystem** and give the agent standard Unix tools (`ls`, `grep`, `cat`).

### Why It Works

1.  **LLMs are Unix Natives**: Models have seen billions of lines of bash scripts and filesystem operations. They intuitively understand how to navigate directory trees.
2.  **Efficient Context Browsing**:
    - `ls -R`: "Give me a high-level map of what's available" (Cheap: few tokens)
    - `grep "error" logs/`: "Find specific relevant info" (Targeted: medium tokens)
    - `cat logs/error.log`: "Load this exact file into context" (Specific: high efficiency)
3.  **No "Tool Bloat"**: You don't need 50 tools (`get_customer`, `search_orders`, `list_products`). You just need a filesystem structure:
    ```text
    /customers/cust_001.json
    /orders/ord_123.json
    /products/widget.json
    ```

### Example: Sales Call Summary Agent

Instead of a RAG pipeline, Vercel engineers built a sales agent by dumping call transcripts and CRM data into a folder structure:

```bash
/
├── calls/
│   ├── 2023-10-01-acme-corp.txt
│   └── 2023-10-05-globex.txt
├── crm/
│   └── acme-corp.json
└── playbooks/
    └── qualification-framework.md
```

The agent uses `grep` to find "budget" or "objections" across transcripts, then `cat` to read the relevant segments. This approach often outperforms vector search for explicit retrieval tasks because it eliminates the "embedding approximation" step—the agent sees the actual keywords.

#### Implementation: Ant Colony Optimization for Research

```python
from typing import TypedDict, Annotated, List, Dict
from langgraph.graph import StateGraph, START, END
import operator
import random

class SwarmState(TypedDict):
    """Shared environment state for swarm agents."""
    query: str
    # Pheromone trails: path -> strength (higher = more promising)
    pheromones: Annotated[Dict[str, float], operator.ior]
    # Discovered findings from all agents
    findings: Annotated[List[dict], operator.add]
    # Exploration paths taken
    explored_paths: Annotated[List[str], operator.add]
    iteration: int

def calculate_path_probability(pheromones: Dict[str, float], paths: List[str]) -> Dict[str, float]:
    """Calculate selection probability based on pheromone strength."""
    total = sum(pheromones.get(p, 1.0) for p in paths)
    return {p: pheromones.get(p, 1.0) / total for p in paths}

def swarm_agent(state: SwarmState, agent_id: int) -> dict:
    """Individual swarm agent following pheromone trails."""
    available_paths = ["academic_papers", "news_articles", "expert_blogs",
                       "patents", "social_media", "government_reports"]

    # Probabilistic path selection based on pheromones (exploitation)
    # with random exploration (exploration-exploitation balance)
    if random.random() < 0.2:  # 20% exploration
        chosen_path = random.choice(available_paths)
    else:  # 80% exploitation - follow pheromones
        probs = calculate_path_probability(state["pheromones"], available_paths)
        chosen_path = max(probs, key=probs.get)

    # Simulate research on chosen path
    quality_score = research_path(state["query"], chosen_path)
    finding = {
        "agent": agent_id,
        "path": chosen_path,
        "content": f"Finding from {chosen_path}",
        "quality": quality_score
    }

    # Deposit pheromone proportional to quality (stigmergy)
    pheromone_deposit = {chosen_path: quality_score * 0.5}

    return {
        "findings": [finding],
        "explored_paths": [f"agent_{agent_id}:{chosen_path}"],
        "pheromones": pheromone_deposit
    }

def evaporate_pheromones(state: SwarmState) -> dict:
    """Pheromone evaporation prevents convergence to suboptimal solutions."""
    evaporation_rate = 0.1
    updated = {k: v * (1 - evaporation_rate) for k, v in state["pheromones"].items()}
    return {"pheromones": updated, "iteration": state["iteration"] + 1}

def should_continue_swarm(state: SwarmState) -> str:
    """Continue until convergence or max iterations."""
    if state["iteration"] >= 5:
        return "synthesize"
    # Check for convergence (one path dominates)
    if state["pheromones"]:
        max_pheromone = max(state["pheromones"].values())
        if max_pheromone > 10.0:  # Strong convergence
            return "synthesize"
    return "continue"

# Build swarm workflow with parallel agent execution
from langgraph.constants import Send

def fan_out_swarm(state: SwarmState) -> List[Send]:
    """Dispatch multiple swarm agents in parallel."""
    num_agents = 5
    return [Send("swarm_agent", {"agent_id": i, **state}) for i in range(num_agents)]

workflow = StateGraph(SwarmState)
workflow.add_node("swarm_agent", lambda s: swarm_agent(s, s.get("agent_id", 0)))
workflow.add_node("evaporate", evaporate_pheromones)
workflow.add_node("synthesize", synthesize_findings)

workflow.add_conditional_edges(START, fan_out_swarm)
workflow.add_edge("swarm_agent", "evaporate")
workflow.add_conditional_edges("evaporate", should_continue_swarm, {
    "continue": "swarm_agent",
    "synthesize": "synthesize"
})
workflow.add_edge("synthesize", END)
```

<Callout type="insight" title="When to Use Swarm Patterns">
  Swarm intelligence excels when: (1) The solution space is large and unknown,
  (2) No single "correct" path exists, (3) You want diverse exploration, (4)
  Fault tolerance is critical (losing one agent doesn't break the system). Avoid
  for tasks requiring strict sequential logic or deterministic outputs.
</Callout>

#### Council Implementation

```python
from typing import TypedDict, Annotated, List, Dict, Literal
from dataclasses import dataclass
import operator

@dataclass
class ExpertVote:
    expert_id: str
    decision: str
    confidence: float  # 0.0 to 1.0
    reasoning: str
    weight: float  # Expert's weight in this domain

class CouncilState(TypedDict):
    query: str
    context: dict
    votes: Annotated[List[ExpertVote], operator.add]
    debate_rounds: int
    consensus: str | None
    dissenting_opinions: List[str]

# Expert definitions with domain weights
EXPERTS = {
    "security": {"weight": 1.5, "domains": ["auth", "data", "compliance"]},
    "performance": {"weight": 1.2, "domains": ["latency", "throughput", "cost"]},
    "usability": {"weight": 1.0, "domains": ["ux", "accessibility", "docs"]},
    "architecture": {"weight": 1.3, "domains": ["scalability", "maintainability"]}
}

def create_expert_node(expert_id: str):
    """Factory for creating expert voting nodes."""
    def expert_vote(state: CouncilState) -> dict:
        llm = ChatOpenAI(model="gpt-4o")
        expert_config = EXPERTS[expert_id]

        # Expert analyzes from their perspective
        response = llm.invoke([
            {"role": "system", "content": f"""You are a {expert_id} expert.
            Analyze this decision from your domain perspective.
            Domains of expertise: {expert_config['domains']}

            Respond with JSON:
            {{"decision": "approve|reject|needs_discussion",
              "confidence": 0.0-1.0,
              "reasoning": "your analysis"}}"""
            },
            {"role": "user", "content": f"Query: {state['query']}\nContext: {state['context']}"}
        ])

        result = json.loads(response.content)
        vote = ExpertVote(
            expert_id=expert_id,
            decision=result["decision"],
            confidence=result["confidence"],
            reasoning=result["reasoning"],
            weight=expert_config["weight"]
        )
        return {"votes": [vote]}

    return expert_vote

def calculate_consensus(state: CouncilState) -> dict:
    """Calculate weighted consensus from expert votes."""
    votes = state["votes"]

    # Group votes by decision
    decision_scores: Dict[str, float] = {}
    for vote in votes:
        weighted_score = vote.confidence * vote.weight
        decision_scores[vote.decision] = decision_scores.get(vote.decision, 0) + weighted_score

    total_weight = sum(decision_scores.values())

    # Check for supermajority (>66% weighted agreement)
    for decision, score in decision_scores.items():
        if score / total_weight > 0.66:
            dissenting = [v.reasoning for v in votes if v.decision != decision]
            return {
                "consensus": decision,
                "dissenting_opinions": dissenting
            }

    # No consensus - need more deliberation
    return {"consensus": None, "debate_rounds": state["debate_rounds"] + 1}

def structured_debate(state: CouncilState) -> dict:
    """Facilitate structured debate when consensus isn't reached."""
    llm = ChatOpenAI(model="gpt-4o")

    # Summarize disagreements
    votes_summary = "\n".join([
        f"- {v.expert_id}: {v.decision} (confidence: {v.confidence}) - {v.reasoning}"
        for v in state["votes"]
    ])

    # Generate debate prompts to resolve disagreement
    response = llm.invoke([
        {"role": "system", "content": """Analyze the expert disagreements and identify:
        1. Key points of contention
        2. Missing information that could resolve disagreement
        3. Potential compromise positions

        Output specific questions each expert should reconsider."""},
        {"role": "user", "content": f"Votes:\n{votes_summary}"}
    ])

    # Clear votes for next round with new context
    return {
        "votes": [],  # Reset for re-voting
        "context": {**state["context"], "debate_guidance": response.content}
    }

def route_after_consensus(state: CouncilState) -> str:
    """Route based on consensus status."""
    if state["consensus"]:
        return "finalize"
    if state["debate_rounds"] >= 3:
        return "escalate"  # Human intervention needed
    return "debate"

# Build council workflow
workflow = StateGraph(CouncilState)

# Add expert nodes
for expert_id in EXPERTS:
    workflow.add_node(f"expert_{expert_id}", create_expert_node(expert_id))

workflow.add_node("consensus", calculate_consensus)
workflow.add_node("debate", structured_debate)
workflow.add_node("finalize", finalize_decision)
workflow.add_node("escalate", escalate_to_human)

workflow.add_edge(START, "expert_security")
workflow.add_edge(START, "expert_performance")
workflow.add_edge(START, "expert_usability")
workflow.add_edge(START, "expert_architecture")
```

### Adaptive Loops: Plan-Do-Check-Act (PDCA)

The PDCA cycle enables self-improving workflows that learn from execution and dynamically adjust their approach.

<Mermaid

    subgraph "Agent Implementation"
        P1[Generate Strategy] --> D1[Execute Tasks]
        D1 --> C1[Evaluate Results]

```python
from typing import TypedDict, Annotated, List
import operator

class PDCAState(TypedDict):
    goal: str
    current_plan: dict
    execution_results: List[dict]
    evaluation: dict
    improvements: Annotated[List[str], operator.add]
    iteration: int
    converged: bool

def plan_node(state: PDCAState) -> dict:
    """Generate or refine the execution plan."""
    llm = ChatOpenAI(model="gpt-4o")

    context = {
        "goal": state["goal"],
        "previous_plan": state.get("current_plan"),
        "previous_evaluation": state.get("evaluation"),
        "accumulated_improvements": state.get("improvements", [])
    }

    response = llm.invoke([
        {"role": "system", "content": """Create an execution plan.
        If previous attempts exist, incorporate lessons learned.
        Output JSON with: {"steps": [...], "success_criteria": [...], "risk_mitigations": [...]}"""},
        {"role": "user", "content": json.dumps(context)}
    ])

    return {"current_plan": json.loads(response.content)}

def do_node(state: PDCAState) -> dict:
    """Execute the current plan."""
    results = []
    for step in state["current_plan"]["steps"]:
        try:
            result = execute_step(step)
            results.append({"step": step, "status": "success", "output": result})
        except Exception as e:
            results.append({"step": step, "status": "failed", "error": str(e)})

    return {"execution_results": results}

def check_node(state: PDCAState) -> dict:
    """Evaluate execution against success criteria."""
    llm = ChatOpenAI(model="gpt-4o")

    response = llm.invoke([
        {"role": "system", "content": """Evaluate the execution results against success criteria.
        Output JSON:
        {
            "criteria_met": {"criterion": true/false, ...},
            "overall_success_rate": 0.0-1.0,
            "failure_analysis": "root cause of failures",
            "improvement_opportunities": ["specific improvements"]
        }"""},
        {"role": "user", "content": json.dumps({
            "criteria": state["current_plan"]["success_criteria"],
            "results": state["execution_results"]
        })}
    ])

    return {"evaluation": json.loads(response.content)}

def act_node(state: PDCAState) -> dict:
    """Decide whether to iterate or complete."""
    evaluation = state["evaluation"]

    # Check for convergence
    if evaluation["overall_success_rate"] >= 0.95:
        return {"converged": True}

    # Check for max iterations
    if state["iteration"] >= 5:
        return {"converged": True}  # Accept best effort

    # Record improvements for next iteration
    return {
        "improvements": evaluation.get("improvement_opportunities", []),
        "iteration": state["iteration"] + 1,
        "converged": False
    }

def should_continue_pdca(state: PDCAState) -> str:
    return "complete" if state["converged"] else "plan"

workflow = StateGraph(PDCAState)
workflow.add_node("plan", plan_node)
workflow.add_node("do", do_node)
workflow.add_node("check", check_node)
workflow.add_node("act", act_node)
workflow.add_node("complete", lambda s: s)

workflow.add_edge(START, "plan")
workflow.add_edge("plan", "do")
workflow.add_edge("do", "check")
workflow.add_edge("check", "act")
workflow.add_conditional_edges("act", should_continue_pdca, {
    "plan": "plan",
    "complete": "complete"
})
workflow.add_edge("complete", END)
```

<Callout type="tip" title="PDCA Best Practices">
  1. **Define measurable success criteria** upfront—vague goals prevent
  convergence 2. **Limit iterations** to prevent infinite loops (3-5 is typical)
  3. **Persist learnings** across iterations using state 4. **Include escape
  hatches** for when improvement plateaus
</Callout>

#### Implementation: Event-Driven Agent Coordination

```python
from typing import TypedDict, Annotated, List, Dict
from dataclasses import dataclass
from enum import Enum
import operator

class EventType(Enum):
    TASK_CREATED = "task_created"
    TASK_COMPLETED = "task_completed"
    FINDING_DISCOVERED = "finding_discovered"
    HELP_REQUESTED = "help_requested"
    CONSENSUS_NEEDED = "consensus_needed"

@dataclass
class AgentEvent:
    event_type: EventType
    source_agent: str
    payload: dict
    timestamp: float

class EventDrivenState(TypedDict):
    events: Annotated[List[AgentEvent], operator.add]
    subscriptions: Dict[str, List[EventType]]  # agent_id -> event types
    agent_states: Dict[str, dict]
    pending_responses: Dict[str, List[dict]]

class EventBus:
    """Central event bus for agent communication."""

    def __init__(self):
        self.subscribers: Dict[EventType, List[callable]] = {}

    def subscribe(self, event_type: EventType, handler: callable):
        if event_type not in self.subscribers:
            self.subscribers[event_type] = []
        self.subscribers[event_type].append(handler)

    def publish(self, event: AgentEvent) -> List[dict]:
        """Publish event and collect responses from subscribers."""
        responses = []
        handlers = self.subscribers.get(event.event_type, [])
        for handler in handlers:
            response = handler(event)
            if response:
                responses.append(response)
        return responses

def create_event_driven_agent(agent_id: str, subscriptions: List[EventType]):
    """Factory for creating event-driven agents."""

    def agent_node(state: EventDrivenState) -> dict:
        # Process events this agent is subscribed to
        my_subscriptions = state["subscriptions"].get(agent_id, [])
        relevant_events = [
            e for e in state["events"]
            if e.event_type in my_subscriptions
            and e.source_agent != agent_id  # Don't process own events
        ]

        new_events = []
        for event in relevant_events:
            # React to event based on type
            if event.event_type == EventType.HELP_REQUESTED:
                if can_help(agent_id, event.payload):
                    new_events.append(AgentEvent(
                        event_type=EventType.TASK_COMPLETED,
                        source_agent=agent_id,
                        payload={"help_response": provide_help(event.payload)},
                        timestamp=time.time()
                    ))

            elif event.event_type == EventType.FINDING_DISCOVERED:
                # React to findings from other agents
                if is_relevant(agent_id, event.payload):
                    incorporate_finding(state["agent_states"][agent_id], event.payload)

            elif event.event_type == EventType.CONSENSUS_NEEDED:
                # Participate in consensus
                vote = generate_vote(agent_id, event.payload)
                new_events.append(AgentEvent(
                    event_type=EventType.TASK_COMPLETED,
                    source_agent=agent_id,
                    payload={"vote": vote},
                    timestamp=time.time()
                ))

        return {"events": new_events}

    return agent_node
```

#### Implementation: P2P Research Collaboration

```python
from typing import TypedDict, Annotated, List, Dict, Set
from dataclasses import dataclass, field
from langgraph.graph import StateGraph, START, END
import operator
import random

@dataclass
class PeerMessage:
    """Message passed between peers."""
    sender: str
    recipient: str  # "*" for broadcast
    msg_type: str  # "finding", "request", "ack", "negotiate"
    content: dict
    timestamp: float

class P2PState(TypedDict):
    """State for peer-to-peer coordination."""
    task: str
    # Each peer's local knowledge
    peer_knowledge: Dict[str, dict]
    # Message queue for inter-peer communication
    messages: Annotated[List[PeerMessage], operator.add]
    # Processed message IDs to avoid duplicates
    processed_ids: Set[str]
    # Convergence tracking
    round: int
    converged: bool

def create_peer_agent(peer_id: str, expertise: List[str]):
    """Factory for creating peer agents with specific expertise."""

    def peer_node(state: P2PState) -> dict:
        my_knowledge = state["peer_knowledge"].get(peer_id, {})
        new_messages = []

        # Process incoming messages addressed to me or broadcast
        incoming = [
            m for m in state["messages"]
            if (m.recipient == peer_id or m.recipient == "*")
            and m.sender != peer_id
            and f"{m.sender}:{m.timestamp}" not in state.get("processed_ids", set())
        ]

        for msg in incoming:
            if msg.msg_type == "finding":
                # Incorporate peer's finding into my knowledge
                if is_relevant_to_expertise(msg.content, expertise):
                    my_knowledge = merge_knowledge(my_knowledge, msg.content)
                    # Acknowledge receipt
                    new_messages.append(PeerMessage(
                        sender=peer_id,
                        recipient=msg.sender,
                        msg_type="ack",
                        content={"received": msg.content.get("id")},
                        timestamp=time.time()
                    ))

            elif msg.msg_type == "request":
                # Peer is asking for help - check if I can assist
                if can_help_with(msg.content["topic"], expertise):
                    response = generate_response(msg.content, my_knowledge)
                    new_messages.append(PeerMessage(
                        sender=peer_id,
                        recipient=msg.sender,
                        msg_type="finding",
                        content=response,
                        timestamp=time.time()
                    ))

            elif msg.msg_type == "negotiate":
                # Task allocation negotiation
                if should_accept_task(msg.content, expertise, my_knowledge):
                    new_messages.append(PeerMessage(
                        sender=peer_id,
                        recipient=msg.sender,
                        msg_type="ack",
                        content={"accepted": msg.content.get("task_id")},
                        timestamp=time.time()
                    ))

        # Do my own work based on expertise
        if not state.get("converged"):
            new_finding = research_topic(state["task"], expertise, my_knowledge)
            if new_finding:
                my_knowledge = merge_knowledge(my_knowledge, new_finding)
                # Broadcast finding to all peers
                new_messages.append(PeerMessage(
                    sender=peer_id,
                    recipient="*",  # Broadcast
                    msg_type="finding",
                    content=new_finding,
                    timestamp=time.time()
                ))

        # Update processed message IDs
        new_processed = {f"{m.sender}:{m.timestamp}" for m in incoming}

        return {
            "peer_knowledge": {peer_id: my_knowledge},
            "messages": new_messages,
            "processed_ids": state.get("processed_ids", set()) | new_processed
        }

    return peer_node

def check_p2p_convergence(state: P2PState) -> dict:
    """Check if peers have reached consensus."""
    # Convergence when all peers have similar knowledge
    knowledge_sets = list(state["peer_knowledge"].values())

    if len(knowledge_sets) < 2:
        return {"round": state["round"] + 1, "converged": False}

    # Calculate knowledge overlap
    overlap = calculate_knowledge_overlap(knowledge_sets)

    if overlap > 0.9 or state["round"] >= 10:
        return {"converged": True}

    return {"round": state["round"] + 1, "converged": False}

def synthesize_p2p_results(state: P2PState) -> dict:
    """Combine all peer knowledge into final result."""
    all_knowledge = state["peer_knowledge"]

    # Merge all peer findings with conflict resolution
    final_result = {}
    for peer_id, knowledge in all_knowledge.items():
        for key, value in knowledge.items():
            if key not in final_result:
                final_result[key] = {"value": value, "sources": [peer_id]}
            else:
                # Conflict resolution: majority vote or merge
                final_result[key]["sources"].append(peer_id)

    return {"final_result": final_result}

# Build P2P workflow
workflow = StateGraph(P2PState)

# Define peers with different expertise
peers = {
    "alice": ["machine_learning", "statistics"],
    "bob": ["software_engineering", "systems"],
    "carol": ["domain_expertise", "validation"]
}

for peer_id, expertise in peers.items():
    workflow.add_node(peer_id, create_peer_agent(peer_id, expertise))

workflow.add_node("check_convergence", check_p2p_convergence)
workflow.add_node("synthesize", synthesize_p2p_results)

# All peers run in parallel each round
workflow.add_edge(START, "alice")
workflow.add_edge(START, "bob")
workflow.add_edge(START, "carol")

# Converge to check
workflow.add_edge("alice", "check_convergence")
workflow.add_edge("bob", "check_convergence")
workflow.add_edge("carol", "check_convergence")

# Loop or finish
workflow.add_conditional_edges(
    "check_convergence",
    lambda s: "synthesize" if s["converged"] else "continue",
    {
        "continue": "alice",  # Next round
        "synthesize": "synthesize"
    }
)
workflow.add_edge("synthesize", END)

app = workflow.compile()
```

<Callout type="tip" title="P2P vs Hierarchical">
  Use P2P when agents have **complementary expertise** and need to **negotiate**
  task allocation. Use hierarchical when you need **deterministic control** and
  **clear accountability**. P2P is more resilient but harder to debug.
</Callout>

#### Implementation: Type-Safe Message Protocol

```python
from typing import TypedDict, Annotated, List, Union, Literal
from dataclasses import dataclass
from enum import Enum
import operator
import uuid

class MessagePriority(Enum):
    LOW = 1
    NORMAL = 2
    HIGH = 3
    CRITICAL = 4

@dataclass
class BaseMessage:
    """Base class for all agent messages."""
    id: str
    sender: str
    timestamp: float
    priority: MessagePriority = MessagePriority.NORMAL
    correlation_id: str | None = None  # For request-response tracking

@dataclass
class RequestMessage(BaseMessage):
    """Request expecting a response."""
    action: str
    payload: dict
    timeout_ms: int = 5000

@dataclass
class ResponseMessage(BaseMessage):
    """Response to a request."""
    success: bool
    result: dict | None
    error: str | None = None

@dataclass
class EventMessage(BaseMessage):
    """Fire-and-forget event notification."""
    event_type: str
    data: dict

@dataclass
class BroadcastMessage(BaseMessage):
    """Message to all agents."""
    topic: str
    content: dict

AgentMessage = Union[RequestMessage, ResponseMessage, EventMessage, BroadcastMessage]

class MessagePassingState(TypedDict):
    """State with typed message queue."""
    inbox: Annotated[List[AgentMessage], operator.add]
    outbox: Annotated[List[AgentMessage], operator.add]
    pending_requests: Dict[str, RequestMessage]  # correlation_id -> request
    agent_states: Dict[str, dict]

class MessageRouter:
    """Routes messages between agents with delivery guarantees."""

    def __init__(self):
        self.dead_letter_queue: List[AgentMessage] = []
        self.retry_counts: Dict[str, int] = {}
        self.max_retries = 3

    def route(self, message: AgentMessage, recipients: List[str]) -> List[tuple[str, AgentMessage]]:
        """Route message to recipients with retry logic."""
        deliveries = []
        for recipient in recipients:
            deliveries.append((recipient, message))
        return deliveries

    def handle_failure(self, message: AgentMessage, error: str) -> AgentMessage | None:
        """Handle delivery failure with retry or dead-letter."""
        msg_id = message.id
        self.retry_counts[msg_id] = self.retry_counts.get(msg_id, 0) + 1

        if self.retry_counts[msg_id] < self.max_retries:
            return message  # Retry
        else:
            self.dead_letter_queue.append(message)
            return None  # Give up

def create_message_handler(agent_id: str):
    """Factory for creating message-handling agents."""

    def handle_messages(state: MessagePassingState) -> dict:
        my_inbox = [m for m in state["inbox"] if getattr(m, 'recipient', None) == agent_id or isinstance(m, BroadcastMessage)]
        outgoing = []
        my_state = state["agent_states"].get(agent_id, {})
        pending = state.get("pending_requests", {})

        for message in my_inbox:
            if isinstance(message, RequestMessage):
                # Handle request and send response
                try:
                    result = process_request(message.action, message.payload, my_state)
                    response = ResponseMessage(
                        id=str(uuid.uuid4()),
                        sender=agent_id,
                        timestamp=time.time(),
                        correlation_id=message.id,
                        success=True,
                        result=result,
                        error=None
                    )
                except Exception as e:
                    response = ResponseMessage(
                        id=str(uuid.uuid4()),
                        sender=agent_id,
                        timestamp=time.time(),
                        correlation_id=message.id,
                        success=False,
                        result=None,
                        error=str(e)
                    )
                outgoing.append(response)

            elif isinstance(message, ResponseMessage):
                # Match response to pending request
                if message.correlation_id in pending:
                    original_request = pending[message.correlation_id]
                    handle_response(original_request, message, my_state)
                    del pending[message.correlation_id]

            elif isinstance(message, EventMessage):
                # Fire-and-forget: just process, no response
                handle_event(message.event_type, message.data, my_state)

            elif isinstance(message, BroadcastMessage):
                # Process broadcast if relevant
                if is_subscribed_to(agent_id, message.topic):
                    handle_broadcast(message.topic, message.content, my_state)

        return {
            "outbox": outgoing,
            "agent_states": {agent_id: my_state},
            "pending_requests": pending
        }

    return handle_messages

# Scatter-Gather implementation
def scatter_gather_coordinator(state: MessagePassingState) -> dict:
    """Coordinator that scatters requests and gathers responses."""
    task = state.get("task")
    workers = ["worker_1", "worker_2", "worker_3"]

    # Scatter phase: send requests to all workers
    scatter_messages = []
    correlation_ids = []

    for worker in workers:
        msg_id = str(uuid.uuid4())
        correlation_ids.append(msg_id)
        scatter_messages.append(RequestMessage(
            id=msg_id,
            sender="coordinator",
            timestamp=time.time(),
            priority=MessagePriority.HIGH,
            action="process",
            payload={"task": task, "worker": worker},
            timeout_ms=10000
        ))

    return {
        "outbox": scatter_messages,
        "pending_requests": {m.id: m for m in scatter_messages}
    }

def gather_responses(state: MessagePassingState) -> dict:
    """Gather and aggregate responses from workers."""
    responses = [m for m in state["inbox"] if isinstance(m, ResponseMessage)]

    # Aggregate results
    successful = [r for r in responses if r.success]
    failed = [r for r in responses if not r.success]

    if len(successful) >= 2:  # Quorum
        aggregated = aggregate_results([r.result for r in successful])
        return {"final_result": aggregated, "status": "success"}
    else:
        return {"status": "failed", "errors": [r.error for r in failed]}
```

#### Comparison Matrix

| Aspect            | Shared Memory          | Message Queues            |
| :---------------- | :--------------------- | :------------------------ |

#### Implementation: Shared Memory with LangGraph

```python
from typing import TypedDict, Annotated, Dict, Any
from threading import Lock
import operator

class SharedMemoryState(TypedDict):
    """State using shared memory pattern."""
    # Shared workspace all agents can read/write
    workspace: Annotated[Dict[str, Any], operator.ior]
    # Version vector for conflict detection
    versions: Dict[str, int]
    # Lock status (for optimistic locking)
    locks: Dict[str, str]  # key -> agent_id holding lock

class SharedMemoryManager:
    """Manages shared state with conflict resolution."""

    def __init__(self):
        self._lock = Lock()
        self._versions: Dict[str, int] = {}

    def read(self, key: str, state: SharedMemoryState) -> tuple[Any, int]:
        """Read value with version for optimistic locking."""
        value = state["workspace"].get(key)
        version = state["versions"].get(key, 0)
        return value, version

    def write(self, key: str, value: Any, expected_version: int,
              state: SharedMemoryState) -> tuple[bool, dict]:
        """Write with optimistic locking - fails if version mismatch."""
        current_version = state["versions"].get(key, 0)

        if current_version != expected_version:
            # Conflict detected
            return False, {}

        # Success - update value and increment version
        return True, {
            "workspace": {key: value},
            "versions": {key: current_version + 1}
        }

    def acquire_lock(self, key: str, agent_id: str,
                     state: SharedMemoryState) -> tuple[bool, dict]:
        """Acquire exclusive lock on a key."""
        current_holder = state["locks"].get(key)

        if current_holder is not None and current_holder != agent_id:
            return False, {}  # Already locked by another agent

        return True, {"locks": {key: agent_id}}

    def release_lock(self, key: str, agent_id: str,
                     state: SharedMemoryState) -> dict:
        """Release lock if held by this agent."""
        if state["locks"].get(key) == agent_id:
            new_locks = {k: v for k, v in state["locks"].items() if k != key}
            return {"locks": new_locks}
        return {}

def create_shared_memory_agent(agent_id: str, manager: SharedMemoryManager):
    """Agent that uses shared memory for coordination."""

    def agent_node(state: SharedMemoryState) -> dict:
        updates = {}

        # Read current shared state
        findings, version = manager.read("findings", state)

        # Do work
        my_finding = research_and_analyze(state, agent_id)

        # Try to update shared state (optimistic locking)
        if findings is None:
            findings = []

        new_findings = findings + [my_finding]
        success, write_updates = manager.write(
            "findings", new_findings, version, state
        )

        if success:
            updates.update(write_updates)
        else:
            # Conflict - retry logic or merge
            current_findings, _ = manager.read("findings", state)
            merged = merge_findings(current_findings, [my_finding])
            _, write_updates = manager.write(
                "findings", merged, version + 1, state
            )
            updates.update(write_updates)

        return updates

    return agent_node

# Build shared memory workflow
manager = SharedMemoryManager()
workflow = StateGraph(SharedMemoryState)

for agent_id in ["researcher", "analyst", "writer"]:
    workflow.add_node(agent_id, create_shared_memory_agent(agent_id, manager))

workflow.add_edge(START, "researcher")
workflow.add_edge(START, "analyst")
workflow.add_edge("researcher", "writer")
workflow.add_edge("analyst", "writer")
workflow.add_edge("writer", END)
```

#### Implementation: Message Queue Pattern

```python
from typing import TypedDict, Annotated, List, Dict
from dataclasses import dataclass
from collections import deque
import operator

@dataclass
class QueueMessage:
    """Message in a queue."""
    id: str
    payload: dict
    timestamp: float
    retries: int = 0

class MessageQueueState(TypedDict):
    """State using message queue pattern."""
    # Named queues between agents
    queues: Dict[str, List[QueueMessage]]
    # Dead letter queue for failed messages
    dlq: Annotated[List[QueueMessage], operator.add]
    # Processing results
    results: Annotated[Dict[str, Any], operator.ior]

class MessageQueue:
    """Simple message queue implementation."""

    def __init__(self, name: str, max_size: int = 1000):
        self.name = name
        self.max_size = max_size

    def enqueue(self, message: QueueMessage, state: MessageQueueState) -> dict:
        """Add message to queue."""
        queue = state["queues"].get(self.name, [])

        if len(queue) >= self.max_size:
            # Queue full - send to DLQ
            return {"dlq": [message]}

        return {"queues": {self.name: queue + [message]}}

    def dequeue(self, state: MessageQueueState) -> tuple[QueueMessage | None, dict]:
        """Remove and return message from queue."""
        queue = state["queues"].get(self.name, [])

        if not queue:
            return None, {}

        message = queue[0]
        remaining = queue[1:]
        return message, {"queues": {self.name: remaining}}

    def peek(self, state: MessageQueueState) -> QueueMessage | None:
        """View next message without removing."""
        queue = state["queues"].get(self.name, [])
        return queue[0] if queue else None

def create_queue_producer(agent_id: str, output_queue: MessageQueue):
    """Agent that produces messages to a queue."""

    def producer_node(state: MessageQueueState) -> dict:
        # Do work
        result = process_task(state, agent_id)

        # Enqueue result for next stage
        message = QueueMessage(
            id=str(uuid.uuid4()),
            payload={"result": result, "producer": agent_id},
            timestamp=time.time()
        )

        return output_queue.enqueue(message, state)

    return producer_node

def create_queue_consumer(agent_id: str, input_queue: MessageQueue,
                          output_queue: MessageQueue | None = None):
    """Agent that consumes from one queue and optionally produces to another."""

    def consumer_node(state: MessageQueueState) -> dict:
        updates = {}

        # Dequeue message
        message, dequeue_updates = input_queue.dequeue(state)
        updates.update(dequeue_updates)

        if message is None:
            return updates  # Nothing to process

        try:
            # Process message
            result = process_message(message.payload, agent_id)

            if output_queue:
                # Forward to next queue
                next_message = QueueMessage(
                    id=str(uuid.uuid4()),
                    payload={"result": result, "producer": agent_id},
                    timestamp=time.time()
                )
                updates.update(output_queue.enqueue(next_message, state))
            else:
                # Final stage - store result
                updates["results"] = {agent_id: result}

        except Exception as e:
            # Retry or DLQ
            if message.retries < 3:
                message.retries += 1
                updates.update(input_queue.enqueue(message, state))
            else:
                updates["dlq"] = [message]

        return updates

    return consumer_node

# Build message queue pipeline
q1 = MessageQueue("stage1_to_stage2")
q2 = MessageQueue("stage2_to_stage3")

workflow = StateGraph(MessageQueueState)
workflow.add_node("producer", create_queue_producer("producer", q1))
workflow.add_node("processor", create_queue_consumer("processor", q1, q2))
workflow.add_node("finalizer", create_queue_consumer("finalizer", q2))

workflow.add_edge(START, "producer")
workflow.add_edge("producer", "processor")
workflow.add_edge("processor", "finalizer")
workflow.add_edge("finalizer", END)
```

<Callout type="insight" title="Choosing Between Patterns">
  **Use Shared Memory when:**
  - Agents need to see each other's work in real-time
  - Strong consistency is required
  - The number of agents is small (< 10)
  
  **Use Message Queues when:**
  - Agents work asynchronously at different speeds
  - You need to scale horizontally
  - Fault isolation is important
  - Processing order matters
</Callout>
