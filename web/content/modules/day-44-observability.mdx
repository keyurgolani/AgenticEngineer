## The Debugging Nightmare

Debugging agentic systems is uniquely challenging. Agents fail silently, loop endlessly, or produce subtly incorrect outputs. The only clue is often buried in massive, nested JSON logs.

> **Key Insight**: Traditional logging is insufficient. You need specialized observability tools designed for multi-step, non-deterministic workflows.

> **Analogy**: Debugging an agent without observability is like trying to fix a car engine while blindfolded. You hear strange noises (errors), feel vibrations (performance issues), but can't see which part is failing. Observability tools are like X-ray vision—they let you see inside the "black box" and watch each component in action.

### OpenLLMetry: GenAI Semantic Conventions

[OpenLLMetry](https://github.com/traceloop/openllmetry) by Traceloop implements the OpenTelemetry GenAI semantic conventions, providing automatic instrumentation for popular LLM libraries.

```bash
pip install traceloop-sdk opentelemetry-exporter-otlp
```

### Basic Setup

```python
from traceloop.sdk import Traceloop

# Initialize with your preferred backend
Traceloop.init(
    app_name="my-agent",
    api_endpoint="http://localhost:4318",  # OTLP endpoint
    disable_batch=False  # Batch spans for efficiency
)

# That's it! LLM calls are now automatically traced
from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
# Span automatically created with model, tokens, latency
```

### GenAI Semantic Attributes

OpenTelemetry defines standard attributes for LLM operations:

```python
from opentelemetry import trace
from opentelemetry.semconv.ai import SpanAttributes

tracer = trace.get_tracer("my-agent")

with tracer.start_as_current_span("llm.chat") as span:
    # Standard GenAI attributes
    span.set_attribute(SpanAttributes.LLM_SYSTEM, "openai")
    span.set_attribute(SpanAttributes.LLM_REQUEST_MODEL, "gpt-4o")
    span.set_attribute(SpanAttributes.LLM_REQUEST_MAX_TOKENS, 1000)
    span.set_attribute(SpanAttributes.LLM_RESPONSE_MODEL, "gpt-4o-2024-08-06")
    span.set_attribute(SpanAttributes.LLM_USAGE_PROMPT_TOKENS, 150)
    span.set_attribute(SpanAttributes.LLM_USAGE_COMPLETION_TOKENS, 89)
    span.set_attribute(SpanAttributes.LLM_USAGE_TOTAL_TOKENS, 239)

    # Make your LLM call
    response = llm.invoke(messages)
```

LLM costs can spiral quickly in production. Effective cost tracking requires per-request attribution, tenant-level budgets, and proactive alerting.

> **Real-World Horror Story**: A startup left their AI chatbot running without cost monitoring. A single user discovered they could ask the bot to "write a novel" and triggered 50,000+ token responses. Their daily OpenAI bill jumped from $200 to $8,000 overnight. Budget alerts would have caught this in the first hour.

### Token-Based Cost Calculation

<CostCalculator defaultModel="gpt-4o" showComparison={false} />

```python
from dataclasses import dataclass
from typing import Optional
import time

# Pricing per 1M tokens (as of early 2025)
MODEL_PRICING = {
    "gpt-4o": {"input": 2.50, "output": 10.00},
    "gpt-4o-mini": {"input": 0.15, "output": 0.60},
    "gpt-4-turbo": {"input": 10.00, "output": 30.00},
    "claude-3-5-sonnet": {"input": 3.00, "output": 15.00},
    "claude-3-5-haiku": {"input": 0.80, "output": 4.00},
}

@dataclass
class UsageMetrics:
    model: str
    input_tokens: int
    output_tokens: int
    latency_ms: int
    user_id: Optional[str] = None
    tenant_id: Optional[str] = None

    @property
    def cost_usd(self) -> float:
        pricing = MODEL_PRICING.get(self.model, {"input": 0, "output": 0})
        input_cost = (self.input_tokens / 1_000_000) * pricing["input"]
        output_cost = (self.output_tokens / 1_000_000) * pricing["output"]
        return input_cost + output_cost

class CostTracker:
    def __init__(self, db_connection):
        self.db = db_connection

    def track(self, metrics: UsageMetrics):
        """Record usage for cost attribution."""
        self.db.execute("""
            INSERT INTO llm_usage
            (timestamp, model, input_tokens, output_tokens,
             cost_usd, user_id, tenant_id, latency_ms)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
        """, (
            time.time(), metrics.model, metrics.input_tokens,
            metrics.output_tokens, metrics.cost_usd,
            metrics.user_id, metrics.tenant_id, metrics.latency_ms
        ))
```

### Cost-Tracking Wrapper

```python
from functools import wraps
from openai import OpenAI

client = OpenAI()
cost_tracker = CostTracker(db)

def track_cost(user_id: str = None, tenant_id: str = None):
    """Decorator to track LLM costs per request."""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            start = time.time()
            response = func(*args, **kwargs)
            latency_ms = int((time.time() - start) * 1000)

            # Extract usage from response
            usage = response.usage
            metrics = UsageMetrics(
                model=response.model,
                input_tokens=usage.prompt_tokens,
                output_tokens=usage.completion_tokens,
                latency_ms=latency_ms,
                user_id=user_id,
                tenant_id=tenant_id
            )

            cost_tracker.track(metrics)
            logger.info(
                "llm_cost_tracked",
                cost_usd=metrics.cost_usd,
                model=metrics.model,
                tokens=usage.total_tokens
            )

            return response
        return wrapper
    return decorator

# Usage
@track_cost(user_id="user_123", tenant_id="acme_corp")
def generate_response(messages: list):
    return client.chat.completions.create(
        model="gpt-4o",
        messages=messages
    )
```

### Budget Alerts and Quotas

```python
from prometheus_client import Gauge

# Prometheus metrics for cost monitoring
daily_cost = Gauge('llm_daily_cost_usd', 'Daily LLM cost', ['tenant_id'])
budget_remaining = Gauge('llm_budget_remaining_pct', 'Budget remaining %', ['tenant_id'])

class BudgetManager:
    def __init__(self, db, alert_service):
        self.db = db
        self.alerts = alert_service

    def check_budget(self, tenant_id: str) -> bool:
        """Check if tenant is within budget. Returns False if over limit."""
        tenant = self.db.get_tenant(tenant_id)
        daily_spend = self.db.get_daily_spend(tenant_id)

        # Update metrics
        daily_cost.labels(tenant_id=tenant_id).set(daily_spend)
        remaining_pct = (1 - daily_spend / tenant.daily_limit) * 100
        budget_remaining.labels(tenant_id=tenant_id).set(remaining_pct)

        # Alert at 80% threshold
        if daily_spend > tenant.daily_limit * 0.8:
            self.alerts.send(
                channel="slack",
                message=f"⚠️ Tenant {tenant_id} at {remaining_pct:.0f}% of daily budget"
            )

        # Hard stop at 100%
        if daily_spend >= tenant.daily_limit:
            self.alerts.send(
                channel="pagerduty",
                message=f"🚨 Tenant {tenant_id} exceeded daily budget"
            )
            return False

        return True
```

## 44.7 Real-Time Monitoring & Alerting

Production agents need real-time visibility and proactive alerting to catch issues before users notice.

### Streaming Trace Visualization

```python
import asyncio
from collections import deque
from fastapi import FastAPI, WebSocket

app = FastAPI()

# In-memory trace buffer for real-time streaming
trace_buffer = deque(maxlen=1000)

async def emit_trace(trace_data: dict):
    """Emit trace to all connected WebSocket clients."""
    trace_buffer.append(trace_data)
    # Broadcast to connected clients (implementation depends on your setup)

@app.websocket("/ws/traces")
async def trace_stream(websocket: WebSocket):
    """WebSocket endpoint for real-time trace streaming."""
    await websocket.accept()

    # Send recent traces
    for trace in trace_buffer:
        await websocket.send_json(trace)

    # Stream new traces
    last_idx = len(trace_buffer)
    while True:
        await asyncio.sleep(0.1)
        current_idx = len(trace_buffer)
        if current_idx > last_idx:
            for trace in list(trace_buffer)[last_idx:current_idx]:
                await websocket.send_json(trace)
            last_idx = current_idx
```

```python
    now = datetime.utcnow()
    window = now - timedelta(minutes=5)

    metrics = db.query("""
        SELECT
            COUNT(*) as total_requests,
            SUM(CASE WHEN status = 'error' THEN 1 ELSE 0 END) as errors,
            AVG(latency_ms) as avg_latency,
            PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY latency_ms) as p95_latency
        FROM agent_requests
        WHERE timestamp > %s
    """, (window,))

    error_rate = metrics.errors / max(metrics.total_requests, 1)

    health = {
        "status": "healthy",
        "timestamp": now.isoformat(),
        "metrics": {
            "requests_5m": metrics.total_requests,
            "error_rate": error_rate,
            "avg_latency_ms": metrics.avg_latency,
            "p95_latency_ms": metrics.p95_latency
        }
    }

    # Determine health status
    if error_rate > 0.1:
        health["status"] = "degraded"
    if error_rate > 0.25 or metrics.p95_latency > 30000:
        health["status"] = "unhealthy"

    return health
```

### PagerDuty/Slack Integration

```python
import httpx
from enum import Enum

class AlertSeverity(Enum):
    INFO = "info"
    WARNING = "warning"
    CRITICAL = "critical"

class AlertService:
    def __init__(self, slack_webhook: str, pagerduty_key: str):
        self.slack_webhook = slack_webhook
        self.pagerduty_key = pagerduty_key

    async def send_slack(self, message: str, severity: AlertSeverity):
        """Send alert to Slack channel."""
        emoji = {"info": "ℹ️", "warning": "⚠️", "critical": "🚨"}

        async with httpx.AsyncClient() as client:
            await client.post(self.slack_webhook, json={
                "text": f"{emoji[severity.value]} {message}",
                "attachments": [{
                    "color": {"info": "#36a64f", "warning": "#ff9800", "critical": "#f44336"}[severity.value]
                }]
            })

    async def send_pagerduty(self, message: str, severity: AlertSeverity):
        """Create PagerDuty incident for critical alerts."""
        if severity != AlertSeverity.CRITICAL:
            return

        async with httpx.AsyncClient() as client:
            await client.post(
                "https://events.pagerduty.com/v2/enqueue",
                json={
                    "routing_key": self.pagerduty_key,
                    "event_action": "trigger",
                    "payload": {
                        "summary": message,
                        "severity": "critical",
                        "source": "agent-monitoring"
                    }
                }
            )

    async def alert(self, message: str, severity: AlertSeverity = AlertSeverity.WARNING):
        """Send alert to appropriate channels based on severity."""
        await self.send_slack(message, severity)
        if severity == AlertSeverity.CRITICAL:
            await self.send_pagerduty(message, severity)
```

```python
    iteration = state.get("iteration", 0)

    if iteration > 20:
        logger.error("loop_detected", iteration=iteration)
        return {"status": "error", "reason": "max_iterations_exceeded"}

    # Check for repeated actions
    recent_actions = state.get("action_history", [])[-5:]
```

{/* IMAGE_PLACEHOLDER: Create a visual metaphor for context overflow:

> **Analogy**: Context overflow is like trying to have a conversation in a crowded, noisy room. At first, you can hear clearly (low token count). As more people join (more messages), the important instructions (system prompt) get drowned out by the noise. Eventually, the model can't "hear" what you originally asked it to do.

**Detection**:

```python
def check_context_health(messages: list) -> dict:
    total_tokens = count_tokens(messages)
    system_tokens = count_tokens([m for m in messages if m["role"] == "system"])

    metrics = {
        "total_tokens": total_tokens,
        "system_ratio": system_tokens / total_tokens,
        "message_count": len(messages)
    }

    if total_tokens > 100000:
        logger.warning("context_overflow_risk", **metrics)

    if metrics["system_ratio"] < 0.05:
        logger.warning("system_prompt_diluted", **metrics)

    return metrics
```

### Issue 3: Tool Failures

**Symptoms**: Agent retries same tool, gives up

**Detection**:

```python
def tool_with_diagnostics(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        tool_name = func.__name__

        try:
            result = func(*args, **kwargs)

            logger.info(
                "tool_success",
                tool=tool_name,
                latency_ms=int((time.time() - start) * 1000),
                result_size=len(str(result))
            )

            return result

        except Exception as e:
            logger.error(
                "tool_failure",
                tool=tool_name,
                error=str(e),
                args=str(args)[:200],
                latency_ms=int((time.time() - start) * 1000)
            )
            raise

    return wrapper
```
