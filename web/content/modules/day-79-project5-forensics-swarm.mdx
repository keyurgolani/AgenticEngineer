### Acceptance Criteria

#### US-01: Multi-Source Investigation

- **Given** a suspicious transaction ID
- **When** the investigation agent runs
- **Then** the system:
  - Retrieves transaction details from Stripe
  - Queries customer information from the database
  - Searches for related communications in Slack
  - Checks audit logs for user activity
  - Compiles all findings into a unified view

#### US-02: Automatic Data Correlation

- **Given** transaction data from Stripe
- **When** the agent identifies a customer ID
- **Then** the system automatically:
  - Looks up the customer in PostgreSQL
  - Finds their account creation date
  - Searches Slack for mentions of their email
  - Correlates IP addresses across systems

#### US-03: Risk Scoring

- **Given** investigation findings
- **When** the analysis phase completes
- **Then** the system calculates a risk score (0-100) based on:
  - Account age vs. transaction amount
  - Transaction velocity (frequency)
  - Amount patterns (round numbers, just under limits)
  - Communication history presence
  - Geographic consistency

#### US-04: Audit Trail

- **Given** an investigation is in progress
- **When** any tool is invoked
- **Then** the system logs:
  - Timestamp
  - Tool name and parameters
  - Data source accessed
  - Results summary (not raw data)
  - Reasoning for the query

#### US-05: Human-in-the-Loop for High Risk

- **Given** a risk score >= 70
- **When** the investigation reaches the decision phase
- **Then** the system:
  - Pauses execution
  - Sends notification to fraud team
  - Waits for human approval/rejection
  - Records the decision and approver

#### US-06: Report Generation

- **Given** an investigation is complete
- **When** the report is generated
- **Then** the output includes:
  - Case ID and transaction ID
  - Risk score with explanation
  - Timeline of events
  - Evidence summary
  - Recommendation (BLOCK/REVIEW/APPROVE)
  - All sources cited

### Graph-Based Fraud Detection

Graph Neural Networks (GNNs) analyze the network structure of financial transactions, capturing patterns that traditional methods miss. Unlike examining transactions in isolation, GNNs map connections between accounts and trace money flows across entire networks.

```python
from dataclasses import dataclass
from typing import List, Dict
import networkx as nx

@dataclass
class TransactionNode:
    account_id: str
    transaction_ids: List[str]
    total_volume: float
    connection_count: int

@dataclass
class GraphFraudSignal:
    signal_type: str  # "ring", "layering", "burst"
    confidence: float
    involved_accounts: List[str]
    description: str

class GraphFraudDetector:
    """Detect fraud patterns using graph analysis."""

    def __init__(self):
        self.graph = nx.DiGraph()

    def build_transaction_graph(self, transactions: List[dict]) -> None:
        """Build graph from transaction data."""
        for txn in transactions:
            self.graph.add_edge(
                txn["source_account"],
                txn["dest_account"],
                amount=txn["amount"],
                timestamp=txn["timestamp"],
                txn_id=txn["id"]
            )

    def detect_fraud_rings(self) -> List[GraphFraudSignal]:
        """Detect circular transaction patterns (fraud rings)."""
        signals = []

        # Find strongly connected components (potential rings)
        sccs = list(nx.strongly_connected_components(self.graph))

        for scc in sccs:
            if len(scc) >= 3:  # Ring requires at least 3 nodes
                subgraph = self.graph.subgraph(scc)
                total_flow = sum(d["amount"] for _, _, d in subgraph.edges(data=True))

                signals.append(GraphFraudSignal(
                    signal_type="ring",
                    confidence=min(0.9, len(scc) * 0.15),
                    involved_accounts=list(scc),
                    description=f"Circular flow detected: {len(scc)} accounts, ${total_flow:,.2f} total"
                ))

        return signals

    def detect_layering(self, account_id: str, depth: int = 3) -> List[GraphFraudSignal]:
        """Detect money layering patterns (rapid fund movement through multiple accounts)."""
        signals = []

        # Find all paths from account within depth
        paths = []
        for target in self.graph.nodes():
            if target != account_id:
                try:
                    for path in nx.all_simple_paths(self.graph, account_id, target, cutoff=depth):
                        if len(path) >= 3:
                            paths.append(path)
                except nx.NetworkXNoPath:
                    continue

        # Analyze timing of transactions along paths
        for path in paths:
            timestamps = []
            for i in range(len(path) - 1):
                edge_data = self.graph.get_edge_data(path[i], path[i+1])
                timestamps.append(edge_data["timestamp"])

            # Check if transactions happened in rapid succession (< 1 hour apart)
            if self._is_rapid_sequence(timestamps):
                signals.append(GraphFraudSignal(
                    signal_type="layering",
                    confidence=0.75,
                    involved_accounts=path,
                    description=f"Rapid fund movement through {len(path)} accounts"
                ))

        return signals

    def calculate_account_risk(self, account_id: str) -> Dict[str, float]:
        """Calculate risk metrics for an account based on graph position."""
        if account_id not in self.graph:
            return {"overall_risk": 0.0}

        # PageRank indicates importance/centrality in transaction network
        pagerank = nx.pagerank(self.graph)

        # Betweenness centrality indicates if account is a "bridge"
        betweenness = nx.betweenness_centrality(self.graph)

        # In-degree vs out-degree ratio (high out = potential source of fraud)
        in_deg = self.graph.in_degree(account_id)
        out_deg = self.graph.out_degree(account_id)

        return {
            "pagerank_score": pagerank.get(account_id, 0),
            "betweenness_score": betweenness.get(account_id, 0),
            "flow_ratio": out_deg / max(in_deg, 1),
            "overall_risk": self._calculate_composite_risk(
                pagerank.get(account_id, 0),
                betweenness.get(account_id, 0),
                out_deg / max(in_deg, 1)
            )
        }
```

```python
@dataclass
class BehavioralProfile:
    user_id: str
    typing_cadence_ms: float  # Average time between keystrokes
    mouse_velocity: float     # Average mouse movement speed
    session_duration_avg: float
    time_of_day_pattern: List[int]  # Hour buckets of typical activity
    device_fingerprints: List[str]

@dataclass
class BehavioralAnomaly:
    anomaly_type: str
    deviation_score: float  # Standard deviations from normal
    details: str

class BehavioralBiometricsAnalyzer:
    """Analyze behavioral patterns for fraud detection."""

    def __init__(self, profile_store):
        self.profile_store = profile_store

    async def analyze_session(
        self,
        user_id: str,
        session_data: dict
    ) -> List[BehavioralAnomaly]:
        """Compare current session behavior against user's profile."""
        anomalies = []
        profile = await self.profile_store.get_profile(user_id)

        if not profile:
            # New user - flag for enhanced monitoring
            return [BehavioralAnomaly(
                anomaly_type="new_user",
                deviation_score=0,
                details="No behavioral baseline established"
            )]

        # Check typing cadence
        if session_data.get("typing_cadence_ms"):
            deviation = abs(session_data["typing_cadence_ms"] - profile.typing_cadence_ms)
            if deviation > profile.typing_cadence_ms * 0.5:  # 50% deviation
                anomalies.append(BehavioralAnomaly(
                    anomaly_type="typing_pattern",
                    deviation_score=deviation / profile.typing_cadence_ms,
                    details=f"Typing speed differs significantly from baseline"
                ))

        # Check device fingerprint
        if session_data.get("device_fingerprint"):
            if session_data["device_fingerprint"] not in profile.device_fingerprints:
                anomalies.append(BehavioralAnomaly(
                    anomaly_type="new_device",
                    deviation_score=1.0,
                    details="Transaction from unrecognized device"
                ))

        # Check time-of-day pattern
        current_hour = session_data.get("hour_of_day", 12)
        if current_hour not in profile.time_of_day_pattern:
            anomalies.append(BehavioralAnomaly(
                anomaly_type="unusual_time",
                deviation_score=0.5,
                details=f"Activity at unusual hour: {current_hour}:00"
            ))

        return anomalies
```

```python
        "name_ssn_mismatch_age": 0.15,  # SSN issued before birth year
        "no_social_footprint": 0.15,

    async def analyze_identity(
        self,
        identity_data: dict,
        mcp_client  # For cross-system queries
    ) -> tuple[float, List[SyntheticIdentitySignal]]:
        """Analyze identity for synthetic fraud indicators."""
        signals = []

        # Check SSN issuance date vs claimed birth year
        ssn_data = await mcp_client.call_tool(

            "check_ssn_issuance",

                risk_contribution=0.15,
                evidence=f"SSN issued {ssn_data['issuance_year']}, birth year {identity_data['birth_year']}"

        credit_data = await mcp_client.call_tool(
            "credit_bureau",
            "get_credit_summary",
            {"ssn": identity_data["ssn"]}
        )

        if credit_data["account_count"] < 2 and credit_data["oldest_account_months"] < 12:
            signals.append(SyntheticIdentitySignal(
                signal_name="thin_credit_file",
                risk_contribution=0.20,
                evidence=f"Only {credit_data['account_count']} accounts, oldest {credit_data['oldest_account_months']} months"
            ))
            total_risk += 0.20

        # Check address velocity (multiple identities at same address)
        address_check = await mcp_client.call_tool(
            "postgres",
            "query",
            {"sql": f"SELECT COUNT(DISTINCT ssn) FROM users WHERE address_hash = '{identity_data['address_hash']}'"}

        if address_check[0]["count"] > 3:
            signals.append(SyntheticIdentitySignal(
                signal_name="address_velocity",
                risk_contribution=0.15,
                evidence=f"{address_check[0]['count']} different identities at this address"
            ))
            total_risk += 0.15

        # Check for disposable email
        email_domain = identity_data["email"].split("@")[1]
        if email_domain in DISPOSABLE_EMAIL_DOMAINS:
            signals.append(SyntheticIdentitySignal(
                signal_name="email_disposable",
                risk_contribution=0.10,
                evidence=f"Disposable email domain: {email_domain}"
            ))
```

Account takeover attacks exploit valid credentials, making them difficult to detect. Modern ATO detection combines multiple signals.

```python
@dataclass
class ATOSignal:
    signal_type: str
    severity: str  # "low", "medium", "high", "critical"
    details: str
    recommended_action: str

class ATODetector:
    """Detect account takeover attempts."""

    async def analyze_login_session(
        self,
        user_id: str,
        session: dict,
        mcp_client
    ) -> List[ATOSignal]:
        """Analyze login session for ATO indicators."""
        signals = []

        # Get user's historical login data
        history = await mcp_client.call_tool(
            "postgres",
            "query",
            {"sql": f"""
                SELECT ip_address, device_fingerprint, country,
                       login_time, success
                FROM login_history
                WHERE user_id = '{user_id}'
                ORDER BY login_time DESC
                LIMIT 100
            """}
        )

        # Check for impossible travel
        if history:
            last_login = history[0]
            time_diff_hours = (session["timestamp"] - last_login["login_time"]).total_seconds() / 3600

            if last_login["country"] != session["country"]:
                # Calculate if travel is physically possible
                distance_km = self._calculate_distance(
                    last_login["country"],
                    session["country"]
                )
                max_travel_km = time_diff_hours * 900  # ~900 km/h max flight speed

                if distance_km > max_travel_km:
                    signals.append(ATOSignal(
                        signal_type="impossible_travel",
                        severity="critical",
                        details=f"Login from {session['country']} {time_diff_hours:.1f}h after {last_login['country']}",
                        recommended_action="Block and require re-authentication"
                    ))

        # Check for credential stuffing pattern
        failed_attempts = await mcp_client.call_tool(
            "postgres",
            "query",
            {"sql": f"""
                SELECT COUNT(*) as failures
                FROM login_history
                WHERE user_id = '{user_id}'
                AND success = false
                AND login_time > NOW() - INTERVAL '1 hour'
            """}
        )

        if failed_attempts[0]["failures"] >= 5:
            signals.append(ATOSignal(
                signal_type="credential_stuffing",
                severity="high",
                details=f"{failed_attempts[0]['failures']} failed attempts in last hour",
                recommended_action="Enforce CAPTCHA and rate limit"
            ))

        # Check for session anomalies
        if session.get("user_agent") and history:
            known_agents = {h["device_fingerprint"] for h in history}
            if session["device_fingerprint"] not in known_agents:
                signals.append(ATOSignal(
                    signal_type="new_device",
                    severity="medium",
                    details="Login from previously unseen device",
                    recommended_action="Send verification email/SMS"
                ))

        return signals
```

### Evidence Aggregation and Confidence Scoring

```python
class EvidenceAggregator:
    """Aggregate findings from multiple specialist agents."""

    def aggregate_findings(
        self,
        state: ParallelInvestigationState
    ) -> tuple[List[AgentFinding], dict[str, float]]:
        """Combine all findings and calculate confidence scores."""

        all_findings = (
            state["payment_findings"] +
            state["communication_findings"] +
            state["behavior_findings"] +
            state["graph_findings"]
        )

        # Group findings by type
        findings_by_type: dict[str, List[AgentFinding]] = {}
        for finding in all_findings:
            if finding.finding_type not in findings_by_type:
                findings_by_type[finding.finding_type] = []
            findings_by_type[finding.finding_type].append(finding)

        # Calculate confidence scores with corroboration bonus
        confidence_scores = {}
        for finding_type, findings in findings_by_type.items():
            base_confidence = max(f.confidence for f in findings)

            # Corroboration bonus: multiple agents agreeing increases confidence
            corroboration_bonus = min(0.15, (len(findings) - 1) * 0.05)

            confidence_scores[finding_type] = min(0.99, base_confidence + corroboration_bonus)

        return all_findings, confidence_scores

    def detect_disagreements(
        self,
        state: ParallelInvestigationState
    ) -> List[AgentDisagreement]:
        """Identify cases where agents have conflicting findings."""
        disagreements = []

        # Example: Check if payment and behavior agents disagree on risk level
        payment_risk = sum(f.risk_contribution for f in state["payment_findings"])
        behavior_risk = sum(f.risk_contribution for f in state["behavior_findings"])

        if abs(payment_risk - behavior_risk) > 0.3:
            disagreements.append(AgentDisagreement(
                topic="overall_risk_level",
                agents=["Payment Analyst", "Behavior Analyst"],
                positions={
                    "Payment Analyst": f"Risk contribution: {payment_risk:.2f}",
                    "Behavior Analyst": f"Risk contribution: {behavior_risk:.2f}"
                }
            ))

        return disagreements

    def resolve_disagreements(
        self,
        disagreements: List[AgentDisagreement],
        llm
    ) -> List[AgentDisagreement]:
        """Use LLM to resolve agent disagreements."""
        resolved = []

        for disagreement in disagreements:
            prompt = f"""
            Two investigation agents disagree on {disagreement.topic}.

            Positions:
            {disagreement.positions}

            Based on the evidence, which position is more credible and why?
            Provide a resolution.
            """

            resolution = llm.invoke(prompt)
            disagreement.resolution = resolution.content
            resolved.append(disagreement)

        return resolved

def calculate_final_risk_score(
    all_findings: List[AgentFinding],
    confidence_scores: dict[str, float],
    disagreements: List[AgentDisagreement]
) -> float:
    """Calculate final risk score from aggregated findings."""

    # Base score from risk contributions
    base_score = sum(f.risk_contribution * f.confidence for f in all_findings)

    # Apply confidence weighting
    weighted_score = 0
    for finding in all_findings:
        type_confidence = confidence_scores.get(finding.finding_type, finding.confidence)
        weighted_score += finding.risk_contribution * type_confidence

    # Penalty for unresolved disagreements
    disagreement_penalty = len([d for d in disagreements if not d.resolution]) * 0.05

    final_score = min(100, max(0, (weighted_score * 100) - disagreement_penalty))

    return final_score
```

```python
from dataclasses import dataclass
from datetime import datetime
import asyncio

@dataclass
class MCPServerHealth:
    server_name: str
    status: str  # "healthy", "degraded", "unavailable"
    latency_ms: float
    last_check: datetime
    error_rate_1h: float

class MCPHealthMonitor:
    """Monitor health of connected MCP servers."""

    def __init__(self, servers: list[str]):
        self.servers = servers
        self.health_cache: dict[str, MCPServerHealth] = {}

    async def check_server_health(self, server_name: str) -> MCPServerHealth:
        """Perform health check on a single MCP server."""
        start = datetime.now()
        try:
            # Ping the server with a lightweight operation
            async with asyncio.timeout(5.0):
                await self.client.call_tool(server_name, "health_check", {})

            latency = (datetime.now() - start).total_seconds() * 1000
            return MCPServerHealth(
                server_name=server_name,
                status="healthy" if latency < 1000 else "degraded",
                latency_ms=latency,
                last_check=datetime.now(),
                error_rate_1h=self._calculate_error_rate(server_name)
            )
        except asyncio.TimeoutError:
            return MCPServerHealth(
                server_name=server_name,
                status="unavailable",
                latency_ms=-1,
                last_check=datetime.now(),
                error_rate_1h=1.0
            )

    async def get_available_servers(self) -> list[str]:
        """Return list of healthy servers for investigation routing."""
        health_checks = await asyncio.gather(
            *[self.check_server_health(s) for s in self.servers]
        )
        return [h.server_name for h in health_checks if h.status != "unavailable"]
```

```python
            "status": obj.status,
            "customer": obj.customer,

            "metadata": dict(obj.metadata)
        }, indent=2)
    except stripe.error.StripeError as e:
        return f"Stripe error: {str(e)}"

@mcp.tool()
async def search_transactions(
    customer_id: str = None,
    min_amount: float = None,
    max_amount: float = None,
    status: str = None,
    limit: int = 10
) -> str:
    """Search Stripe transactions with filters.

    Args:
        customer_id: Filter by customer ID
        min_amount: Minimum amount in dollars
        max_amount: Maximum amount in dollars
        status: Filter by status (succeeded, pending, failed)
        limit: Maximum results to return
    """
    params = {"limit": limit}

    if customer_id:
        params["customer"] = customer_id

    charges = stripe.Charge.list(**params)

    results = []
    for charge in charges.data:
        amount = charge.amount / 100

        if min_amount and amount < min_amount:
            continue
        if max_amount and amount > max_amount:
            continue
        if status and charge.status != status:
            continue

        results.append({
            "id": charge.id,
            "amount": amount,
            "status": charge.status,
            "customer": charge.customer,
            "created": charge.created
        })

    return json.dumps(results, indent=2)
```

## 79.5 Investigation Workflow

```python
from typing import TypedDict, List
from langgraph.graph import StateGraph, START, END

class InvestigationState(TypedDict):
    case_id: str
    transaction_id: str
    findings: List[dict]
    risk_score: float
    recommendation: str
    evidence: List[str]

async def gather_transaction_data(state: InvestigationState) -> dict:
    """Gather initial transaction data."""
    agent = await create_investigation_agent()

    result = await agent.ainvoke({
        "input": f"""Investigate transaction {state['transaction_id']}.

        Step 1: Get the transaction details from Stripe.
        Step 2: Identify the customer ID.
        Step 3: Get customer details.

        Return the findings as structured data."""
    })

    return {
        "findings": [{"stage": "transaction_data", "data": result["output"]}]
    }

async def check_user_history(state: InvestigationState) -> dict:
    """Check user's history across systems."""
    agent = await create_investigation_agent()

    result = await agent.ainvoke({
        "input": f"""Based on the previous findings, investigate the user's history.

        Previous findings: {state['findings']}

        Step 1: Query the users table in PostgreSQL for this customer.
        Step 2: Check when the account was created.
        Step 3: Look for any previous transactions.
        Step 4: Search Slack for any mentions of this user or their email.

        Note any red flags."""
    })

    return {
        "findings": state["findings"] + [{"stage": "user_history", "data": result["output"]}]
    }

async def analyze_patterns(state: InvestigationState) -> dict:
    """Analyze patterns and anomalies."""
    agent = await create_investigation_agent()

    result = await agent.ainvoke({
        "input": f"""Analyze patterns in the collected data.

        All findings so far: {state['findings']}

        Look for:
        1. Velocity anomalies (too many transactions too fast)
        2. Amount anomalies (round numbers, just under limits)
        3. Timing anomalies (unusual hours)
        4. Geographic inconsistencies
        5. Missing expected data (no email verification, no address)

        Calculate a risk score from 0-100."""
    })

    # Extract risk score from response
    import re
    risk_match = re.search(r'risk.*?(\d+)', result["output"].lower())
    risk_score = int(risk_match.group(1)) if risk_match else 50

    return {
        "findings": state["findings"] + [{"stage": "pattern_analysis", "data": result["output"]}],
        "risk_score": risk_score
    }

async def generate_report(state: InvestigationState) -> dict:
    """Generate final investigation report."""

    # Determine recommendation based on risk score
    if state["risk_score"] >= 80:
        recommendation = "BLOCK - High fraud probability"
    elif state["risk_score"] >= 50:
        recommendation = "REVIEW - Manual review required"
    else:
        recommendation = "APPROVE - Low risk"

    report = f"""
# Investigation Report: {state['case_id']}

## Transaction: {state['transaction_id']}

## Risk Score: {state['risk_score']}/100

## Recommendation: {recommendation}

## Findings Summary:
"""

    for finding in state["findings"]:
        report += f"\n### {finding['stage'].replace('_', ' ').title()}\n"
        report += finding["data"][:500] + "...\n"

    return {
        "recommendation": recommendation,
        "evidence": [f["data"] for f in state["findings"]]
    }

# Build the investigation graph
def build_investigation_workflow():
    workflow = StateGraph(InvestigationState)

    workflow.add_node("gather_transaction", gather_transaction_data)
    workflow.add_node("check_history", check_user_history)
    workflow.add_node("analyze_patterns", analyze_patterns)
    workflow.add_node("generate_report", generate_report)

    workflow.add_edge(START, "gather_transaction")
    workflow.add_edge("gather_transaction", "check_history")
    workflow.add_edge("check_history", "analyze_patterns")
    workflow.add_edge("analyze_patterns", "generate_report")
    workflow.add_edge("generate_report", END)

    return workflow.compile()
```

```python
from langgraph.checkpoint.sqlite import SqliteSaver

def build_investigation_with_approval():
    workflow = StateGraph(InvestigationState)

    # ... add nodes ...

    # Compile with interrupt
    checkpointer = SqliteSaver.from_conn_string("investigations.db")

    return workflow.compile(
        checkpointer=checkpointer,
        interrupt_before=["human_review"]
    )
```

### PCI DSS 4.0 Requirements for Fraud Systems

PCI DSS 4.0 became fully mandatory on March 31, 2025. Key requirements affecting fraud detection systems:

| Requirement | Description                                    | Implementation                                        |
| :---------- | :--------------------------------------------- | :---------------------------------------------------- |
| **10.4.1**  | Audit logs must be protected from modification | Immutable log storage, cryptographic signing          |
| **10.4.2**  | Automated mechanisms to detect tampering       | Log integrity monitoring                              |
| **11.6.1**  | Deploy change-detection mechanisms             | File integrity monitoring on investigation scripts    |
| **12.3.1**  | Targeted risk analysis for customized approach | Document risk decisions for ML-based fraud scoring    |
| **8.3.6**   | MFA for all access to cardholder data          | Require MFA for analyst access to investigation tools |
| **8.6.1**   | Manage system/application accounts             | Service accounts for MCP servers must be inventoried  |

```python
from datetime import datetime
import hashlib
import json

class PCI_DSS_AuditLogger:
    """PCI DSS 4.0 compliant audit logging for investigations."""

    def __init__(self, log_store, signing_key: bytes):
        self.log_store = log_store
        self.signing_key = signing_key
        self.previous_hash = "0" * 64  # Genesis hash

    def log_investigation_action(
        self,
        case_id: str,
        action: str,
        actor: str,
        data_accessed: List[str],
        result_summary: str,
        pii_fields_accessed: List[str] = None
    ) -> str:
        """Create tamper-evident audit log entry."""

        entry = {
            "timestamp": datetime.utcnow().isoformat() + "Z",
            "case_id": case_id,
            "action": action,
            "actor": actor,
            "actor_ip": self._get_actor_ip(),
            "data_sources_accessed": data_accessed,
            "result_summary": result_summary,  # Never log raw PII
            "pii_fields_accessed": pii_fields_accessed or [],
            "previous_hash": self.previous_hash,
        }

        # Create chain hash for tamper detection (Req 10.4.2)
        entry_json = json.dumps(entry, sort_keys=True)
        entry["hash"] = hashlib.sha256(
            (entry_json + self.signing_key.hex()).encode()
        ).hexdigest()

        self.previous_hash = entry["hash"]

        # Store in immutable log (Req 10.4.1)
        self.log_store.append(entry)

        return entry["hash"]

    def verify_log_integrity(self) -> tuple[bool, List[str]]:
        """Verify audit log chain hasn't been tampered with."""
        errors = []
        previous_hash = "0" * 64

        for i, entry in enumerate(self.log_store.get_all()):
            # Verify chain
            if entry["previous_hash"] != previous_hash:
                errors.append(f"Chain break at entry {i}")

            # Verify entry hash
            entry_copy = {k: v for k, v in entry.items() if k != "hash"}
            entry_json = json.dumps(entry_copy, sort_keys=True)
            expected_hash = hashlib.sha256(
                (entry_json + self.signing_key.hex()).encode()
            ).hexdigest()

            if entry["hash"] != expected_hash:
                errors.append(f"Hash mismatch at entry {i}")

            previous_hash = entry["hash"]

        return len(errors) == 0, errors
```

### Rate Limiting Across MCP Servers

```python
from dataclasses import dataclass
from collections import defaultdict
import asyncio
import time

@dataclass
class RateLimitConfig:
    requests_per_minute: int
    requests_per_hour: int
    burst_limit: int

class MCPRateLimiter:
    """Rate limiter for MCP server calls."""

    DEFAULT_LIMITS = {
        "stripe": RateLimitConfig(100, 1000, 25),
        "slack": RateLimitConfig(50, 500, 10),
        "postgres": RateLimitConfig(200, 5000, 50),
        "filesystem": RateLimitConfig(100, 2000, 20),
    }

    def __init__(self):
        self.request_times: dict[str, list[float]] = defaultdict(list)
        self.locks: dict[str, asyncio.Lock] = defaultdict(asyncio.Lock)

    async def acquire(self, server_name: str) -> bool:
        """Acquire permission to make a request."""
        async with self.locks[server_name]:
            config = self.DEFAULT_LIMITS.get(
                server_name,
                RateLimitConfig(50, 500, 10)
            )

            now = time.time()

            # Clean old entries
            self.request_times[server_name] = [
                t for t in self.request_times[server_name]
                if now - t < 3600  # Keep last hour
            ]

            times = self.request_times[server_name]

            # Check hourly limit
            if len(times) >= config.requests_per_hour:
                return False

            # Check per-minute limit
            recent = [t for t in times if now - t < 60]
            if len(recent) >= config.requests_per_minute:
                # Wait until we can make another request
                wait_time = 60 - (now - min(recent))
                await asyncio.sleep(wait_time)

            # Check burst limit
            very_recent = [t for t in times if now - t < 1]
            if len(very_recent) >= config.burst_limit:
                await asyncio.sleep(1)

            self.request_times[server_name].append(time.time())
            return True

    async def call_with_rate_limit(
        self,
        mcp_client,
        server_name: str,
        tool_name: str,
        args: dict
    ):
        """Make MCP call with rate limiting."""
        await self.acquire(server_name)
        return await mcp_client.call_tool(server_name, tool_name, args)
```

### Caching Strategies

```python
from functools import lru_cache
import hashlib
import json
from typing import Optional, Any
import redis.asyncio as redis

class InvestigationCache:
    """Multi-tier caching for investigation queries."""

    def __init__(self, redis_url: str):
        self.redis = redis.from_url(redis_url)
        self.local_cache: dict[str, tuple[Any, float]] = {}
        self.local_ttl = 60  # 1 minute local cache

    def _cache_key(self, server: str, tool: str, args: dict) -> str:
        """Generate cache key from request parameters."""
        args_hash = hashlib.md5(
            json.dumps(args, sort_keys=True).encode()
        ).hexdigest()[:12]
        return f"mcp:{server}:{tool}:{args_hash}"

    async def get(
        self,
        server: str,
        tool: str,
        args: dict
    ) -> Optional[Any]:
        """Get cached result if available."""
        key = self._cache_key(server, tool, args)

        # Check local cache first
        if key in self.local_cache:
            value, timestamp = self.local_cache[key]
            if time.time() - timestamp < self.local_ttl:
                return value
            del self.local_cache[key]

        # Check Redis
        cached = await self.redis.get(key)
        if cached:
            value = json.loads(cached)
            self.local_cache[key] = (value, time.time())
            return value

        return None

    async def set(
        self,
        server: str,
        tool: str,
        args: dict,
        result: Any,
        ttl_seconds: int = 300
    ) -> None:
        """Cache a result."""
        key = self._cache_key(server, tool, args)

        # Different TTLs based on data type
        if server == "stripe" and tool == "get_transaction":
            ttl_seconds = 3600  # Transactions don't change
        elif server == "slack" and tool == "search_messages":
            ttl_seconds = 60  # Messages can be edited/deleted
        elif server == "postgres":
            ttl_seconds = 300  # 5 minutes for DB queries

        await self.redis.setex(key, ttl_seconds, json.dumps(result))
        self.local_cache[key] = (result, time.time())

    async def invalidate_case(self, case_id: str) -> None:
        """Invalidate all cache entries for a case."""
        pattern = f"mcp:*:*:*{case_id}*"
        async for key in self.redis.scan_iter(pattern):
            await self.redis.delete(key)
```

### Fallback Patterns

```python
from enum import Enum
from typing import Callable, Any

class FallbackStrategy(Enum):
    RETRY = "retry"
    CACHE = "cache"
    DEGRADE = "degrade"
    FAIL = "fail"

class MCPFallbackHandler:
    """Handle MCP server failures gracefully."""

    def __init__(self, cache: InvestigationCache):
        self.cache = cache
        self.server_status: dict[str, str] = {}
        self.fallback_strategies: dict[str, FallbackStrategy] = {
            "stripe": FallbackStrategy.RETRY,
            "slack": FallbackStrategy.DEGRADE,
            "postgres": FallbackStrategy.CACHE,
            "filesystem": FallbackStrategy.FAIL,
        }

    async def call_with_fallback(
        self,
        mcp_client,
        server_name: str,
        tool_name: str,
        args: dict,
        max_retries: int = 3
    ) -> tuple[Any, str]:  # Returns (result, source)
        """Make MCP call with fallback handling."""

        strategy = self.fallback_strategies.get(server_name, FallbackStrategy.FAIL)

        for attempt in range(max_retries):
            try:
                result = await asyncio.wait_for(
                    mcp_client.call_tool(server_name, tool_name, args),
                    timeout=10.0
                )

                # Cache successful result
                await self.cache.set(server_name, tool_name, args, result)
                self.server_status[server_name] = "healthy"

                return result, "live"

            except asyncio.TimeoutError:
                self.server_status[server_name] = "timeout"

                if strategy == FallbackStrategy.RETRY and attempt < max_retries - 1:
                    await asyncio.sleep(2 ** attempt)  # Exponential backoff
                    continue

            except Exception as e:
                self.server_status[server_name] = f"error: {str(e)}"

        # All retries failed - apply fallback strategy
        if strategy == FallbackStrategy.CACHE:
            cached = await self.cache.get(server_name, tool_name, args)
            if cached:
                return cached, "cache"

        if strategy == FallbackStrategy.DEGRADE:
            return self._get_degraded_response(server_name, tool_name), "degraded"

        raise MCPServerUnavailableError(f"{server_name} unavailable after {max_retries} retries")

    def _get_degraded_response(self, server: str, tool: str) -> dict:
        """Return degraded response when server unavailable."""
        return {
            "status": "degraded",
            "server": server,
            "tool": tool,
            "message": f"Data from {server} temporarily unavailable",
            "data": None
        }

class MCPServerUnavailableError(Exception):
    pass
```

```python
@dataclass
class MCPCostConfig:
    cost_per_call: float
    cost_per_mb: float
    monthly_budget: float

class InvestigationCostOptimizer:
    """Optimize costs for multi-source investigations."""

    COST_CONFIG = {
        "stripe": MCPCostConfig(0.001, 0.0001, 100.0),
        "slack": MCPCostConfig(0.0005, 0.0001, 50.0),
        "postgres": MCPCostConfig(0.0001, 0.00001, 20.0),
        "openai": MCPCostConfig(0.01, 0.0, 500.0),  # LLM calls
    }

    def __init__(self):
        self.monthly_spend: dict[str, float] = defaultdict(float)

    def estimate_investigation_cost(
        self,
        planned_calls: dict[str, int]
    ) -> dict:
        """Estimate cost before running investigation."""
        estimates = {}
        total = 0.0

        for server, call_count in planned_calls.items():
            config = self.COST_CONFIG.get(server)
            if config:
                cost = call_count * config.cost_per_call
                estimates[server] = cost
                total += cost

        return {
            "breakdown": estimates,
            "total_estimated": total,
            "budget_remaining": self._get_budget_remaining(),
        }

    def optimize_query_plan(
        self,
        required_data: List[str],
        budget_limit: float
    ) -> List[dict]:
        """Optimize query plan to stay within budget."""

        # Prioritize by information value / cost ratio
        data_sources = [
            {"source": "postgres", "data": "user_history", "cost": 0.001, "value": 0.8},
            {"source": "stripe", "data": "transactions", "cost": 0.01, "value": 0.9},
            {"source": "slack", "data": "communications", "cost": 0.005, "value": 0.5},
        ]

        # Sort by value/cost ratio
        sorted_sources = sorted(
            data_sources,
            key=lambda x: x["value"] / x["cost"],
            reverse=True
        )

        # Select sources within budget
        selected = []
        remaining_budget = budget_limit

        for source in sorted_sources:
            if source["cost"] <= remaining_budget:
                selected.append(source)
                remaining_budget -= source["cost"]

        return selected

    def track_spend(self, server: str, cost: float) -> None:
        """Track spending for budget monitoring."""
        self.monthly_spend[server] += cost

        config = self.COST_CONFIG.get(server)
        if config and self.monthly_spend[server] > config.monthly_budget * 0.8:
            # Alert when approaching budget
            self._send_budget_alert(server, self.monthly_spend[server], config.monthly_budget)
```
