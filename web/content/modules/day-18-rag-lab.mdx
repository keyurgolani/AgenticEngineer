In this lab, you'll build a **Company Policy Assistant**—an agent that can answer questions about company documents while remembering user preferences and past interactions. This combines:

- **RAG** (from Day 17) for document retrieval
- **Semantic Memory** for user preferences
- **Episodic Memory** for conversation history
- **LangGraph Checkpointing** for session persistence
- **LangGraph Store** for cross-thread user profiles

<Callout type="info">
  **What's New:** This lab uses LangGraph's Store API for cross-thread memory,
  which persists user preferences across different conversation threads. This is
  the recommended approach for production applications.
</Callout>

### Agentic RAG: Beyond Simple Retrieval

Traditional RAG follows a fixed pipeline: retrieve → generate. **Agentic RAG** adds intelligence to this process:

<ConceptVisual
  src="/images/rag_vs_agentic_rag_comparison.png"
  alt="Traditional vs Agentic RAG"
  caption="Agentic RAG adds critical reasoning loops to evaluate and improve quality."
/>

<Mermaid

Key agentic RAG patterns we'll implement:

- **Query routing**: Direct simple queries, decompose complex ones
- **Document grading**: Verify retrieved documents are actually relevant
- **Self-correction**: Rewrite queries when retrieval fails
- **Hallucination checking**: Ensure answers are grounded in retrieved context

<Callout type="info">
  **Analogy: The Research Librarian** — Think of Agentic RAG like a skilled
  research librarian vs. a simple search engine. A search engine returns results
  and stops. A librarian evaluates if the books they found actually answer your
  question, tries different search terms if the first attempt fails, and
  double-checks that their recommendations are based on the books they found
  (not their own assumptions). That's the difference between traditional RAG and
  Agentic RAG.
</Callout>

## 6.3 Building the RAG Pipeline

<ConceptVisual
  src="/images/rag_indexing_visualization.png"
  alt="Vector Indexing Process"
  caption="Documents are split into chunks, converted to vectors, and stored in high-dimensional space."
/>

Now let's build a RAG pipeline that indexes these documents:

```python title="rag_pipeline.py"
import chromadb
from pathlib import Path
from typing import List, Dict, Any
from sentence_transformers import SentenceTransformer

class PolicyRAG:
    """RAG pipeline for company policy documents."""

    def __init__(self, persist_path: str = "./memory/rag"):
        self.persist_path = Path(persist_path)
        self.persist_path.mkdir(parents=True, exist_ok=True)

        # Initialize ChromaDB with persistence
        self.chroma = chromadb.PersistentClient(
            path=str(self.persist_path)
        )
        self.collection = self.chroma.get_or_create_collection(
            name="policies",
            metadata={"hnsw:space": "cosine"}
        )

        # Local embedding model (no API calls needed)
        self.embedder = SentenceTransformer('all-MiniLM-L6-v2')

    def index_documents(self, docs_dir: str) -> int:
        """Index all markdown documents in a directory."""
        docs_path = Path(docs_dir)
        indexed = 0

        for file_path in docs_path.glob("*.md"):
            content = file_path.read_text()
            chunks = self._chunk_document(content, str(file_path))

            for i, chunk in enumerate(chunks):
                doc_id = f"{file_path.stem}_{i}"

                # Generate embedding
                embedding = self.embedder.encode(chunk["text"]).tolist()

                # Upsert to handle re-indexing
                self.collection.upsert(
                    ids=[doc_id],
                    documents=[chunk["text"]],
                    embeddings=[embedding],
                    metadatas=[{
                        "source": chunk["source"],
                        "section": chunk.get("section", ""),
                        "chunk_index": i
                    }]
                )
                indexed += 1

        return indexed

    def _chunk_document(
        self,
        content: str,
        source: str
    ) -> List[Dict[str, Any]]:
        """Chunk document by sections (headers)."""
        chunks: List[Dict[str, Any]] = []
        current_section = ""
        current_text = ""

        for line in content.split("\n"):
            if line.startswith("# "):
                # New top-level section
                if current_text.strip():
                    chunks.append({
                        "text": current_text.strip(),
                        "source": source,
                        "section": current_section
                    })
                current_section = line[2:].strip()
                current_text = line + "\n"
            elif line.startswith("## "):
                # New subsection - save previous and start new
                if current_text.strip():
                    chunks.append({
                        "text": current_text.strip(),
                        "source": source,
                        "section": current_section
                    })
                current_section = line[3:].strip()
                current_text = line + "\n"
            else:
                current_text += line + "\n"

        # Don't forget the last chunk
        if current_text.strip():
            chunks.append({
                "text": current_text.strip(),
                "source": source,
                "section": current_section
            })

        return chunks

    def search(self, query: str, n_results: int = 3) -> List[Dict[str, Any]]:
        """Search for relevant policy chunks."""
        # Generate query embedding
        query_embedding = self.embedder.encode(query).tolist()

        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=n_results,
            include=["documents", "metadatas", "distances"]
        )

        # Format results
        formatted: List[Dict[str, Any]] = []
        if results["documents"] and results["documents"][0]:
            for doc, meta, dist in zip(
                results["documents"][0],
                results["metadatas"][0],
                results["distances"][0]
            ):
                formatted.append({
                    "content": doc,
                    "source": meta["source"],
                    "section": meta["section"],
                    "relevance": 1 - dist  # Convert distance to similarity
                })

        return formatted

    def to_context(self, query: str, n_results: int = 3) -> str:
        """Convert search results to context string for LLM."""
        results = self.search(query, n_results)

        if not results:
            return "No relevant policy documents found."

        parts = ["## Relevant Policy Information\n"]
        for r in results:
            source_name = Path(r["source"]).stem.replace("-", " ").title()
            parts.append(f"### {source_name} - {r['section']}")
            parts.append(r["content"])
            parts.append("")

        return "\n".join(parts)


# Test the RAG pipeline
if __name__ == "__main__":
    rag = PolicyRAG()

    # Index documents
    count = rag.index_documents("./documents")
    print(f"✅ Indexed {count} chunks")

    # Test search
    results = rag.search("Can I work from home on Friday?")
    for r in results:
        print(f"\n📄 {r['section']} (relevance: {r['relevance']:.2f})")
        print(r['content'][:200] + "...")
```

## 6.4 Agentic RAG: Document Grading and Query Rewriting

<ConceptVisual
  src="/images/agentic_rag_flowchart.png"
  alt="Agentic RAG Retry Loop"
  caption="Self-correction allows the agent to recover from poor initial retrieval."
/>

Let's enhance our RAG pipeline with agentic capabilities—the ability to evaluate retrieval quality and self-correct when needed.

```python title="agentic_rag.py"
from typing import List, Dict, Any, Literal
from openai import OpenAI
import json

class AgenticRAG:
    """RAG pipeline with document grading and query rewriting."""

    def __init__(self, base_rag: PolicyRAG):
        self.rag = base_rag
        self.client = OpenAI()

    def query(
        self,
        question: str,
        max_retries: int = 2
    ) -> Dict[str, Any]:
        """Query with automatic retry and query rewriting."""

        current_query = question
        attempts = []

        for attempt in range(max_retries + 1):
            # Step 1: Retrieve documents
            docs = self.rag.search(current_query, n_results=5)

            # Step 2: Grade document relevance
            graded_docs = self._grade_documents(question, docs)
            relevant_docs = [d for d in graded_docs if d["relevant"]]

            attempts.append({
                "query": current_query,
                "docs_retrieved": len(docs),
                "docs_relevant": len(relevant_docs)
            })

            # Step 3: If we have relevant docs, generate answer
            if relevant_docs:
                answer = self._generate_answer(question, relevant_docs)

                # Step 4: Check for hallucination
                if self._check_grounded(answer, relevant_docs):
                    return {
                        "answer": answer,
                        "sources": [d["source"] for d in relevant_docs],
                        "attempts": attempts,
                        "grounded": True
                    }

            # Step 5: Rewrite query if we need to retry
            if attempt < max_retries:
                current_query = self._rewrite_query(
                    original=question,
                    previous_query=current_query,
                    failed_docs=docs
                )

        # Fallback: return best effort answer
        return {
            "answer": "I couldn't find relevant information to answer this question confidently.",
            "sources": [],
            "attempts": attempts,
            "grounded": False
        }

    def _grade_documents(
        self,
        question: str,
        docs: List[Dict]
    ) -> List[Dict]:
        """Grade each document for relevance to the question."""

        graded = []
        for doc in docs:
            response = self.client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{
                    "role": "system",
                    "content": """You are a relevance grader. Given a question and a document,
determine if the document contains information relevant to answering the question.
Return JSON: {"relevant": true/false, "reason": "brief explanation"}"""
                }, {
                    "role": "user",
                    "content": f"Question: {question}\n\nDocument:\n{doc['content']}"
                }],
                response_format={"type": "json_object"}
            )

            grade = json.loads(response.choices[0].message.content)
            graded.append({**doc, **grade})

        return graded

    def _rewrite_query(
        self,
        original: str,
        previous_query: str,
        failed_docs: List[Dict]
    ) -> str:
        """Rewrite query to improve retrieval."""

        doc_summaries = "\n".join([
            f"- {d['section']}: {d['content'][:100]}..."
            for d in failed_docs[:3]
        ])

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """You are a query rewriter. The previous query didn't retrieve
relevant documents. Rewrite it to be more specific or use different terminology.
Return only the rewritten query, nothing else."""
            }, {
                "role": "user",
                "content": f"""Original question: {original}
Previous query: {previous_query}
Documents retrieved (not relevant):
{doc_summaries}

Rewrite the query to find more relevant documents:"""
            }]
        )

        return response.choices[0].message.content.strip()

    def _generate_answer(
        self,
        question: str,
        docs: List[Dict]
    ) -> str:
        """Generate answer from relevant documents."""

        context = "\n\n".join([
            f"[{d['section']}]\n{d['content']}"
            for d in docs
        ])

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """Answer the question based ONLY on the provided context.
If the context doesn't contain enough information, say so.
Cite the relevant section when possible."""
            }, {
                "role": "user",
                "content": f"Context:\n{context}\n\nQuestion: {question}"
            }]
        )

        return response.choices[0].message.content

    def _check_grounded(
        self,
        answer: str,
        docs: List[Dict]
    ) -> bool:
        """Check if the answer is grounded in the documents."""

        context = "\n".join([d['content'] for d in docs])

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": """You are a fact-checker. Determine if the answer is
fully supported by the provided documents.
Return JSON: {"grounded": true/false, "unsupported_claims": ["list of claims not in docs"]}"""
            }, {
                "role": "user",
                "content": f"Documents:\n{context}\n\nAnswer to check:\n{answer}"
            }],
            response_format={"type": "json_object"}
        )

        result = json.loads(response.choices[0].message.content)
        return result["grounded"]


# Example usage
if __name__ == "__main__":
    base_rag = PolicyRAG()
    base_rag.index_documents("./documents")

    agentic = AgenticRAG(base_rag)

    # This query might need rewriting
    result = agentic.query("What happens if I submit expenses late?")

    print(f"Answer: {result['answer']}")
    print(f"Grounded: {result['grounded']}")
    print(f"Attempts: {len(result['attempts'])}")
    for i, attempt in enumerate(result['attempts']):
        print(f"  {i+1}. Query: '{attempt['query']}' -> {attempt['docs_relevant']}/{attempt['docs_retrieved']} relevant")
```

  ambiguous, (2) retrieval quality varies, or (3) accuracy is critical and you
  can afford extra latency.
</Callout>

## 6.5 Adding User Memory

<ConceptVisual
  src="/images/semantic_memory_filing_cabinet.png"

Now let's add semantic memory to remember user preferences:

```python title="user_memory.py"
import chromadb
from pathlib import Path
from typing import Dict, List, Optional, Any
from datetime import datetime
import json

class UserMemory:
    """Semantic memory for user preferences and facts."""

    def __init__(self, persist_path: str = "./memory/users"):
        self.persist_path = Path(persist_path)
        self.persist_path.mkdir(parents=True, exist_ok=True)

        self.chroma = chromadb.PersistentClient(
            path=str(self.persist_path / "chroma")
        )
        self.preferences = self.chroma.get_or_create_collection("preferences")

        # JSON file for structured user data
        self.users_file = self.persist_path / "users.json"
        self.users: Dict[str, Dict[str, Any]] = self._load_users()

    def _load_users(self) -> Dict[str, Dict[str, Any]]:
        """Load user data from disk."""
        if self.users_file.exists():
            return json.loads(self.users_file.read_text())
        return {}

    def _save_users(self) -> None:
        """Save user data to disk."""
        self.users_file.write_text(json.dumps(self.users, indent=2))

    def set_user_info(self, user_id: str, key: str, value: Any) -> None:
        """Store structured user information."""
        if user_id not in self.users:
            self.users[user_id] = {"created_at": datetime.now().isoformat()}

        self.users[user_id][key] = value
        self.users[user_id]["updated_at"] = datetime.now().isoformat()
        self._save_users()

        # Also store in vector DB for semantic search
        pref_text = f"User {key}: {value}"
        pref_id = f"{user_id}_{key}"

        self.preferences.upsert(
            ids=[pref_id],
            documents=[pref_text],
            metadatas=[{
                "user_id": user_id,
                "key": key,
                "value": str(value),
                "timestamp": datetime.now().isoformat()
            }]
        )

    def get_user_info(self, user_id: str, key: str) -> Optional[Any]:
        """Get specific user information."""
        if user_id in self.users:
            return self.users[user_id].get(key)
        return None

    def get_user_profile(self, user_id: str) -> Dict[str, Any]:
        """Get complete user profile."""
        return self.users.get(user_id, {})

    def search_preferences(
        self,
        user_id: str,
        query: str,
        n: int = 5
    ) -> List[str]:
        """Search user preferences semantically."""
        results = self.preferences.query(
            query_texts=[query],
            n_results=n,
            where={"user_id": user_id}
        )

        if results["documents"] and results["documents"][0]:
            return results["documents"][0]
        return []

    def to_context(self, user_id: str) -> str:
        """Convert user profile to context string."""
        profile = self.get_user_profile(user_id)

        if not profile:
            return "No user profile found."

        parts = ["## User Profile\n"]
        for key, value in profile.items():
            if key not in ["created_at", "updated_at"]:
                parts.append(f"- **{key}**: {value}")

        return "\n".join(parts)


# Test user memory
if __name__ == "__main__":
    memory = UserMemory()

    # Store user preferences
    memory.set_user_info("alice", "name", "Alice")
    memory.set_user_info("alice", "department", "Engineering")
    memory.set_user_info("alice", "tenure_years", 3)
    memory.set_user_info("alice", "preferred_communication", "Slack")

    # Retrieve
    print(memory.to_context("alice"))
```

## 6.6 Building the LangGraph Agent

<ConceptVisual
  src="/images/langgraph_state_machine.png"
  alt="LangGraph State Machine"
  caption="The architecture explicitly separates retrieval, reasoning, and learning phases."
/>

Now let's combine everything into a LangGraph agent with checkpointing and the Store API for cross-thread memory:

```python title="agent.py"
from typing import Annotated, TypedDict, List, Optional
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage, BaseMessage
from langchain_core.runnables import RunnableConfig
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver
from langgraph.checkpoint.sqlite import SqliteSaver
from langgraph.store.memory import InMemoryStore
from langgraph.store.base import BaseStore
from operator import add
import re

# Import our components
from rag_pipeline import PolicyRAG
from user_memory import UserMemory


class AgentState(TypedDict):
    """State for the policy assistant agent."""
    messages: Annotated[List[BaseMessage], add]
    user_id: str
    context: str


class PolicyAssistant:
    """Memory-augmented policy assistant agent."""

    def __init__(self, persist_path: str = "./memory"):
        # Initialize components
        self.rag = PolicyRAG(f"{persist_path}/rag")
        self.user_memory = UserMemory(f"{persist_path}/users")
        self.llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.1)
        self.persist_path = persist_path

        # Build the graph
        self.graph = self._build_graph()

    def _build_graph(self) -> StateGraph:
        """Build the LangGraph workflow."""
        workflow = StateGraph(AgentState)

        # Add nodes
        workflow.add_node("retrieve", self._retrieve_node)
        workflow.add_node("respond", self._respond_node)
        workflow.add_node("learn", self._learn_node)

        # Add edges
        workflow.add_edge(START, "retrieve")
        workflow.add_edge("retrieve", "respond")
        workflow.add_edge("respond", "learn")
        workflow.add_edge("learn", END)

        # Use SQLite for persistent checkpointing (conversation history)
        checkpointer = SqliteSaver.from_conn_string(
            f"{self.persist_path}/checkpoints.db"
        )

        # Use InMemoryStore for cross-thread memory (user profiles)
        # In production, use PostgresStore for persistence
        store = InMemoryStore()

        return workflow.compile(checkpointer=checkpointer, store=store)

    def _retrieve_node(
        self,
        state: AgentState,
        config: RunnableConfig,
        *,
        store: BaseStore
    ) -> dict:
        """Retrieve relevant context from RAG and user memory."""
        # Get the latest user message
        last_message = state["messages"][-1]
        query = last_message.content if hasattr(last_message, 'content') else str(last_message)
        user_id = state["user_id"]

        # Get RAG context
        rag_context = self.rag.to_context(query)

        # Get user context from Store (cross-thread memory)
        namespace = (user_id, "profile")
        profile_item = store.get(namespace, "info")

        if profile_item:
            user_context = f"## User Profile\n"
            for key, value in profile_item.value.items():
                user_context += f"- **{key}**: {value}\n"
        else:
            user_context = self.user_memory.to_context(user_id)

        # Combine contexts
        full_context = f"{user_context}\n\n{rag_context}"

        return {"context": full_context}

    def _respond_node(self, state: AgentState) -> dict:
        """Generate response using LLM."""
        system_prompt = f"""You are a helpful company policy assistant.
Answer questions based on the provided policy documents and user context.

{state['context']}

Guidelines:
- Be specific and cite the relevant policy when possible
- If information isn't in the policies, say so clearly
- Personalize responses based on user profile (e.g., tenure for PTO calculations)
- If the user shares preferences or information about themselves, acknowledge it
"""

        messages = [SystemMessage(content=system_prompt)] + state["messages"]

        response = self.llm.invoke(messages)

        return {"messages": [response]}

    def _learn_node(
        self,
        state: AgentState,
        config: RunnableConfig,
        *,
        store: BaseStore
    ) -> dict:
        """Extract and store user information from the conversation."""
        # Get the last user message
        messages = state["messages"]
        if len(messages) < 2:
            return {}

        last_user_msg = messages[-2].content if len(messages) >= 2 else ""
        user_id = state["user_id"]

        # Simple pattern matching for user info
        # In production, use LLM to extract this
        patterns = {
            "name": r"(?:my name is|I'm|I am)\s+(\w+)",
            "department": r"(?:I work in|I'm in|my department is)\s+(\w+)",
            "tenure_years": r"(?:I've been here|working here for)\s+(\d+)\s+years?",
        }

        extracted = {}
        for key, pattern in patterns.items():
            match = re.search(pattern, last_user_msg, re.IGNORECASE)
            if match:
                value = match.group(1)
                if key == "tenure_years":
                    value = int(value)
                extracted[key] = value
                # Also store in legacy user memory
                self.user_memory.set_user_info(user_id, key, value)

        # Store in LangGraph Store for cross-thread persistence
        if extracted:
            namespace = (user_id, "profile")
            existing = store.get(namespace, "info")
            if existing:
                # Merge with existing profile
                profile = {**existing.value, **extracted}
            else:
                profile = extracted

            store.put(namespace, "info", profile)

        return {}

    def chat(
        self,
        message: str,
        user_id: str,
        thread_id: Optional[str] = None
    ) -> str:
        """Send a message and get a response."""
        if thread_id is None:
            thread_id = f"{user_id}_default"

        config = {
            "configurable": {
                "thread_id": thread_id,
                "user_id": user_id
            }
        }

        result = self.graph.invoke(
            {
                "messages": [HumanMessage(content=message)],
                "user_id": user_id,
                "context": ""
            },
            config
        )

        # Return the last AI message
        for msg in reversed(result["messages"]):
            if isinstance(msg, AIMessage):
                return msg.content

        return "I couldn't generate a response."

    def get_conversation_history(
        self,
        user_id: str,
        thread_id: Optional[str] = None
    ) -> List[dict]:
        """Get conversation history for a thread."""
        if thread_id is None:
            thread_id = f"{user_id}_default"

        config = {"configurable": {"thread_id": thread_id}}

        state = self.graph.get_state(config)

        history = []
        if state.values and "messages" in state.values:
            for msg in state.values["messages"]:
                history.append({
                    "role": "user" if isinstance(msg, HumanMessage) else "assistant",
                    "content": msg.content
                })

        return history
```

<Callout type="tip">
  **Store vs UserMemory:** This example uses both the LangGraph Store (for
  cross-thread data) and our custom UserMemory class. In production, you'd
  likely use just the Store with a persistent backend like PostgresStore.
</Callout>

<Callout type="info">
  **Analogy: Checkpointer vs Store** — Think of the Checkpointer as your
  conversation notebook—it records everything said in one meeting (thread). The
  Store is like your contact database—it remembers facts about people across all
  meetings. When Alice starts a new conversation (new thread), the Checkpointer
  starts fresh, but the Store still remembers she's in Engineering with 3 years
  tenure. This separation allows personalization without carrying over
  irrelevant conversation history.
</Callout>

### Hybrid Search: Combining Dense and Sparse Retrieval

Dense embeddings excel at semantic similarity but can miss exact keyword matches. Combine with sparse retrieval (BM25) for best results:

<Mermaid
  chart={`
graph LR
    Query["Query: 'Remote work Friday'"]
    
    subgraph Dense[Dense Search]
        V1[Vector: 'Telecommute policy']
        V2[Vector: 'WFH guidelines']
    end
    
    subgraph Sparse[Sparse Search]
        K1[Keyword: 'Friday']
        K2[Keyword: 'Remote']
    end
    
    Query --> Dense
    Query --> Sparse
    
    Dense --> Fusion{Weighted Fusion}
    Sparse --> Fusion
    
    Fusion --> Result["Result: 'Fri WFH OK'"]
    
    style Dense fill:#e1bee7
    style Sparse fill:#bbdefb
    style Fusion fill:#c8e6c9
`}
  caption="Hybrid Search: Combining semantic understanding with keyword precision."
/>

<Callout type="info">
  **Analogy: Google Search** — Modern search engines use hybrid retrieval! When
  you search "best pizza near me", they use semantic understanding (you want
  food recommendations) AND keyword matching (the word "pizza" must appear).
  Dense embeddings are like understanding intent; sparse retrieval is like exact
  word matching. Combining both gives you the best of both worlds—understanding
  AND precision.
</Callout>

```python
from rank_bm25 import BM25Okapi
import numpy as np

class HybridSearch:
    """Combines dense embeddings with BM25 sparse retrieval."""

    def __init__(self, documents: List[str], embedder):
        self.documents = documents
        self.embedder = embedder

        # Dense: embed all documents
        self.embeddings = embedder.encode(documents)

        # Sparse: build BM25 index
        tokenized = [doc.lower().split() for doc in documents]
        self.bm25 = BM25Okapi(tokenized)

    def search(
        self,
        query: str,
        n_results: int = 5,
        alpha: float = 0.5  # Weight for dense vs sparse
    ) -> List[Dict]:
        """Hybrid search with configurable weighting."""

        # Dense scores
        query_embedding = self.embedder.encode(query)
        dense_scores = np.dot(self.embeddings, query_embedding)
        dense_scores = (dense_scores - dense_scores.min()) / (dense_scores.max() - dense_scores.min() + 1e-8)

        # Sparse scores
        sparse_scores = np.array(self.bm25.get_scores(query.lower().split()))
        sparse_scores = (sparse_scores - sparse_scores.min()) / (sparse_scores.max() - sparse_scores.min() + 1e-8)

        # Combine with Reciprocal Rank Fusion or weighted sum
        combined = alpha * dense_scores + (1 - alpha) * sparse_scores

        # Get top results
        top_indices = np.argsort(combined)[::-1][:n_results]

        return [
            {"content": self.documents[i], "score": combined[i]}
            for i in top_indices
        ]
```

### Contextual Compression

Reduce noise by compressing retrieved documents to only the relevant parts:

<Mermaid
  chart={`

    LLM -->|Extract| Sent1[Relevant Sentence 1]
    LLM -->|Extract| Sent2[Relevant Sentence 2]
    LLM -->|Ignore| Noise[Irrelevant Text]
    
    Sent1 & Sent2 --> Final[Compressed Context\n(50 tokens)]
    
    style Doc fill:#ffccbc

```python
class ContextualCompressor:
    """Compresses documents to only relevant portions."""

    def __init__(self):
        self.client = OpenAI()

    def compress(
        self,
        question: str,
        documents: List[str]
    ) -> List[str]:
        """Extract only relevant portions from each document."""

        compressed = []
        for doc in documents:
            response = self.client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{
                    "role": "system",
                    "content": """Extract ONLY the sentences from the document that are
relevant to answering the question. Return the relevant sentences verbatim.
If nothing is relevant, return "NOT_RELEVANT"."""
                }, {
                    "role": "user",
                    "content": f"Question: {question}\n\nDocument:\n{doc}"
                }]
            )

            result = response.choices[0].message.content
            if result != "NOT_RELEVANT":
                compressed.append(result)

        return compressed
```

### Multi-Query Retrieval

Generate multiple query variations to improve recall:

<Mermaid
  chart={`
graph TD
    Q[Original Query]
    
    Q --> Q1[Variation 1]
    Q --> Q2[Variation 2]
    Q --> Q3[Variation 3]
    
    Q1 --> D1[Docs 1]
    Q2 --> D2[Docs 2]
    Q3 --> D3[Docs 3]
    
    D1 & D2 & D3 --> Dedup{Deduplicate}
    Dedup --> Final[Final Set]
    
    style Q fill:#e1bee7
    style Final fill:#c8e6c9
`}
  caption="Multi-Query: Expanding search coverage with variations."
/>

```python
class MultiQueryRetriever:
    """Generates multiple queries to improve retrieval coverage."""

    def __init__(self, base_retriever):
        self.retriever = base_retriever
        self.client = OpenAI()

    def retrieve(
        self,
        question: str,
        n_queries: int = 3
    ) -> List[Dict]:
        """Generate multiple queries and deduplicate results."""

        # Generate query variations
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{
                "role": "system",
                "content": f"""Generate {n_queries} different versions of the given question.
Each version should approach the question from a different angle or use different terminology.
Return as JSON: {{"queries": ["query1", "query2", ...]}}"""
            }, {
                "role": "user",
                "content": question
            }],
            response_format={"type": "json_object"}
        )

        queries = json.loads(response.choices[0].message.content)["queries"]
        queries.append(question)  # Include original

        # Retrieve for each query
        all_docs = []
        seen_content = set()

        for query in queries:
            docs = self.retriever.search(query, n_results=3)
            for doc in docs:
                content_hash = hash(doc["content"])
                if content_hash not in seen_content:
                    seen_content.add(content_hash)
                    all_docs.append(doc)

        return all_docs
```

<Callout type="info">
  **RAG Evaluation:** Always measure your RAG system's performance. Key metrics
  include: (1) **Retrieval precision** - are retrieved docs relevant? (2)
  **Answer faithfulness** - is the answer grounded in retrieved docs? (3)
  **Answer relevance** - does the answer address the question? Tools like RAGAS
  and TruLens can automate this evaluation.
</Callout>
