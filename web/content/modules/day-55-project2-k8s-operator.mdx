## Project Overview

**Objective**: Create an autonomous Site Reliability Engineering (SRE) agent that monitors a Kubernetes cluster, diagnoses pod failures, plans remediation, and executes fixes after human approval—with full audit trails via GitOps.

**Why This Matters**: This project demonstrates event-driven architecture, policy-as-code, and human-in-the-loop patterns essential for production AI systems. In 2025, AI-powered SRE tools are transforming how teams handle incidents, with leading platforms automating up to 80% of incident response workflows.

**Real-World Analogy**: Think of this operator as an experienced SRE engineer who never sleeps. Just as a human SRE would: (1) monitor dashboards for anomalies, (2) investigate logs and metrics when issues arise, (3) consult runbooks for remediation steps, (4) get approval from a senior engineer before making changes, and (5) document everything for future reference—our AI agent does the same, but at machine speed and scale. The key difference? It never gets tired, never misses a pattern, and always follows the approval process.

**Skills Showcased**:

- Event-driven architecture
- Kubernetes API integration
- Policy enforcement (OPA/Kyverno)
- Human-in-the-loop (HITL) patterns
- GitOps integration (ArgoCD/Flux)
- Observability and metrics
- AI agent security

## The AIOps Landscape in 2025

<Callout type="info">
  **Industry Context**: The AIOps market has matured significantly. Tools like
  K8sGPT (a CNCF sandbox project), incident.io's AI SRE, and Causely's causal AI
  platform are now production-ready. The pattern we're building here reflects
  real-world architectures used by platform teams at scale.
</Callout>

Modern AI-powered SRE tools have evolved beyond simple chatbots. They now function as **agentic systems** that can:

1. **Detect** anomalies using ML-based pattern recognition
2. **Diagnose** root causes by correlating logs, metrics, and traces
3. **Plan** remediation using LLM reasoning over runbooks
4. **Execute** fixes through GitOps pipelines with policy guardrails
5. **Learn** from incident outcomes to improve future responses

The key insight driving this evolution: **most SRE pain comes from missing context, not missing data**. AI agents excel at stitching together context from disparate sources—logs, metrics, traces, deployment history, and documentation—to surface actionable insights.

**1. Prompt Injection via Logs**
Malicious actors can embed instructions in application logs that get passed to the LLM:

```python
# BAD: Directly passing logs to LLM
diagnosis = llm.invoke(f"Analyze these logs: {pod_logs}")

# GOOD: Sanitize and truncate logs, use structured prompts
sanitized_logs = sanitize_logs(pod_logs, max_chars=5000)
diagnosis = llm.invoke({
    "system": "You are a K8s diagnostician. Only output valid JSON.",
    "user": f"Analyze: {sanitized_logs}",
    "response_format": {"type": "json_object"}
})
```

**2. Command Injection via LLM Output**
Never execute LLM-generated commands directly:

```python
# BAD: Executing LLM output directly
commands = llm.invoke("Generate kubectl commands to fix this")
subprocess.run(commands, shell=True)  # DANGEROUS!

# GOOD: Validate against allowlist, use K8s Python client
plan = llm.invoke(...)
validated_plan = validate_against_allowlist(plan)
if validated_plan.fix_type == "restart":
    k8s_client.delete_namespaced_pod(name, namespace)  # Type-safe
```

**3. Data Exfiltration Prevention**
Redact sensitive data before sending to LLMs:

```python
def redact_sensitive_data(logs: str) -> str:
    """Remove secrets, tokens, and PII before LLM processing."""
    patterns = [
        (r'password[=:]\s*\S+', 'password=***REDACTED***'),
        (r'token[=:]\s*\S+', 'token=***REDACTED***'),
        (r'api[_-]?key[=:]\s*\S+', 'api_key=***REDACTED***'),
        (r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', '***EMAIL***'),
    ]
    for pattern, replacement in patterns:
        logs = re.sub(pattern, replacement, logs, flags=re.IGNORECASE)
    return logs
```

### Phase 2: Define State and Models (30 minutes)

#### Step 2.1: Create the Operator State

```python
# models/state.py
from typing import TypedDict, List, Optional, Literal
from datetime import datetime
from pydantic import BaseModel, Field

class PodEvent(BaseModel):
    """Kubernetes pod event data."""
    pod_name: str
    namespace: str
    event_type: str
    reason: str
    message: str
    timestamp: datetime
    container_statuses: List[dict]

class Diagnosis(BaseModel):
    """Diagnostic analysis result."""
    root_cause: str
    category: Literal["oom", "crash", "image", "config", "network", "storage", "unknown"]
    confidence: float = Field(ge=0, le=1)
    evidence: List[str]
    affected_components: List[str]
    metrics_summary: Optional[dict] = None

class RemediationPlan(BaseModel):
    """Proposed fix for the issue."""
    fix_type: Literal["restart", "scale", "patch", "rollback", "escalate"]
    description: str
    commands: List[str]
    manifest_changes: Optional[dict] = None
    risk_level: Literal["low", "medium", "high"]
    expected_outcome: str
    rollback_plan: str

class PolicyViolation(BaseModel):
    """Policy check result."""
    policy_name: str
    description: str
    severity: Literal["warning", "error", "critical"]
    source: Literal["opa", "kyverno", "internal"]

class K8sOperatorState(TypedDict):
    """Main state for the K8s operator workflow."""
    # Event data
    pod_name: str
    namespace: str
    event_type: str
    timestamp: str

    # Diagnostic data
    logs: str
    pod_yaml: str
    events: List[dict]
    metrics: Optional[dict]

    # Analysis
    diagnosis: Optional[dict]
    diagnosis_confidence: float

    # Remediation
    proposed_fix: Optional[dict]
    fix_type: str

    # Policy
    policy_violations: List[dict]
    policy_passed: bool

    # GitOps
    pr_url: Optional[str]
    pr_branch: Optional[str]
    pr_merged: bool

    # Approval
    human_approved: Optional[bool]
    approval_notes: str
    approver: str

    # Execution
    execution_result: str
    status: Literal["detected", "diagnosing", "planning", "awaiting_approval",
                    "creating_pr", "awaiting_merge", "executing",
                    "completed", "failed", "escalated"]

    # Metadata
    incident_id: str
    iteration_count: int
    errors: List[str]
```

```python
        "Error",

        "Evicted"
    ]

    def __init__(self, on_failure: Callable[[PodEvent], None]):
        """Initialize the watcher."""
        try:
            config.load_incluster_config()
        except config.ConfigException:
            config.load_kube_config()

        self.v1 = client.CoreV1Api()
        self.on_failure = on_failure
        self.seen_events = set()  # Deduplicate events
        self._reconnect_delay = 1  # Exponential backoff

    def _extract_container_statuses(self, pod) -> list:
        """Extract container status information."""
        statuses = []
        for status in pod.status.container_statuses or []:
            info = {
                "name": status.name,
                "ready": status.ready,
                "restart_count": status.restart_count,
                "state": None,
                "last_state": None
            }
            if status.state.waiting:
                info["state"] = {
                    "type": "waiting",
                    "reason": status.state.waiting.reason,
                    "message": status.state.waiting.message
                }
            elif status.state.running:
                info["state"] = {"type": "running"}
            elif status.state.terminated:
                info["state"] = {
                    "type": "terminated",
                    "reason": status.state.terminated.reason,
                    "exit_code": status.state.terminated.exit_code
                }
            if status.last_state.terminated:
                info["last_state"] = {
                    "reason": status.last_state.terminated.reason,
                    "exit_code": status.last_state.terminated.exit_code,
                    "finished_at": str(status.last_state.terminated.finished_at)
                }
            statuses.append(info)
        return statuses

    def _is_failure(self, pod) -> tuple[bool, str, str]:
        """Detect various failure conditions."""
        if pod.status.phase in ["Failed", "Unknown"]:
            return True, pod.status.phase, f"Pod in {pod.status.phase} phase"

        for status in pod.status.container_statuses or []:
            if status.state.waiting:
                reason = status.state.waiting.reason
                if reason in self.FAILURE_REASONS:
                    return True, reason, status.state.waiting.message or ""
            if status.last_state.terminated:
                if status.last_state.terminated.reason == "OOMKilled":
                    return True, "OOMKilled", "Container was killed due to OOM"
            if status.restart_count > 5:
                return True, "HighRestartCount", f"Container restarted {status.restart_count} times"

        return False, "", ""

    async def watch_pods(self, namespaces: Optional[list] = None):
        """Stream pod events and trigger agent on failures."""
        w = watch.Watch()
        print("👀 Starting Kubernetes pod watcher...")

        while True:
            try:
                if namespaces:
                    for ns in namespaces:
                        await self._watch_namespace(w, ns)
                else:
                    await self._watch_all_namespaces(w)
                self._reconnect_delay = 1  # Reset on success
            except ApiException as e:
                print(f"API error: {e}")
                await asyncio.sleep(self._reconnect_delay)
                self._reconnect_delay = min(self._reconnect_delay * 2, 60)
            except Exception as e:
                print(f"Watcher error: {e}")
                await asyncio.sleep(self._reconnect_delay)
                self._reconnect_delay = min(self._reconnect_delay * 2, 60)

    async def _watch_all_namespaces(self, w):
        """Watch all namespaces for pod events."""
        for event in w.stream(self.v1.list_pod_for_all_namespaces, timeout_seconds=60):
            await self._process_event(event)

    async def _watch_namespace(self, w, namespace: str):
        """Watch a specific namespace."""
        for event in w.stream(
            self.v1.list_namespaced_pod,
            namespace=namespace,
            timeout_seconds=60
        ):
            await self._process_event(event)

    async def _process_event(self, event):
        """Process a single pod event."""
        pod = event['object']
        event_type = event['type']
        event_id = f"{pod.metadata.namespace}/{pod.metadata.name}/{event_type}"

        if event_id in self.seen_events:
            return

        is_failure, reason, message = self._is_failure(pod)

        if is_failure:
            self.seen_events.add(event_id)
            pod_event = PodEvent(
                pod_name=pod.metadata.name,
                namespace=pod.metadata.namespace,
                event_type=event_type,
                reason=reason,
                message=message,
                timestamp=datetime.now(),
                container_statuses=self._extract_container_statuses(pod)
            )
            print(f"🚨 Failure detected: {pod_event.pod_name} - {reason}")
            await self.on_failure(pod_event)
```

```python
import httpx

class PrometheusClient:
    """Query Prometheus for pod metrics."""

    def __init__(self, url: Optional[str] = None):
        self.url = url or os.getenv("PROMETHEUS_URL", "http://prometheus:9090")

    async def query_pod_metrics(
        self,
        pod_name: str,
        namespace: str,
        duration: str = "1h"
    ) -> dict:
        """Get comprehensive metrics for a pod."""
        metrics = {}

        queries = {
            "cpu_usage": f'sum(rate(container_cpu_usage_seconds_total{{pod="{pod_name}",namespace="{namespace}"}}[5m]))',
            "memory_usage": f'sum(container_memory_usage_bytes{{pod="{pod_name}",namespace="{namespace}"}})',
            "memory_limit": f'sum(container_spec_memory_limit_bytes{{pod="{pod_name}",namespace="{namespace}"}})',
            "restart_count": f'sum(kube_pod_container_status_restarts_total{{pod="{pod_name}",namespace="{namespace}"}})',
            "oom_kills": f'sum(increase(container_oom_events_total{{pod="{pod_name}",namespace="{namespace}"}}[{duration}]))',
        }

        async with httpx.AsyncClient() as client:
            for metric_name, query in queries.items():
                try:
                    response = await client.get(
                        f"{self.url}/api/v1/query",
                        params={"query": query}
                    )
                    data = response.json()
                    if data["status"] == "success" and data["data"]["result"]:
                        metrics[metric_name] = float(data["data"]["result"][0]["value"][1])
                except Exception as e:
                    metrics[metric_name] = None
                    print(f"Warning: Could not fetch {metric_name}: {e}")

        # Calculate memory utilization percentage
        if metrics.get("memory_usage") and metrics.get("memory_limit"):
            metrics["memory_utilization_pct"] = (
                metrics["memory_usage"] / metrics["memory_limit"] * 100
            )

        return metrics
```

```python
def sanitize_logs(logs: str, max_chars: int = 5000) -> str:
    """Remove sensitive data and truncate logs."""
    patterns = [
        (r'password[=:]\s*\S+', 'password=***REDACTED***'),
        (r'token[=:]\s*\S+', 'token=***REDACTED***'),
        (r'api[_-]?key[=:]\s*\S+', 'api_key=***REDACTED***'),
        (r'secret[=:]\s*\S+', 'secret=***REDACTED***'),
        (r'bearer\s+\S+', 'bearer ***REDACTED***'),
        (r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', '***EMAIL***'),
    ]
    for pattern, replacement in patterns:
        logs = re.sub(pattern, replacement, logs, flags=re.IGNORECASE)

    if len(logs) > max_chars:
        logs = logs[:max_chars] + "\n... [TRUNCATED]"
    return logs

class DiagnosticianAgent:
    """Analyzes pod failures and identifies root causes."""

            namespace=namespace,

        )
        return [
            {
                "reason": e.reason,
                "message": e.message,
                "count": e.count,
                "last_seen": str(e.last_timestamp),

            for e in sorted(events.items,

        return {
            "image": container.image,
            "resources": container.resources.to_dict() if container.resources else "Not specified",
```

```python
        print("🔒 Checking policies...")

        # 1. Check internal policies
        internal_violations = self._check_internal_policies(state, proposed_fix)
        violations.extend(internal_violations)

        # 2. Check OPA policies
        opa_result = await self._check_opa_policies(state, proposed_fix)
        for v in opa_result.get("violations", []):
            violations.append({
                "policy_name": "opa_policy",
                "description": v,
                "severity": "critical",
                "source": "opa"
            })
        for w in opa_result.get("warnings", []):
            violations.append({
                "policy_name": "opa_warning",
                "description": w,
                "severity": "warning",
                "source": "opa"
            })

        # Determine if policy check passed
        critical_violations = [v for v in violations if v["severity"] == "critical"]
        policy_passed = len(critical_violations) == 0

        print(f"   Total violations: {len(violations)} ({len(critical_violations)} critical)")
        print(f"   Policy Passed: {policy_passed}")

        return {
            "policy_violations": violations,
            "policy_passed": policy_passed,
            "status": "policy_check_complete"
        }

    def _check_internal_policies(self, state: K8sOperatorState, fix: dict) -> List[dict]:
        """Check against internal policy configuration."""
        violations = []
        namespace = state["namespace"]

        # Namespace restrictions
        ns_policy = self.policies.get("policies", {}).get("namespace_restrictions", {})
        forbidden_ns = ns_policy.get("forbidden_namespaces", [])
        allowed_ns = ns_policy.get("allowed_namespaces", [])

        if namespace in forbidden_ns:
            violations.append({
                "policy_name": "namespace_restriction",
                "description": f"Automated remediation not allowed in {namespace}",
                "severity": "critical",
                "source": "internal"
            })

        if allowed_ns and namespace not in allowed_ns:
            violations.append({
                "policy_name": "namespace_allowlist",
                "description": f"Namespace {namespace} not in allowed list",
                "severity": "error",
                "source": "internal"
            })

        # Check for dangerous patterns
        dangerous = self.policies.get("policies", {}).get("dangerous_patterns", {})
        for cmd in fix.get("commands", []):
            for pattern in dangerous.get("blocked_patterns", []):
                if re.search(pattern, cmd, re.IGNORECASE):
                    violations.append({
                        "policy_name": "dangerous_command",
                        "description": f"Command matches blocked pattern: {pattern}",
                        "severity": "critical",
                        "source": "internal"
                    })

        return violations

    async def _check_opa_policies(self, state: K8sOperatorState, fix: dict) -> dict:
        """Check against OPA policies."""
        input_data = {
            "namespace": state["namespace"],
            "pod_name": state["pod_name"],
            "fix_type": fix.get("fix_type"),
            "commands": fix.get("commands", []),
            "manifest_changes": fix.get("manifest_changes"),
            "risk_level": fix.get("risk_level"),
            "diagnosis_confidence": state.get("diagnosis_confidence", 0)
        }
        return await self.opa.check_policy("kubernetes/remediation", input_data)

async def policy_checker_node(state: K8sOperatorState) -> dict:
    """LangGraph node for policy checking."""
    checker = PolicyChecker()
    return await checker.check_fix(state)
```

<Callout type="tip">

  cluster, we create a Pull Request with the changes. This provides an audit
  trail, enables CI validation, and allows ArgoCD/Flux to reconcile the changes.

#### Step 7.1: Create GitOps Integration

```python
# integrations/gitops.py
import httpx
import os
import base64
from datetime import datetime
from typing import Optional
import yaml

class GitOpsClient:
    """Create PRs for GitOps-backed remediation."""

    def __init__(self):
        self.token = os.getenv("GITHUB_TOKEN")
        self.repo = os.getenv("GITHUB_REPO")  # e.g., "org/k8s-manifests"
        self.base_url = "https://api.github.com"
        self.headers = {
            "Authorization": f"token {self.token}",
            "Accept": "application/vnd.github.v3+json"
        }

    async def create_remediation_pr(
        self,
        incident_id: str,
        namespace: str,
        pod_name: str,
        fix: dict,
        diagnosis: dict
    ) -> dict:
        """Create a PR with the remediation changes."""
        branch_name = f"remediation/{incident_id}"

        async with httpx.AsyncClient() as client:
            # 1. Get the default branch SHA
            repo_info = await client.get(
                f"{self.base_url}/repos/{self.repo}",
                headers=self.headers
            )
            default_branch = repo_info.json()["default_branch"]

            ref_info = await client.get(
                f"{self.base_url}/repos/{self.repo}/git/ref/heads/{default_branch}",
                headers=self.headers
            )
            base_sha = ref_info.json()["object"]["sha"]

            # 2. Create a new branch
            await client.post(
                f"{self.base_url}/repos/{self.repo}/git/refs",
                headers=self.headers,
                json={
                    "ref": f"refs/heads/{branch_name}",
                    "sha": base_sha
                }
            )

            # 3. Create/update the manifest file
            manifest_path = f"namespaces/{namespace}/{pod_name.rsplit('-', 2)[0]}/deployment.yaml"
            manifest_content = self._generate_manifest_patch(fix)

            await client.put(
                f"{self.base_url}/repos/{self.repo}/contents/{manifest_path}",
                headers=self.headers,
                json={
                    "message": f"fix({incident_id}): {fix['description'][:50]}",
                    "content": base64.b64encode(manifest_content.encode()).decode(),
                    "branch": branch_name
                }
            )

            # 4. Create the PR
            pr_body = self._generate_pr_body(incident_id, diagnosis, fix)
            pr_response = await client.post(
                f"{self.base_url}/repos/{self.repo}/pulls",
                headers=self.headers,
                json={
                    "title": f"🤖 Auto-remediation: {incident_id}",
                    "body": pr_body,
                    "head": branch_name,
                    "base": default_branch,
                    "labels": ["auto-remediation", fix["risk_level"]]
                }
            )

            pr_data = pr_response.json()
            return {
                "pr_url": pr_data["html_url"],
                "pr_number": pr_data["number"],
                "branch": branch_name
            }

    def _generate_manifest_patch(self, fix: dict) -> str:
        """Generate the manifest changes as YAML."""
        if fix.get("manifest_changes"):
            return yaml.dump(fix["manifest_changes"], default_flow_style=False)
        return f"# Remediation: {fix['description']}\n# Commands: {fix['commands']}"

    def _generate_pr_body(self, incident_id: str, diagnosis: dict, fix: dict) -> str:
        """Generate a detailed PR description."""
        return f"""## 🤖 Automated Remediation

**Incident ID:** `{incident_id}`
**Generated:** {datetime.now().isoformat()}

### Diagnosis
- **Root Cause:** {diagnosis.get('root_cause', 'Unknown')}
- **Category:** {diagnosis.get('category', 'unknown')}
- **Confidence:** {diagnosis.get('confidence', 0):.0%}

### Evidence
{chr(10).join(f'- {e}' for e in diagnosis.get('evidence', []))}

### Proposed Fix
- **Type:** `{fix['fix_type']}`
- **Risk Level:** `{fix['risk_level']}`
- **Description:** {fix['description']}

### Expected Outcome
{fix.get('expected_outcome', 'N/A')}

### Rollback Plan
{fix.get('rollback_plan', 'N/A')}

---
⚠️ **This PR was generated automatically by the SRE Agent.**
Please review carefully before merging.
"""
```

```python
# agents/executor.py
from kubernetes import client
from kubernetes.client.rest import ApiException
from models.state import K8sOperatorState
from integrations.gitops import GitOpsClient
from datetime import datetime
import os

class ExecutorAgent:
    """Executes approved remediation plans."""

    def __init__(self):
        self.v1 = client.CoreV1Api()
        self.apps_v1 = client.AppsV1Api()
        self.gitops = GitOpsClient()
        self.use_gitops = os.getenv("USE_GITOPS", "true").lower() == "true"

    async def execute(self, state: K8sOperatorState) -> dict:
        """Execute the approved remediation."""
        if not state.get("human_approved"):
            return {
                "execution_result": "Execution blocked: Not approved",
                "status": "awaiting_approval"
            }

        fix = state.get("proposed_fix", {})
        fix_type = fix.get("fix_type", "")
        pod_name = state["pod_name"]
        namespace = state["namespace"]

        print(f"⚡ Executing {fix_type} for {namespace}/{pod_name}")

        try:
            # For GitOps mode, create PR instead of direct execution
            if self.use_gitops and fix_type in ["patch", "scale"]:
                result = await self._execute_via_gitops(state, fix)
            else:
                result = await self._execute_direct(state, fix)

            print(f"   Result: {result}")
            return {
                "execution_result": result,
                "status": "completed"
            }

        except Exception as e:
            error_msg = f"Execution failed: {str(e)}"
            print(f"   ❌ {error_msg}")
            return {
                "execution_result": error_msg,
                "status": "failed",
                "errors": state.get("errors", []) + [error_msg]
            }

    async def _execute_via_gitops(self, state: K8sOperatorState, fix: dict) -> str:
        """Create a PR for GitOps reconciliation."""
        pr_result = await self.gitops.create_remediation_pr(
            incident_id=state["incident_id"],
            namespace=state["namespace"],
            pod_name=state["pod_name"],
            fix=fix,
            diagnosis=state.get("diagnosis", {})
        )
        return f"Created PR: {pr_result['pr_url']}"

    async def _execute_direct(self, state: K8sOperatorState, fix: dict) -> str:
        """Execute remediation directly on the cluster."""
        fix_type = fix.get("fix_type", "")
        pod_name = state["pod_name"]
        namespace = state["namespace"]

        if fix_type == "restart":
            return self._restart_pod(pod_name, namespace)
        elif fix_type == "scale":
            return self._scale_deployment(pod_name, namespace)
        elif fix_type == "rollback":
            return self._rollback_deployment(pod_name, namespace)
        elif fix_type == "escalate":
            return "Escalated to human operator"
        else:
            return f"Unknown fix type: {fix_type}"

    def _restart_pod(self, pod_name: str, namespace: str) -> str:
        """Delete pod to trigger restart by controller."""
        self.v1.delete_namespaced_pod(
            name=pod_name,
            namespace=namespace,
            grace_period_seconds=30
        )
        return f"Pod {pod_name} deleted, will be recreated by controller"

    def _scale_deployment(self, pod_name: str, namespace: str) -> str:
        """Scale deployment up."""
        deployment_name = self._get_deployment_name(pod_name, namespace)
        if not deployment_name:
            return "Could not find parent deployment"

        deployment = self.apps_v1.read_namespaced_deployment(deployment_name, namespace)
        current_replicas = deployment.spec.replicas or 1
        new_replicas = min(current_replicas + 1, 5)

        self.apps_v1.patch_namespaced_deployment_scale(
            deployment_name, namespace,
            {"spec": {"replicas": new_replicas}}
        )
        return f"Scaled {deployment_name} from {current_replicas} to {new_replicas} replicas"

    def _rollback_deployment(self, pod_name: str, namespace: str) -> str:
        """Rollback deployment to previous revision."""
        deployment_name = self._get_deployment_name(pod_name, namespace)
        if not deployment_name:
            return "Could not find parent deployment"

        patch = {
            "spec": {
                "template": {
                    "metadata": {
                        "annotations": {
                            "kubectl.kubernetes.io/restartedAt": datetime.now().isoformat()
                        }
                    }
                }
            }
        }
        self.apps_v1.patch_namespaced_deployment(deployment_name, namespace, patch)
        return f"Triggered rollout restart for {deployment_name}"

    def _get_deployment_name(self, pod_name: str, namespace: str) -> str | None:
        """Get the deployment name from a pod."""
        try:
            pod = self.v1.read_namespaced_pod(pod_name, namespace)
            for ref in pod.metadata.owner_references or []:
                if ref.kind == "ReplicaSet":
                    rs = self.apps_v1.read_namespaced_replica_set(ref.name, namespace)
                    for rs_ref in rs.metadata.owner_references or []:
                        if rs_ref.kind == "Deployment":
                            return rs_ref.name
            return None
        except ApiException:
            return None

async def executor_node(state: K8sOperatorState) -> dict:
    """LangGraph node for execution."""
    executor = ExecutorAgent()
    return await executor.execute(state)
```

````python
        if action == "approve":
            self._update_message(pending["message_ts"], f"✅ Approved by <@{user}>")
            del self.pending_approvals[incident_id]
            return {
                "human_approved": True,
                "approver": user,

        elif action == "reject":

            del self.pending_approvals[incident_id]
            return {
                "human_approved": False,
                "approver": user,
                "approval_notes": "Rejected via Slack",
                "status": "rejected"
            }
        elif action == "details":
            state = pending["state"]
            self.slack.chat_postMessage(
                channel=self.channel,
                thread_ts=pending["message_ts"],
                text=f"```\n{json.dumps(state, indent=2, default=str)[:3000]}\n```"
            )
            return {}

        return {"error": f"Unknown action: {action}"}

            ts=ts,
            text=status,
````

#### Step 11.1: Create the Main Workflow

```python
# main.py
from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver
from models.state import K8sOperatorState
from agents.diagnostician import diagnostician_node
from agents.planner import planner_node
from agents.policy_checker import policy_checker_node
from agents.executor import executor_node
from agents.watcher import K8sEventWatcher
from integrations.slack import SlackApprovalHandler
from observability.metrics import metrics
from datetime import datetime
import asyncio
import uuid

# Initialize components
slack_handler = SlackApprovalHandler()

def route_after_diagnosis(state: K8sOperatorState) -> str:
    """Route based on diagnosis confidence."""
    confidence = state.get("diagnosis_confidence", 0)
    if confidence < 0.3:
        return "escalate"
    return "plan"

def route_after_policy(state: K8sOperatorState) -> str:
    """Route based on policy check results."""
    if not state.get("policy_passed"):
        critical = any(
            v.get("severity") == "critical"
            for v in state.get("policy_violations", [])
        )
        if critical:
            return "escalate"
    return "request_approval"

def route_after_approval(state: K8sOperatorState) -> str:
    """Route based on approval status."""
    if state.get("human_approved"):
        return "execute"
    if state.get("status") == "rejected":
        return "end"
    return "wait_approval"

def request_approval_node(state: K8sOperatorState) -> dict:
    """Send approval request to Slack."""
    print("📨 Requesting human approval...")
    metrics.record_approval_request()
    slack_handler.send_approval_request(state)
    return {"status": "awaiting_approval"}

def escalate_node(state: K8sOperatorState) -> dict:
    """Escalate to human operator."""
    print("🚨 Escalating to human operator...")
    diagnosis = state.get("diagnosis", {})
    reason = "low_confidence" if state.get("diagnosis_confidence", 0) < 0.3 else "policy_violation"

    metrics.record_incident_escalated(
        namespace=state["namespace"],
        category=diagnosis.get("category", "unknown"),
        reason=reason
    )

    slack_handler.slack.chat_postMessage(
        channel="#sre-escalations",
        text=f"🚨 *ESCALATION*: Incident {state['incident_id']} requires manual intervention.\n"
             f"Pod: `{state['namespace']}/{state['pod_name']}`\n"
             f"Reason: {reason}"
    )
    return {"status": "escalated"}

def build_operator_graph():
    """Build the K8s operator workflow."""
    workflow = StateGraph(K8sOperatorState)

    # Add nodes
    workflow.add_node("diagnose", diagnostician_node)
    workflow.add_node("plan", planner_node)
    workflow.add_node("policy_check", policy_checker_node)
    workflow.add_node("request_approval", request_approval_node)
    workflow.add_node("execute", executor_node)
    workflow.add_node("escalate", escalate_node)

    # Set entry point
    workflow.set_entry_point("diagnose")

    # Add edges
    workflow.add_conditional_edges(
        "diagnose",
        route_after_diagnosis,
        {"plan": "plan", "escalate": "escalate"}
    )
    workflow.add_edge("plan", "policy_check")
    workflow.add_conditional_edges(
        "policy_check",
        route_after_policy,
        {"request_approval": "request_approval", "escalate": "escalate"}
    )
    workflow.add_edge("request_approval", END)  # Pauses for approval
    workflow.add_edge("execute", END)
    workflow.add_edge("escalate", END)

    # Compile with checkpointing for HITL
    memory = MemorySaver()
    return workflow.compile(
        checkpointer=memory,
        interrupt_before=["execute"]
    )

async def handle_pod_failure(event):
    """Callback when pod failure is detected."""
    incident_id = f"INC-{datetime.now().strftime('%Y%m%d%H%M%S')}-{uuid.uuid4().hex[:6]}"

    # Record metrics
    metrics.record_incident_detected(event.namespace, "unknown")
    metrics.record_diagnosis_start(incident_id)

    initial_state = {
        "pod_name": event.pod_name,
        "namespace": event.namespace,
        "event_type": event.event_type,
        "timestamp": event.timestamp.isoformat(),
        "container_statuses": [s.dict() for s in event.container_statuses] if hasattr(event, 'container_statuses') else [],
        "incident_id": incident_id,
        "iteration_count": 0,
        "errors": [],
        "status": "detected"
    }

    graph = build_operator_graph()
    config = {"configurable": {"thread_id": incident_id}}

    # Run until approval checkpoint
    result = await graph.ainvoke(initial_state, config)
    print(f"Incident {incident_id} awaiting approval...")
    return incident_id, config

async def main():
    """Main entry point."""
    print("=" * 60)
    print("🤖 K8s SRE Agent Starting...")
    print("=" * 60)

    # Start metrics server
    metrics.start_server()

    # Start the watcher
    watcher = K8sEventWatcher(on_failure=handle_pod_failure)
    await watcher.watch_pods(namespaces=["default", "staging"])

if __name__ == "__main__":
    asyncio.run(main())
```

```python
from kubernetes import client, config
from typing import Dict, List

class MultiClusterClient:
    """Manage multiple Kubernetes clusters."""

    def __init__(self, cluster_configs: Dict[str, str]):
        self.clients: Dict[str, client.CoreV1Api] = {}
        for name, kubeconfig in cluster_configs.items():
            config.load_kube_config(config_file=kubeconfig)
            self.clients[name] = client.CoreV1Api()

    async def watch_all_clusters(self, on_failure):
        """Watch all clusters for failures."""
        tasks = [
            self._watch_cluster(name, api, on_failure)
```

### Integration with K8sGPT

[K8sGPT](https://k8sgpt.ai/) is a CNCF sandbox project that provides AI-powered Kubernetes troubleshooting. You can integrate it with your operator for enhanced diagnosis:

```python
# integrations/k8sgpt.py
import subprocess
import json

class K8sGPTClient:
    """Integration with K8sGPT for enhanced diagnosis."""

    def analyze(self, namespace: str = None) -> List[dict]:
        """Run K8sGPT analysis."""
        cmd = ["k8sgpt", "analyze", "--output", "json"]
        if namespace:
            cmd.extend(["--namespace", namespace])

        result = subprocess.run(cmd, capture_output=True, text=True)
        if result.returncode == 0:
            return json.loads(result.stdout)
        return []

    def get_pod_analysis(self, pod_name: str, namespace: str) -> dict:
        """Get K8sGPT analysis for a specific pod."""
        analyses = self.analyze(namespace)
        for analysis in analyses:
            if analysis.get("name") == pod_name:
                return {
                    "error": analysis.get("error"),
                    "details": analysis.get("details"),
                    "solution": analysis.get("solution")
                }
        return {}
```

1. **Event-driven** architecture enables reactive agents that respond to infrastructure changes in real-time
2. **Policy-as-code** with OPA/Kyverno ensures automated actions comply with organizational rules
3. **Human-in-the-loop** approval is essential for production safety—never skip this for infrastructure changes
4. **GitOps integration** provides audit trails, enables rollback, and fits into existing CI/CD workflows
5. **Observability** for the operator itself is crucial—monitor your AI SRE's effectiveness
6. **Security-first design** protects against prompt injection and ensures least-privilege access
7. **Prometheus metrics** enable data-driven improvements to your remediation strategies

**Final Analogy**: Building this K8s operator is like training an apprentice SRE engineer. You teach them (via prompts and runbooks) how to diagnose issues, you give them guidelines (policies) they must follow, you supervise their work (human approval), and you track their performance (metrics). Over time, as you refine the prompts and policies based on real incidents, your AI apprentice becomes more capable—but you always maintain oversight for critical decisions.
