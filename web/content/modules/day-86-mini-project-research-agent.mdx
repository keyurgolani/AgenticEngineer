## Project Overview

**Objective**: Build a research agent that searches the web, synthesizes information, and provides cited answers. Uses SearXNG (self-hosted search) or Tavily as the search backend.

**Why This Matters**: Agents without web access are hallucination-prone and outdated. A research service gives them live access to the world, turning them into capable analysts.

### Search Service

{/* IMAGE_PLACEHOLDER: Create a comparison infographic showing SearXNG vs Tavily side-by-side. For SearXNG: show self-hosted server icon, "Free" badge, "Privacy-focused" label, aggregates from Google/Bing/DuckDuckGo. For Tavily: show cloud icon, "Paid API" badge, "Deep Crawling" label, AI-optimized results. Include a decision tree: "Simple query?" → SearXNG, "Complex research?" → Tavily, "SearXNG down?" → Auto-fallback to Tavily. Place this before the code to help learners understand when to use each provider. */}

```python
# services/search.py
import httpx
from typing import List, Dict, Optional
from abc import ABC, abstractmethod
import os

class SearchResult:
    def __init__(self, title: str, url: str, snippet: str, content: str = None):
        self.title = title
        self.url = url
        self.snippet = snippet
        self.content = content

class SearchProvider(ABC):
    @abstractmethod
    async def search(self, query: str, num_results: int = 5) -> List[SearchResult]:
        pass

class SearXNGProvider(SearchProvider):
    """Self-hosted SearXNG search."""

    def __init__(self, base_url: str = "http://localhost:8888"):
        self.base_url = base_url

    async def search(self, query: str, num_results: int = 5) -> List[SearchResult]:
        async with httpx.AsyncClient() as client:
            response = await client.get(
                f"{self.base_url}/search",
                params={
                    "q": query,
                    "format": "json",
                    "engines": "google,bing,duckduckgo",
                    "pageno": 1
                },
                timeout=10.0
            )

            data = response.json()
            results = []

            for item in data.get("results", [])[:num_results]:
                results.append(SearchResult(
                    title=item.get("title", ""),
                    url=item.get("url", ""),
                    snippet=item.get("content", "")
                ))

            return results

class TavilyProvider(SearchProvider):
    """Tavily search API."""

    def __init__(self, api_key: str = None):
        self.api_key = api_key or os.getenv("TAVILY_API_KEY")

    async def search(self, query: str, num_results: int = 5) -> List[SearchResult]:
        async with httpx.AsyncClient() as client:
            response = await client.post(
                "https://api.tavily.com/search",
                json={
                    "api_key": self.api_key,
                    "query": query,
                    "search_depth": "advanced",
                    "max_results": num_results,
                    "include_raw_content": True
                },
                timeout=30.0
            )

            data = response.json()
            results = []

            for item in data.get("results", []):
                results.append(SearchResult(
                    title=item.get("title", ""),
                    url=item.get("url", ""),
                    snippet=item.get("content", ""),
                    content=item.get("raw_content", "")
                ))

            return results

class SearchService:
    """Unified search service with fallback."""

    def __init__(self):
        self.providers = []

        # Try SearXNG first (free, self-hosted)
        self.providers.append(SearXNGProvider())

        # Fallback to Tavily
        if os.getenv("TAVILY_API_KEY"):
            self.providers.append(TavilyProvider())

    async def search(self, query: str, num_results: int = 5) -> List[SearchResult]:
        """Search with automatic fallback."""
        for provider in self.providers:
            try:
                results = await provider.search(query, num_results)
                if results:
                    return results
            except Exception as e:
                print(f"Search provider failed: {e}")
                continue

        return []
```

**Key Implementation Details**:

- **Abstract Base Class**: `SearchProvider` defines the interface, making it easy to add new search providers (Brave, Bing, etc.)
- **Timeout Strategy**: SearXNG has a 10s timeout (fast, aggregated results), Tavily has 30s (deep crawling takes longer)
- **Graceful Degradation**: If a provider fails, the service automatically tries the next one—no manual intervention needed
- **Content Extraction**: Tavily provides `raw_content` for deeper analysis, while SearXNG returns snippets for quick answers

### Research Agent

{/* IMAGE_PLACEHOLDER: Create an animated sequence diagram showing the iterative research process with a concrete example. Show: Question: "How do transformers work?" → Iteration 1: Search "transformer architecture" → Synthesize: "Found attention mechanism info, but missing training details" → Iteration 2: Search "transformer training process" → Synthesize: "Now have architecture + training, but unclear about applications" → Iteration 3: Search "transformer applications NLP" → Final Answer with [1][2][3] citations. Use progressive disclosure to show how knowledge builds across iterations. Place this before the code to demonstrate the iterative refinement concept. */}

```python
# services/research_agent.py
from services.search import SearchService, SearchResult
from langchain_openai import ChatOpenAI
from typing import List, Dict
import asyncio

class ResearchAgent:
    """Agentic research with iterative search and synthesis."""

    def __init__(self, llm_model: str = "gpt-4o-mini"):
        self.search = SearchService()
        self.llm = ChatOpenAI(model=llm_model, temperature=0.3)

    async def research(
        self,
        question: str,
        max_iterations: int = 3,
        sources_per_iteration: int = 5
    ) -> Dict:
        """Conduct iterative research on a question."""

        all_sources = []
        search_queries = [question]
        findings = []

        for iteration in range(max_iterations):
            # Search with current queries
            for query in search_queries:
                results = await self.search.search(query, sources_per_iteration)
                all_sources.extend(results)

            # Synthesize current findings
            synthesis = await self._synthesize(question, all_sources, findings)
            findings.append(synthesis)

            # Check if we have enough information
            if await self._is_sufficient(question, findings):
                break

            # Generate follow-up queries
            search_queries = await self._generate_followup_queries(
                question, findings, all_sources
            )

            if not search_queries:
                break

        # Generate final answer with citations
        answer = await self._generate_answer(question, findings, all_sources)

        return {
            "answer": answer["content"],
            "citations": answer["citations"],
            "sources_consulted": len(all_sources),
            "iterations": len(findings)
        }

    async def _synthesize(
        self,
        question: str,
        sources: List[SearchResult],
        previous_findings: List[str]
    ) -> str:
        """Synthesize information from sources."""

        source_text = "\n\n".join([
            f"Source: {s.title}\nURL: {s.url}\nContent: {s.snippet or s.content[:500] if s.content else ''}"
            for s in sources[-10:]  # Last 10 sources
        ])

        previous = "\n".join(previous_findings) if previous_findings else "None yet"

        prompt = f"""Synthesize information to answer: {question}

Previous findings:
{previous}

New sources:
{source_text}

Extract key facts and insights. Note any contradictions or gaps."""

        response = await self.llm.ainvoke(prompt)
        return response.content

    async def _is_sufficient(self, question: str, findings: List[str]) -> bool:
        """Check if we have enough information."""
        if len(findings) < 2:
            return False

        prompt = f"""Question: {question}

Current findings:
{chr(10).join(findings)}

Do we have sufficient information to comprehensively answer the question?
Reply with just YES or NO."""

        response = await self.llm.ainvoke(prompt)
        return "YES" in response.content.upper()

    async def _generate_followup_queries(
        self,
        question: str,
        findings: List[str],
        sources: List[SearchResult]
    ) -> List[str]:
        """Generate follow-up search queries."""

        prompt = f"""Original question: {question}

Current findings:
{chr(10).join(findings[-2:])}

What specific follow-up searches would help fill gaps in our knowledge?
Return 2-3 specific search queries, one per line. If no more searches needed, return DONE."""

        response = await self.llm.ainvoke(prompt)

        if "DONE" in response.content.upper():
            return []

        queries = [q.strip() for q in response.content.strip().split("\n") if q.strip()]
        return queries[:3]

    async def _generate_answer(
        self,
        question: str,
        findings: List[str],
        sources: List[SearchResult]
    ) -> Dict:
        """Generate final answer with citations."""

        # Build source reference
        source_refs = {i+1: s for i, s in enumerate(sources[:20])}
        source_text = "\n".join([
            f"[{i}] {s.title} - {s.url}"
            for i, s in source_refs.items()
        ])

        prompt = f"""Answer this question comprehensively: {question}

Research findings:
{chr(10).join(findings)}

Available sources for citation:
{source_text}

Write a well-structured answer. Cite sources using [1], [2], etc."""

        response = await self.llm.ainvoke(prompt)

        # Extract used citations
        import re
        used_citations = set(re.findall(r'\[(\d+)\]', response.content))

        citations = [
            {"id": int(c), "title": source_refs[int(c)].title, "url": source_refs[int(c)].url}
            for c in used_citations if int(c) in source_refs
        ]

        return {
            "content": response.content,
            "citations": citations
        }
```

**Critical Implementation Patterns**:

- **Iterative Refinement**: The agent doesn't just search once—it reads, identifies gaps, and searches again (like a human researcher)
- **Synthesis Quality**: The `_synthesize` method is crucial—it must extract facts, note contradictions, and identify what's still unknown
- **Sufficiency Detection**: The agent decides when to stop researching (avoiding infinite loops or premature conclusions)
- **Citation Extraction**: Uses regex to find `[1]`, `[2]` patterns in the LLM's response and maps them back to source URLs
- **Temperature Setting**: `0.3` balances creativity (for query generation) with factual accuracy (for synthesis)

# routers/research.py
from fastapi import APIRouter
from pydantic import BaseModel
from typing import List, Optional
from services.research_agent import ResearchAgent

router = APIRouter(prefix="/research", tags=["research"])
agent = ResearchAgent()

class ResearchRequest(BaseModel):
    question: str
    max_iterations: int = 3
    sources_per_iteration: int = 5

class Citation(BaseModel):
    id: int
    title: str
    url: str

class ResearchResponse(BaseModel):
    answer: str
    citations: List[Citation]
    sources_consulted: int
    iterations: int

@router.post("/", response_model=ResearchResponse)
async def research(request: ResearchRequest):
    """Conduct research on a question."""
    result = await agent.research(
        question=request.question,
        max_iterations=request.max_iterations,
        sources_per_iteration=request.sources_per_iteration
    )
    return ResearchResponse(**result)

@router.post("/quick")
async def quick_search(question: str):
    """Quick single-iteration search."""
    result = await agent.research(question, max_iterations=1)
    return result

## Key Takeaways

{/* IMAGE_PLACEHOLDER: Create an infographic with 4 key lessons as visual metaphors: (1) Iterative Search shown as a spiral/loop getting closer to a target, (2) Citation Tracking shown as facts connected to source documents with chains/links, (3) Hybrid Providers shown as a balance scale with SearXNG (free) and Tavily (premium), (4) Synthesis Quality shown as puzzle pieces from multiple sources forming a complete picture. Use icons and minimal text. Place this at the beginning of Key Takeaways section. */}

1. **Iterative Search**: Good research is a loop, not a line. Allow agents to refine their queries.
   - **Why it matters**: Single-shot searches miss nuances. Humans naturally iterate—read, identify gaps, search again. Your agent should too.
   - **Example**: Asking "What is RAG?" might return basic definitions. A follow-up "RAG implementation challenges" reveals practical issues. A third query "RAG vs fine-tuning" provides comparative context.

2. **Citation Tracking**: Always maintain the link between a fact and its source URL.
   - **Why it matters**: Without citations, your agent is just another hallucination machine. Citations enable verification, build trust, and provide legal defensibility.
   - **Implementation tip**: Store citations as structured data (not just text) so you can programmatically verify URLs, check freshness, and rank source credibility.

3. **Hybrid Providers**: Self-hosted SearXNG is great for basic queries; keep Tavily as a backup for complex crawls.
   - **Cost optimization**: SearXNG handles 80% of queries at zero cost. Tavily's deep crawling is worth paying for the remaining 20% of complex research.
   - **Privacy consideration**: SearXNG keeps sensitive queries on your infrastructure—critical for enterprise or regulated industries.

4. **Synthesis is Hard**: The quality of the final answer depends heavily on the "synthesizer" prompt—iterate on it!
   - **Common pitfalls**: Contradictory information, missing context, over-reliance on a single source, failure to identify gaps.
   - **Prompt engineering tips**: Explicitly instruct the LLM to note contradictions, identify missing information, and cross-reference facts across sources.
