## Introduction: Why Evaluation Matters

Building an agent that works on your test cases is easy. Building one that works reliably in production is hard. The difference? **Rigorous evaluation.**

<Callout type="warning">
  **The Production Reality**: Most agent failures in production aren't
  bugs—they're edge cases that weren't tested. Without systematic evaluation,
  you're flying blind.
</Callout>

**The "Vibe Check" Trap:**

1. Developer tries 3 queries
2. Agent gets 3/3 right
3. "It works!" → Ship it
4. Reality: 3 samples is statistically insignificant

<Callout type="info">
  **The Law of Large Numbers:** You need at least 50-100 examples to have *any*
  confidence in an LLM system's performance. Stochasticity means "it worked
  once" proves nothing.
</Callout>

## 69.3 Building Custom Evaluation Pipelines

While standard benchmarks are valuable, production agents need custom evaluations tailored to your specific use cases.

### Using LangSmith for Agent Tracing & Evaluation

[LangSmith](https://smith.langchain.com) provides end-to-end observability and evaluation for LangChain applications.

```python
import os
from langsmith import Client
from langsmith.evaluation import evaluate
from langchain_openai import ChatOpenAI

# Setup
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "ls_..."
os.environ["LANGCHAIN_PROJECT"] = "agent-evaluation"

client = Client()

# Create a dataset for evaluation
dataset_name = "customer-support-queries"
dataset = client.create_dataset(dataset_name)

# Add examples to the dataset
examples = [
    {
        "input": {"query": "How do I reset my password?"},
        "output": {"answer": "Go to Settings > Security > Reset Password"}
    },
    {
        "input": {"query": "What's your refund policy?"},
        "output": {"answer": "Full refund within 30 days of purchase"}
    },
]

for example in examples:
    client.create_example(
        inputs=example["input"],
        outputs=example["output"],
        dataset_id=dataset.id,
    )

# Define your agent
def my_agent(inputs: dict) -> dict:
    """Your agent implementation."""
    llm = ChatOpenAI(model="gpt-4o")
    response = llm.invoke(inputs["query"])
    return {"answer": response.content}

# Define evaluators
def correctness_evaluator(run, example) -> dict:
    """Check if the answer is semantically correct."""
    predicted = run.outputs.get("answer", "")
    expected = example.outputs.get("answer", "")

    # Use LLM-as-judge for semantic comparison
    judge = ChatOpenAI(model="gpt-4o")
    prompt = f"""Compare these two answers for semantic equivalence:

    Expected: {expected}
    Predicted: {predicted}

    Are they semantically equivalent? Answer YES or NO."""

    result = judge.invoke(prompt)
    is_correct = "YES" in result.content.upper()

    return {"key": "correctness", "score": 1.0 if is_correct else 0.0}

# Run evaluation
results = evaluate(
    my_agent,
    data=dataset_name,
    evaluators=[correctness_evaluator],
    experiment_prefix="agent-v1",
)

print(f"Correctness: {results['correctness'].mean():.1%}")
```

### Building a Custom Evaluation Framework

For full control, build your own evaluation harness:

```python
import json
import asyncio
from dataclasses import dataclass, field
from typing import Callable, Any
from datetime import datetime
import statistics

@dataclass
class EvalResult:
    """Result of a single evaluation."""
    input: dict
    expected: Any
    actual: Any
    score: float
    latency_ms: int
    cost_usd: float
    metadata: dict = field(default_factory=dict)

@dataclass
class EvalSummary:
    """Summary of evaluation run."""
    total: int
    passed: int
    failed: int
    accuracy: float
    avg_latency_ms: float
    p95_latency_ms: float
    total_cost_usd: float
    timestamp: str

class EvaluationHarness:
    """Custom evaluation framework for agents."""

    def __init__(
        self,
        agent: Callable,
        evaluator: Callable,
        name: str = "evaluation",
    ):
        self.agent = agent
        self.evaluator = evaluator
        self.name = name
        self.results: list[EvalResult] = []

    async def run_single(self, example: dict) -> EvalResult:
        """Run evaluation on a single example."""
        import time

        start = time.perf_counter()

        try:
            # Run agent
            actual = await self.agent(example["input"])
            latency_ms = int((time.perf_counter() - start) * 1000)

            # Evaluate result
            score = await self.evaluator(
                actual=actual,
                expected=example.get("expected"),
                input=example["input"],
            )

            return EvalResult(
                input=example["input"],
                expected=example.get("expected"),
                actual=actual,
                score=score,
                latency_ms=latency_ms,
                cost_usd=actual.get("cost", 0) if isinstance(actual, dict) else 0,
            )

        except Exception as e:
            latency_ms = int((time.perf_counter() - start) * 1000)
            return EvalResult(
                input=example["input"],
                expected=example.get("expected"),
                actual={"error": str(e)},
                score=0.0,
                latency_ms=latency_ms,
                cost_usd=0,
                metadata={"error": str(e)},
            )

    async def run(
        self,
        dataset: list[dict],
        parallel: int = 5,
    ) -> EvalSummary:
        """Run evaluation on entire dataset."""

        # Run evaluations with concurrency limit
        semaphore = asyncio.Semaphore(parallel)

        async def bounded_eval(example):
            async with semaphore:
                return await self.run_single(example)

        tasks = [bounded_eval(ex) for ex in dataset]
        self.results = await asyncio.gather(*tasks)

        # Calculate summary statistics
        scores = [r.score for r in self.results]
        latencies = [r.latency_ms for r in self.results]

        passed = sum(1 for s in scores if s >= 0.5)

        return EvalSummary(
            total=len(self.results),
            passed=passed,
            failed=len(self.results) - passed,
            accuracy=statistics.mean(scores),
            avg_latency_ms=statistics.mean(latencies),
            p95_latency_ms=sorted(latencies)[int(len(latencies) * 0.95)],
            total_cost_usd=sum(r.cost_usd for r in self.results),
            timestamp=datetime.utcnow().isoformat(),
        )

    def save_results(self, path: str):
        """Save results to JSON file."""
        with open(path, "w") as f:
            json.dump(
                [
                    {
                        "input": r.input,
                        "expected": r.expected,
                        "actual": r.actual,
                        "score": r.score,
                        "latency_ms": r.latency_ms,
                    }
                    for r in self.results
                ],
                f,
                indent=2,
            )
```

### Success Rate Metrics

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class SuccessMetrics:
    """Core success metrics for agent evaluation."""

    # Task completion
    task_success_rate: float      # % of tasks completed correctly
    partial_success_rate: float   # % with partial completion

    # Quality scores
    accuracy: float               # Correctness of outputs
    relevance: float              # How relevant to the query
    completeness: float           # How complete the response

    # Reliability
    pass_at_1: float              # First-try success rate
    pass_at_5: float              # Success in 5 attempts
    consistency: float            # Same input → same output

def calculate_pass_at_k(n: int, c: int, k: int) -> float:
    """
    Calculate Pass@k metric.

    Args:
        n: Total samples generated
        c: Number of correct samples
        k: Number of attempts allowed

    Returns:
        Probability of at least one correct in k attempts
    """
    if n - c < k:
        return 1.0

    # Pass@k = 1 - C(n-c, k) / C(n, k)
    from math import comb
    return 1.0 - comb(n - c, k) / comb(n, k)

# Example usage
n_samples = 100
n_correct = 65

print(f"Pass@1: {calculate_pass_at_k(n_samples, n_correct, 1):.1%}")   # 65%
print(f"Pass@5: {calculate_pass_at_k(n_samples, n_correct, 5):.1%}")   # 99.5%
print(f"Pass@10: {calculate_pass_at_k(n_samples, n_correct, 10):.1%}") # 99.99%
```

### Cost Metrics

```python
# Model pricing (per 1M tokens, as of 2025)
MODEL_PRICING = {
    "gpt-4o": {"input": 2.50, "output": 10.00},
    "gpt-4o-mini": {"input": 0.15, "output": 0.60},
    "claude-3-5-sonnet": {"input": 3.00, "output": 15.00},
    "claude-3-5-haiku": {"input": 0.80, "output": 4.00},
}

def calculate_cost(
    model: str,
    input_tokens: int,
    output_tokens: int,
) -> float:
    """Calculate cost for a single request."""
    pricing = MODEL_PRICING.get(model, {"input": 0, "output": 0})

    input_cost = (input_tokens / 1_000_000) * pricing["input"]
    output_cost = (output_tokens / 1_000_000) * pricing["output"]

    return input_cost + output_cost

def cost_adjusted_score(
    accuracy: float,
    cost_per_request: float,
    baseline_cost: float = 0.01,
) -> float:
    """
    Calculate cost-adjusted performance score.

    Higher is better: good accuracy at low cost.
    """
    return accuracy / (cost_per_request / baseline_cost)
```

### Safety Scores

```python
from enum import Enum

class SafetyCategory(Enum):
    HARMFUL_CONTENT = "harmful_content"
    HALLUCINATION = "hallucination"
    PII_LEAK = "pii_leak"
    PROMPT_INJECTION = "prompt_injection"

def calculate_safety_score(
    total_requests: int,
    safety_violations: dict[SafetyCategory, int],
) -> dict:
    """Calculate safety metrics."""

    total_violations = sum(safety_violations.values())

    return {
        "overall_safety_rate": 1 - (total_violations / total_requests),
        "harmful_content_rate": safety_violations.get(
            SafetyCategory.HARMFUL_CONTENT, 0
        ) / total_requests,
        "hallucination_rate": safety_violations.get(
            SafetyCategory.HALLUCINATION, 0
        ) / total_requests,
        "pii_leak_rate": safety_violations.get(
            SafetyCategory.PII_LEAK, 0
        ) / total_requests,
    }
```

```python
    traffic_split: float       # % to treatment (0.0-1.0)
    start_time: datetime
    end_time: Optional[datetime] = None

class ABTestingFramework:
    """Framework for A/B testing agent versions."""

    def __init__(self):
        self.experiments: dict[str, Experiment] = {}
        self.results: dict[str, list] = {}

    def create_experiment(
        self,
        name: str,
        control: Callable,
        treatment: Callable,
        traffic_split: float = 0.5,
    ) -> Experiment:
        """Create a new A/B test experiment."""
        experiment = Experiment(
            name=name,
            control=control,
            treatment=treatment,
            traffic_split=traffic_split,
            start_time=datetime.utcnow(),
        )
        self.experiments[name] = experiment
        self.results[name] = []
        return experiment

    def get_variant(
        self,
        experiment_name: str,
        user_id: str,
    ) -> str:
        """
        Deterministically assign user to variant.
        Same user always gets same variant.
        """
        experiment = self.experiments[experiment_name]

        # Hash user_id for deterministic assignment
        hash_input = f"{experiment_name}:{user_id}"
        hash_value = int(hashlib.md5(hash_input.encode()).hexdigest(), 16)

        # Assign based on traffic split
        if (hash_value % 100) / 100 < experiment.traffic_split:
            return "treatment"
        return "control"

    async def run(
        self,
        experiment_name: str,
        user_id: str,
        input_data: dict,
    ) -> dict:
        """Run the appropriate agent variant."""
        import time

        experiment = self.experiments[experiment_name]
        variant = self.get_variant(experiment_name, user_id)

        agent = (
            experiment.treatment if variant == "treatment"
            else experiment.control
        )

        start = time.perf_counter()
        result = await agent(input_data)
        latency_ms = int((time.perf_counter() - start) * 1000)

        # Record result
        self.results[experiment_name].append({
            "user_id": user_id,
            "variant": variant,
            "input": input_data,
            "output": result,
            "latency_ms": latency_ms,
            "timestamp": datetime.utcnow().isoformat(),
        })

        return {
            "variant": variant,
            "result": result,
            "latency_ms": latency_ms,
        }

    def analyze(self, experiment_name: str) -> dict:
        """Analyze experiment results."""
        from scipy import stats

        results = self.results[experiment_name]

        control = [r for r in results if r["variant"] == "control"]
        treatment = [r for r in results if r["variant"] == "treatment"]

        # Calculate metrics for each group
        def calc_metrics(group):
            latencies = [r["latency_ms"] for r in group]
            # Assume success is stored in output
            successes = sum(
                1 for r in group
                if r["output"].get("success", False)
            )
            return {
                "n": len(group),
                "success_rate": successes / len(group) if group else 0,
                "avg_latency": sum(latencies) / len(latencies) if latencies else 0,
            }

        control_metrics = calc_metrics(control)
        treatment_metrics = calc_metrics(treatment)

        # Statistical significance test
        control_successes = [
            1 if r["output"].get("success") else 0
            for r in control
        ]
        treatment_successes = [
            1 if r["output"].get("success") else 0
            for r in treatment
        ]

        if control_successes and treatment_successes:
            t_stat, p_value = stats.ttest_ind(
                control_successes,
                treatment_successes
            )
        else:
            t_stat, p_value = 0, 1

        return {
            "control": control_metrics,
            "treatment": treatment_metrics,
            "lift": (
                (treatment_metrics["success_rate"] - control_metrics["success_rate"])
                / control_metrics["success_rate"]
                if control_metrics["success_rate"] > 0 else 0
            ),
            "p_value": p_value,
            "significant": p_value < 0.05,
        }

# Usage example
ab_framework = ABTestingFramework()

# Create experiment

    name="agent-v2-rollout",
    control=agent_v1,
    treatment=agent_v2,
    traffic_split=0.1,  # 10% to new version

    user_id="user_123",
```

```python
import asyncio
from typing import Callable
from datetime import datetime

class ShadowModeEvaluator:
    """Run shadow evaluations in production."""

    def __init__(
        self,
        production_agent: Callable,
        shadow_agent: Callable,
        comparison_fn: Callable,
    ):
        self.production = production_agent
        self.shadow = shadow_agent
        self.compare = comparison_fn
        self.comparisons = []

    async def evaluate(self, input_data: dict) -> dict:
        """
        Run both agents, return production result,
        log comparison for analysis.
        """
        # Run both agents in parallel
        prod_task = asyncio.create_task(self.production(input_data))
        shadow_task = asyncio.create_task(self.shadow(input_data))

        # Wait for production (user-facing)
        prod_result = await prod_task

        # Shadow can complete async (non-blocking)
        try:
            shadow_result = await asyncio.wait_for(
                shadow_task,
                timeout=30.0
            )
        except asyncio.TimeoutError:
            shadow_result = {"error": "timeout"}

        # Log comparison
        comparison = await self.compare(
            input=input_data,
            production=prod_result,
            shadow=shadow_result,
        )

        self.comparisons.append({
            "timestamp": datetime.utcnow().isoformat(),
            "input": input_data,
            "production": prod_result,
            "shadow": shadow_result,
            "comparison": comparison,
        })

        # Return only production result to user
        return prod_result

    def get_shadow_metrics(self) -> dict:
        """Analyze shadow performance."""
        if not self.comparisons:
            return {}

        shadow_better = sum(
            1 for c in self.comparisons
            if c["comparison"].get("shadow_better", False)
        )

        return {
            "total_comparisons": len(self.comparisons),
            "shadow_better_rate": shadow_better / len(self.comparisons),
            "ready_for_promotion": shadow_better / len(self.comparisons) > 0.05,
        }
```

### Automated Regression Testing

```python
import json
from pathlib import Path
from datetime import datetime
from typing import Optional

class RegressionDetector:
    """Detect performance regressions in agent updates."""

    def __init__(
        self,
        baseline_path: str,
        threshold: float = 0.02,  # 2% regression threshold
    ):
        self.baseline_path = Path(baseline_path)
        self.threshold = threshold
        self.baseline = self._load_baseline()

    def _load_baseline(self) -> dict:
        """Load baseline metrics."""
        if self.baseline_path.exists():
            with open(self.baseline_path) as f:
                return json.load(f)
        return {}

    def _save_baseline(self, metrics: dict):
        """Save new baseline."""
        with open(self.baseline_path, "w") as f:
            json.dump(metrics, f, indent=2)

    def check_regression(
        self,
        current_metrics: dict,
        metric_name: str = "accuracy",
    ) -> dict:
        """
        Check if current metrics show regression.

        Returns:
            dict with regression status and details
        """
        if metric_name not in self.baseline:
            return {
                "status": "no_baseline",
                "message": f"No baseline for {metric_name}",
            }

        baseline_value = self.baseline[metric_name]
        current_value = current_metrics[metric_name]

        delta = current_value - baseline_value
        delta_pct = delta / baseline_value if baseline_value > 0 else 0

        is_regression = delta_pct < -self.threshold

        return {
            "status": "regression" if is_regression else "ok",
            "metric": metric_name,
            "baseline": baseline_value,
            "current": current_value,
            "delta": delta,
            "delta_pct": delta_pct,
            "threshold": self.threshold,
            "message": (
                f"REGRESSION: {metric_name} dropped {abs(delta_pct):.1%}"
                if is_regression
                else f"OK: {metric_name} within threshold"
            ),
        }

    def update_baseline(
        self,
        metrics: dict,
        require_improvement: bool = True,
    ) -> bool:
        """
        Update baseline if metrics improved.

        Returns:
            True if baseline was updated
        """
        if not self.baseline or not require_improvement:
            self._save_baseline(metrics)
            return True

        # Only update if all metrics improved or stayed same
        for key, value in metrics.items():
            if key in self.baseline and value < self.baseline[key]:
                return False

        self._save_baseline(metrics)
        return True

# CI/CD integration
def ci_regression_check():
    """Run in CI/CD pipeline."""

    # Run evaluation suite

        detector.check_regression(current_metrics, "latency_p95"),
        detector.check_regression(current_metrics, "cost_per_request"),
    ]

    regressions = [c for c in checks if c["status"] == "regression"]

    if regressions:
        print("❌ REGRESSION DETECTED:")
        for r in regressions:
```

```python
class ProductionMonitor:
    """Monitor agent performance in production."""

    def __init__(self, agent_version: str, window_size: int = 1000):
        self.version = agent_version
        self.window_size = window_size
        self.recent_results = []

    def record_request(
        self,
        success: bool,
        latency_seconds: float,
        cost_usd: float,
        model: str,
    ):
        """Record a single request."""
        status = "success" if success else "failure"

        # Update Prometheus metrics
        AGENT_REQUESTS.labels(
            agent_version=self.version,
            status=status
        ).inc()

        AGENT_LATENCY.labels(
            agent_version=self.version
        ).observe(latency_seconds)

        AGENT_COST.labels(
            agent_version=self.version,
            model=model
        ).inc(cost_usd)

        # Update rolling accuracy
        self.recent_results.append(success)
        if len(self.recent_results) > self.window_size:
            self.recent_results.pop(0)

        accuracy = sum(self.recent_results) / len(self.recent_results)
        AGENT_ACCURACY.labels(
            agent_version=self.version
        ).set(accuracy)

    def get_current_metrics(self) -> dict:
        """Get current performance metrics."""
        if not self.recent_results:
            return {}

        return {
            "accuracy": sum(self.recent_results) / len(self.recent_results),
            "sample_size": len(self.recent_results),
```

```python
from openai import OpenAI
from typing import Optional
import json

class LLMJudge:
    """Use GPT-4 to evaluate agent outputs."""

    def __init__(self, model: str = "gpt-4o"):
        self.client = OpenAI()
        self.model = model

    async def evaluate(
        self,
        query: str,
        response: str,
        reference: Optional[str] = None,
        criteria: list[str] = None,
    ) -> dict:
        """
        Evaluate a response using LLM-as-judge.

        Args:
            query: The original user query
            response: The agent's response to evaluate
            reference: Optional reference/expected answer
            criteria: Evaluation criteria (default: helpfulness, accuracy, coherence)

        Returns:
            dict with scores and reasoning
        """
        criteria = criteria or ["helpfulness", "accuracy", "coherence"]

        criteria_text = "\n".join([
            f"- {c}: Score 1-5" for c in criteria
        ])

        reference_text = (
            f"\n\nReference Answer:\n{reference}"
            if reference else ""
        )

        prompt = f"""You are an expert evaluator. Evaluate the following response.

User Query:
{query}

Agent Response:
{response}{reference_text}

Evaluate on these criteria:
{criteria_text}

Provide your evaluation as JSON:
{{
    "scores": {{
        "criterion_name": score (1-5),
        ...
    }},
    "reasoning": "Brief explanation of scores",
    "overall_score": average_score (1-5)
}}"""

        result = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"},
        )

        return json.loads(result.choices[0].message.content)

        self,
        query: str,
        response_a: str,
        response_b: str,

        Returns:
            dict with winner and reasoning
        """
        prompt = f"""Compare these two responses to the same query.

Query: {query}

Response A:
{response_a}

Response B:
{response_b}

Which response is better? Consider:
- Accuracy and correctness
- Helpfulness and completeness
- Clarity and coherence

Respond with JSON:
{{
    "winner": "A" or "B" or "tie",
    "reasoning": "Brief explanation",
    "confidence": "high" or "medium" or "low"
}}"""

        result = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"},
        )

        return json.loads(result.choices[0].message.content)
```

```python
from typing import Callable
import re

def intent_accuracy(actual: dict, expected: dict, input: dict) -> float:
    """Check if agent identified correct intent."""
    actual_intent = actual.get("intent", "").lower()
    expected_intent = expected.get("expected_intent", "").lower()
    return 1.0 if actual_intent == expected_intent else 0.0

def keyword_coverage(actual: dict, expected: dict, input: dict) -> float:
    """Check if response contains expected keywords."""
    response = actual.get("response", "").lower()
    keywords = expected.get("expected_contains", [])

    if not keywords:
        return 1.0

    found = sum(1 for kw in keywords if kw.lower() in response)
    return found / len(keywords)

def response_quality(actual: dict, expected: dict, input: dict) -> float:
    """Check response quality heuristics."""
    response = actual.get("response", "")

    score = 1.0

    # Penalize very short responses
    if len(response) < 50:
        score -= 0.3

    # Penalize very long responses
    if len(response) > 1000:
        score -= 0.2

    # Penalize responses without actionable steps
    if not any(word in response.lower() for word in ["click", "go to", "select", "try"]):
        score -= 0.2

    return max(0.0, score)

def create_composite_evaluator(
    evaluators: list[tuple[str, Callable, float]]
) -> Callable:
    """Create weighted composite evaluator."""

    async def composite(actual, expected, input) -> float:
        total_weight = sum(w for _, _, w in evaluators)
        weighted_sum = 0.0

        for name, evaluator, weight in evaluators:
            score = evaluator(actual, expected, input)
            weighted_sum += score * weight

        return weighted_sum / total_weight

    return composite

# Create composite evaluator

    ("keywords", keyword_coverage, 0.3),
```

  ensure reliability. These benchmarking skills help you validate each agent in

### Recommended Exercises

1. **Beginner**: Set up Promptfoo locally and run a simple eval suite on 10 examples
2. **Intermediate**: Implement Pass@k evaluation for a code generation agent
3. **Advanced**: Build a complete A/B testing framework with statistical significance testing
4. **Expert**: Create a continuous evaluation pipeline with regression detection and alerting

In the capstone, you'll implement:

- Per-agent performance metrics with trajectory evaluation
- Cost tracking across the agent fleet (cost-adjusted performance)
- Regression testing for prompt changes with quality gates
- A/B testing for orchestration strategies
- Shadow mode evaluation for safe rollouts
