## 89.2 On-Device Agents (Edge AI)

The cloud is too slow and too public. The future is **Local**.

### The Privacy Sandwich

1.  **Tiny Model (Edge)**: Runs on your phone/laptop. Handles PII (Names, Passwords).
2.  **Giant Model (Cloud)**: Handles complex reasoning. Receives sanitized data.

<ConceptVisual
  src="/images/privacy_sandwich_architecture.png"
  alt="The Privacy Sandwich"
  caption="Process sensitive PII locally; send only sanitized, complex queries to the cloud."
/>

**Example: Apple Intelligence (2024-2025)**
Apple Intelligence demonstrates the hybrid approach that's becoming industry standard:

- **On-device models** (~3B parameters): Handle personal data (emails, messages, photos) with Apple Silicon Neural Engine
- **Private Cloud Compute (PCC)**: Handles complex requests with cryptographic privacy guarantees
- **Stateless architecture**: Data is wiped the moment a request is fulfilled—verified by independent security researchers
- **Siri 2.0 (2025)**: Full on-screen awareness and cross-app action capabilities

<Callout type="info">
  **2025 Update**: Apple's Private Cloud Compute has been rigorously verified by
  independent security researchers. The "stateless" model ensures data is wiped
  immediately after processing—a claim that has held up under scrutiny
  throughout 2025.
</Callout>

<Callout type="tip">
  **The Privacy-First Trend**: Apple's approach—processing sensitive data
  locally while using cloud for complex reasoning—is becoming the industry
  standard. Expect all major platforms to adopt similar architectures.
</Callout>

## 89.4 Emerging Agent Architectures

Beyond basic RAG and tool use, new architectural patterns are reshaping how agents work.

### Agentic RAG

Traditional RAG retrieves context once. **Agentic RAG** uses autonomous agents that:

- **Plan**: Decompose complex queries into retrieval steps
- **Evaluate**: Assess retrieval quality and try alternative strategies
- **Self-correct**: Detect poor results and iterate until confident
- **Use tools**: Invoke APIs, databases, and external services dynamically

```python
# Traditional RAG: Single retrieval
context = retriever.get_relevant_docs(query)
response = llm.generate(query, context)

# Agentic RAG: Iterative, self-correcting
class AgenticRAG:
    def answer(self, query):
        plan = self.planner.decompose(query)
        for step in plan:
            docs = self.retriever.search(step)
            if self.evaluator.is_sufficient(docs):
                partial = self.llm.generate(step, docs)
            else:
                # Try alternative retrieval strategy
                docs = self.fallback_retriever.search(step)
            self.memory.add(partial)
        return self.synthesizer.combine(self.memory)
```

### Self-Improving Agents

Research patterns enabling agents to learn from their mistakes:

| Pattern                   | Mechanism                          | Use Case                 |
| :------------------------ | :--------------------------------- | :----------------------- |
| **SELF-REFINE**           | Generate → Critique → Refine loop  | Writing, code generation |
| **Reflexion**             | Verbal reinforcement from failures | Multi-step reasoning     |
| **Constitutional AI**     | Self-critique against principles   | Safety alignment         |
| **Chain-of-Verification** | Verify each reasoning step         | Factual accuracy         |

### Agent-to-Agent Communication (A2A)

As agent ecosystems grow, standardized communication becomes critical:

- **MCP (Model Context Protocol)**: Anthropic's standard for tool integration
- **OpenAI Function Calling**: De facto standard for tool use
- **LangChain/LangGraph**: Framework-level agent orchestration
- **Emerging A2A protocols**: Direct agent-to-agent messaging standards

## 89.7 Regulatory Landscape

<ConceptVisual src="/images/global_ai_regulation_map.png" alt="Global Regulation Map" caption="A patchwork of global regulations requires localized compliance strategies." />

### EU AI Act (Effective 2024-2026)

The world's first comprehensive AI regulation is now in force:

| Phase                 | Date     | Requirements                                     |
| :-------------------- | :------- | :----------------------------------------------- |
| **Prohibitions**      | Feb 2025 | Ban on social scoring, subliminal manipulation   |
| **AI Literacy**       | Feb 2025 | Staff must have adequate AI training             |
| **GPAI Rules**        | Aug 2025 | Transparency requirements for general-purpose AI |
| **High-Risk Systems** | Aug 2026 | Conformity assessments, CE marking, monitoring   |

**Risk Categories for Agents:**

<ConceptVisual src="/images/eu_ai_act_risk_pyramid.png" alt="EU AI Act Risk Levels" caption="Understand your agent's risk category to ensure compliance from day one." />

- **Unacceptable Risk**: Social scoring, real-time biometric ID (banned)
- **High Risk**: Credit scoring, recruitment, biometric systems (heavy regulation)
- **Limited Risk**: Chatbots, content generation (transparency requirements)
- **Minimal Risk**: Most business automation (self-regulation)

<Callout type="warning">
  **Compliance Alert**: If your agents make decisions affecting people (hiring,
  credit, healthcare), you likely need conformity assessments, audit trails, and
  human oversight mechanisms. Build compliance into your architecture from day
  one.
</Callout>

### US State Regulations

- **California**: Bias audits, transparency requirements for automated decisions
- **New York**: Local Law 144 requires bias audits for hiring AI
- **Colorado**: AI governance requirements for high-risk systems
- **Over 50% of US states** have enacted some form of AI accountability law
